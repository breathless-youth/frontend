# BY-1205 플래너 분 범위 편집 검증

FE 구현: `feature/BY-1205-planner-minute-ranges`. 서버 계약은 [BY-1204](https://breathless-youth.atlassian.net/browse/BY-1204?focusedCommentId=10409), FE 추적은 [BY-1205](https://breathless-youth.atlassian.net/browse/BY-1205)다.

## 구현

- 실제 pieces를 분별로 자르고 과목별 점유 길이를 합산한다. 동률이면 가장 늦게 끝난 과목을 표시한다. 소수초와 명시적 null을 보존하며 빈 분은 만들지 않는다.
- 부모 키와 UTC 분 범위를 선택한다. 기존 패널·과목 선택·삭제 확인을 재사용하고, 손잡이·시각 입력은 선택 범위만 바꾼다.
- 부모별 EDIT_RANGES 하나에 revision과 최대100개 비겹침 범위를 담는다. 과목 변경과 삭제를 구분하고 이미 삭제한 빈칸을 넓은 과목 변경으로 되살리지 않는다.
- stale 항목은 최신 기록으로 교체하고 다시 선택한다. 다른 부모의 미저장 변경은 유지한다. 응답 유실은 같은 operationId·본문으로 재전송한다.
- 구계약·손상된 metadata를 전체 UPDATE/DELETE로 대체하지 않는다. 새 직접 입력 CREATE는 기존 경로를 유지한다.

## 남은 검증

BY-1204가 실제 테스트 서버에 반영된 뒤 안전한 테스트 기록으로 범위 저장·삭제·재조회, 동시 수정 충돌, 원자성, 개인 통계 반영을 확인해야 한다. 이번에는 실제 사용자 데이터에 저장 요청을 보내지 않았다. 실기기 새 편집 왕복과 VoiceOver는 미실행이다. 5분 순공 실측·기존95항목 전체 QA는 사용자 요청대로 보류 상태다.

범위 편집의 별도 분석 이벤트는 추가하지 않았다. 기존 플래너 진입·날짜 이동 계측을 유지했고, 실제 배포 서버 성공 결과를 포함한 이벤트 확장은 이번 작업 범위 밖이다.
