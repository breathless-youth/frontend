# BY-1351 모드 이름(관리 모드·자율 모드)과 기록 탭 모드별 시간

## 배경

BY-1321에서 카메라 없이 공부하는 방식을 만들었고 화면에는 `카메라 없이`로 적었다.
2026-11-19 사용자 결정으로 두 방식의 이름을 카메라로 측정하는 **관리 모드**와 카메라 없이 스스로 기록하는 **자율 모드**로 정했다.
자율 모드 시간은 공부 시간에는 들어가지만 연속 공부·랭킹·포인트에는 들어가지 않으므로, 기록 탭에서 그날 시간 중 얼마가 어느 모드였는지와 그 규칙을 함께 보여 준다.
정책 원본은 위키 `product/specs/BY-1321-카메라-없는-공부-모드.md`다.

## 구현

- 문구는 카탈로그 값만 바꾸고 키 이름은 유지한다. 플래너 시트는 `timerItem.badge`를 그대로 쓰므로 함께 바뀐다.
- 하루 요약 새 줄은 이미 받는 하루 세션 목록(`GET /api/stats?date=`)의 `source`를 `isTimerSession`으로 나눠 `studySec`를 더한다. 서버는 바꾸지 않는다.
- 직접 입력(`MANUAL`) 기록은 두 모드 어디에도 넣지 않는다. 그래서 두 값의 합이 `총 공부시간`과 다를 수 있다.
- 시간 표기는 기록 탭이 이미 쓰는 길이 포맷을 그대로 쓴다.
- ⓘ는 기존 `InfoTooltip`(탭으로 여닫는 툴팁)을 쓰고, 트리거에 44px 터치 영역과 접근성 이름을 준다.
- 하루 요약은 일간과 주간이 함께 쓰는 컴포넌트라, 새 줄은 선택 prop으로 넘겨 일간에서만 그린다.
- 앱 거부 화면 버튼은 앱 코드라 다음 스토어 배포에 실린다.

## 범위 밖

- 주간·월간 모드별 시간과 서버 응답 변경.
- 머리 영역 큰 숫자 라벨 `순공시간`을 바꾸는 일. 자율 모드 시간도 순공으로 저장되는 기존 결정을 유지한다.
- 백엔드 주석·ADR의 `기본 모드` 표기 정리(다음 백엔드 작업 때 고친다).

## 테스트

- 카탈로그: 4개 언어에 새 키가 있고 값이 비어 있지 않다.
- 하루 요약: 관리·자율 기록이 섞인 날은 두 시간을 나눠 보이고, 자율 모드가 없는 날은 `0분`으로 보이며, 기록이 없는 날은 줄이 없고, 직접 입력은 어느 쪽에도 들어가지 않는다.
- 툴팁: ⓘ를 누르면 설명이 보이고, ⓘ에 접근성 이름이 있다.
- 주간 화면에는 새 줄이 없다.
- 기존 토스트·배지·결과 안내 테스트의 기대 문구를 새 이름으로 바꾼다.

## 추가 범위: 공부 시작 버튼 문구 (2026-11-19)

- 자율 모드 세션도 같은 버튼으로 시작하므로, 공부를 시작하는 버튼은 4개 언어 모두 "공부 시작" 계열(`Start studying`, `勉強を始める`, `開始讀書`)로 맞춘다.
- 랭킹 카드 시작 버튼(`ranking:focusStart.label`)과 옛 홈 시작 버튼(`home:startFocus`)을 바꾼다.
- 기록 탭이 비었을 때 안내(`records:emptyHint`)는 `공부를 시작하면 여기에 쌓여요`로 바꾸고, 온보딩 그림 설명의 버튼 이름도 맞춘다.
- 세션 안내의 `순공 시작하기`는 관리 모드에서만 나오므로 그대로 둔다.
- 랭킹에서 자율 모드로 시작하면 랭킹에 반영되지 않는 동작은 바꾸지 않는다.
