# BY-1199 PC 홈에서 공부 세션: 시작·진행·종료

## 배경

BY-1202로 PC 브라우저 홈(월페이퍼·레일·공부시간 패널)이 생겼지만, `공부 시작`을 누르면 모바일 세션 화면(`/room/1`)이 창 전체로 열려 PC 셸과 월페이퍼가 사라졌다.
PC 첫 출시는 홈과 공부 세션만 내보내기로 했고(2026-11-19), 공부는 홈 화면에서만 한다는 결정(2026-11-09)에 따라 세션을 홈 위로 옮긴다.
결과 모달(BY-1362), 배경음·타이머 플라이아웃(BY-1363), 실수로 떠나기 방지·탭 중복 잠금(BY-1364)은 이 티켓 위에서 따로 한다.
카메라 창 꺼내기(BY-1365)와 최소화 중 측정 유지(BY-1200)는 첫 출시 다음이다.

## 구조

```
PcShell (PC 기기면 폭과 무관, 960 미만이면 덮개)
└─ HomeTabPage → HomeV3Entry (데이터·동작)
   └─ PcHomeContent (월페이퍼 · 레일 · 패널 · 문의)
      └─ PcStudySession (공부 중일 때만, 지연 로딩)
         ├─ useSoloSessionEngine  RoomSessionScreen에서 떼어 낸 로직
         ├─ PcCameraWindow        카메라 작은 창 (관리 모드)
         └─ PcSessionGuide        첫 관리 모드 가이드 4단계
RoomPage → RoomSessionScreen → useSoloSessionEngine (모바일은 그리는 코드 그대로)
```

- `useSoloSessionEngine`은 카메라 어댑터, 비전·기기 감지, 타임랩스, 사용량 카운터, `useStudyRoomSession`, 감지기 시작·정지, 종료 처리를 묶는다.
- 결과로 가기와 홈으로 가기는 함수로 받는다. `RoomPage`는 지금 이동 코드를 넘겨 모바일 동작이 같다.
- `useSessionGate`는 신원 대기, 서버 진행 기록 복원, 처음 과목을 묶어 `RoomPage`와 PC가 함께 쓴다.
- 세션 훅은 마운트되면 세션을 시작하므로, `PcStudySession`이 그려지는 것이 곧 시작이다.

## 시작

1. PC에서 `공부 시작`을 누르면 경로를 바꾸지 않고 `PcStudySession`을 연다.
2. 관리 모드면 카메라 어댑터의 확인 함수로 카메라를 먼저 열어 본다. 첫 방문이면 브라우저 권한 창이 뜬다.
3. 열리지 않으면 세션을 열지 않고 `카메라를 쓸 수 없어요` 토스트와 `자율 모드로 시작` 버튼을 띄운다. 버튼은 측정 모드를 자율로 바꾸고 시작한다.
4. 처음 관리 모드면 가이드 4단계를 띄우고, 끝나면 세션을 재개하고 관리 모드 토스트(`카메라로 자리 비움을 확인해요 · 영상은 어디로도 보내지 않아요`)를 한 번 띄운다.
5. 자율 모드는 카메라 확인과 가이드 없이 바로 시작한다.
6. 관리 모드 첫 시작에 모바일이 여는 세션 가이드 화면(`/session-guide`)은 PC에서 열지 않는다.

## 공부 중

### 공부시간 패널

- 위치·끌기·최소화·기억은 BY-1202 그대로다.
- 진행 띠는 그대로 둔다. 오늘 공부시간·순공시간·집중률은 오늘 기록에 이번 세션 값을 더해 1초마다 바뀐다.
- 아래 버튼은 `일시정지`·`종료`이고, 일시정지 중에는 왼쪽이 `계속하기`다. 공부 시작 분할 버튼은 공부 중에 보이지 않는다.
- 최소화하면 머리줄에 이번 세션이 흐르는 시간이 보인다. 자율 모드는 총 공부시간이다.
- 관리 모드로 공부할 때 머리줄 접기 버튼 왼쪽에 `?`(공부 도움말)가 있다.
- 카메라 창을 숨기면 머리줄에 `카메라 보기` 버튼이 생긴다.
- 과목은 공부 중에도 바꿀 수 있지만 `과목 추가`(플래너로 이동)는 숨긴다. 홈을 떠나면 세션이 끝나기 때문이다.

### 카메라 작은 창 (관리 모드)

- 상자 오른쪽 아래 16:9(288×162)에서 시작하고 끌어서 옮긴다. 패널과 같은 끌기 훅을 쓰고 저장 키만 다르다.
- 5px 넘게 움직이면 끌기, 그보다 적게 움직이고 놓으면 크게 보기다. 크게 보기는 상자 전체를 채우고 다시 누르거나 `작게`로 돌아온다.
- 버튼 줄은 `숨기기`와 `크게/작게`이고, 왼쪽 위에 `타임랩스` 표시가 있다.
- 숨겨도 영상 요소는 화면 밖에 그대로 두어 측정이 계속된다.
- 패널과 겹치면 마지막에 만진 쪽이 위다. 플라이아웃은 둘보다 늘 위다.
- 카메라 화면 요소에는 `amp-block`·`sentry-block`을 붙인다.

### 자율 모드

- 카메라 창 없이 월페이퍼와 패널만 보인다. 측정과 타임랩스는 없다.

### 가이드

| 단계  | 비추는 곳                     | 제목                                 | 본문                                         |
| ----- | ----------------------------- | ------------------------------------ | -------------------------------------------- |
| 1 / 4 | 없음(가운데 카드)             | 포커스메이커스에 오신 걸 환영해요    | 어떻게 사용하는지 같이 알아볼까요?           |
| 2 / 4 | 패널의 오늘 공부시간·순공시간 | 집중하면 순공시간이 흘러가요         | 집중하지 않는 것 같으면 순공시간이 멈춰요    |
| 3 / 4 | 카메라 작은 창                | 카메라 화면은 어디로도 보내지 않아요 | 끌어서 옮기거나, 숨기거나, 크게 볼 수 있어요 |
| 4 / 4 | 일시정지·종료 버튼            | 준비됐어요, 이제 집중해 볼까요?      | 도움말은 패널의 ? 버튼에서 다시 볼 수 있어요 |

- 비출 자리는 그 순간 패널·카메라 창·버튼의 실제 위치를 재서 정한다.
- `나중에 하기`, 끝까지 보기, Esc 중 무엇으로 닫아도 다시 뜨지 않는다. 모바일과 같은 계정별 기기 기록(`focusmakers:session-guide:{userId}`)을 쓴다.
- 「다음」에 포커스가 가고, 닫으면 포커스를 원래 자리로 돌려준다.

### 좁은 창 덮개

- PC 기기에서 창 폭이 960px보다 좁으면 상자 위에 `창을 조금 더 넓혀 주세요`를 덮는다. 세션은 뒤에서 계속되고, 넓히면 덮개만 사라진다.

### 그 밖

- 공부 중에는 `문의` 버튼을 숨긴다.
- 공부 중 카메라를 잃으면 지금처럼 `카메라가 꺼져 있어요`가 뜨고 세션은 계속된다.
- 다른 탭으로 옮겨도 관리 모드는 일시정지하지 않는다. 실제 Chrome에서 숨은 탭도 카메라 프레임이 계속 바뀌고 1초 캡처가 약 2초 간격으로 돌아(7분 동안 1분 간격으로 늦춰지지 않음) 측정이 이어지기 때문이다. 숨는 순간 진행 기록을 keepalive로 한 번 보내고, 카메라가 재고 있으니 2시간 상한은 걸지 않는다. 돌아오면 지금처럼 카메라를 다시 확인한다. 자율 모드는 휴대폰과 같이 숨은 시간을 2시간까지 공부로 센다. 휴대폰 앱과 휴대폰 브라우저의 관리 모드는 지금처럼 `BACKGROUND`로 일시정지한다.

## 새로고침 이어 가기

- 이 탭에서 세션을 열면 `sessionStorage`에 표시를 남기고, 세션이 끝나면 지운다.
- 새로고침 뒤 PC 홈에 표시가 있으면 `useSessionGate`로 서버 진행 기록을 받아 그 기록에서 세션을 다시 연다.
- 표시가 없으면 서버에 진행 기록이 있어도 열지 않는다. 다른 기기의 세션을 잘못 이어 가지 않기 위해서이고, 그 안내는 BY-1353에서 한다.
- 서버 기록이 이미 확정돼 없으면 표시를 지우고 홈으로 둔다.

## 종료

- `종료`를 누르면 기존 종료 확인 창이 뜨고, 확인하면 제출한다.
- 제출이 끝나면 지금 결과 화면(`/room/1/result`)으로 결과를 넘겨 이동한다.
- 1분 미만이라 기록되지 않는 경우와 자동 종료는 모바일과 같은 안내를 상자 안 가운데 창으로 보여 주고, 확인하면 홈 상태로 돌아온다.
- 제출 실패는 상자 안 가운데 창에 `다시 시도`를 보여 준다.

## 오류 처리

- 카메라 확인 실패는 위 시작 3번을 따르고, 사유는 지금처럼 `reportHandled`로 종류만 남긴다.
- 진행 기록 보고 실패와 비전 모델 로딩 실패는 지금 엔진 동작 그대로다.
