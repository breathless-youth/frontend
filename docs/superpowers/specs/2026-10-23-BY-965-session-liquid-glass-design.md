# BY-965 싱글룸 세션 화면에 iOS 26 Liquid Glass 적용 설계

## 배경

BY-957은 세션 밖 화면의 위쪽 고정 줄과 본문 컨트롤을 iOS 26 Liquid Glass로 바꿨고, 세션 화면은 카메라·WebRTC·회전을 따로 확인해야 해서 범위에서 뺐다. 구조와 근거는 [ADR 0018](../../adr/0018-native-glass-chrome-over-webview.md)에 있다.

코드를 조사해 확인한 사실은 다음과 같다.

- 싱글룸(`RoomPage`)과 라이브룸(`LiveRoomSession`)은 모두 문서가 스크롤되지 않는 전체 화면이다(`h-svh overflow-hidden`, `h-dvh overflow-hidden`).
- 그래서 BY-957의 그 자리 부품 방식(`useNativeControl`)을 쓰면 `absolute`로 놓인 버튼도 자리가 맞는다.
- 두 화면 모두 위쪽 뒤로·닫기 버튼이 없어서 BY-957의 위쪽 고정 줄은 쓸 곳이 없다.
- 시트·대화상자(배경음 페이지, 과목 페이지, 종료 확인) 안 컨트롤은 모달이 열리면 네이티브 부품을 모두 숨기는 구조라 이 방식으로 바꿀 수 없고, BY-967에서 다룬다.
- 세션 루트는 `theme-dark`라 항상 다크인데, 네이티브 부품의 색은 시스템 테마를 따른다.
- BY-957의 네이티브 버튼은 색 역할이 없고 원형 버튼 아이콘이 12pt로 고정이라 세션의 23px 아이콘과 상태 색을 표현하지 못한다.

## 결정

사용자 결정으로 정한 것은 다음과 같다.

| 항목       | 결정                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| 적용 범위  | 싱글룸만 바꾼다. 라이브룸 하단 조작 바는 화면 탭으로 미끄러져 숨는 애니메이션이 있어 지금 웹 모양(CSS 흐림)을 유지한다 |
| 버튼 색    | 지금 웹 색을 그대로 쓴다. 다시 시작은 파란 채움, 종료는 빨간 아이콘, 켜진 배경음·과목은 강조색 아이콘이다              |
| 간단 모드  | 지금처럼 0.2초 동안 흐려지며 사라지고 다시 나타난다. 숨은 동안에는 눌리지 않는다                                       |
| 아이콘     | iOS 시스템 아이콘(SF Symbols)을 쓴다. Android·브라우저와 아이콘 모양이 달라지는 것을 받아들인다                        |
| 애니메이션 | 일시정지↔재생은 아이콘 교체 효과, 카메라 전환은 아이콘 회전 효과로 대신한다. 누름 반응은 glass 버튼 기본 효과가 맡는다 |

### 대상 버튼

| 버튼               | 웹 컴포넌트          | 아이콘(SF Symbol)                    | 색 역할                         | 간단 모드 |
| ------------------ | -------------------- | ------------------------------------ | ------------------------------- | --------- |
| 카메라 전환        | `SessionSideActions` | `arrow.triangle.2.circlepath.camera` | 기본                            | 숨김      |
| 배경음             | `AmbientSoundButton` | `music.note`                         | 기본, 켜지면 켜짐               | 숨김      |
| 과목               | `RoomPage` 과목 버튼 | `book`                               | 기본, 고른 과목이 있으면 켜짐   | 숨김      |
| 일시정지·다시 시작 | `SessionPauseButton` | `pause.fill`, `play.fill`            | 기본, 일시정지 중이면 강조 채움 | 보임      |
| 종료               | `SessionExitButton`  | `rectangle.portrait.and.arrow.right` | 위험                            | 숨김      |

상태 표시 필, 과목 라벨, 타이머는 누를 수 없거나 흐름 배치라 웹으로 남긴다.

### 앱에 더하는 것

- 버튼 부품에 선택 필드 `tone`을 더한다. 값은 `default`, `prominent`, `danger`, `active`이고 없으면 `default`다.
  - `prominent`는 세션 강조색(`--session-control-resume-bg`)으로 채운 glass, `danger`는 위험색 아이콘, `active`는 강조색(`--state-focus`) 아이콘이다.
  - 색 값은 BY-957처럼 호스트의 팔레트 상수로 넘기고 Swift에 색을 직접 적지 않는다.
- 버튼 부품에 선택 필드 `iconSize`(pt)를 더한다. 웹은 등장 효과가 렌더 상자를 키우고 줄이므로 변형과 무관한 아이콘의 계산된 CSS 폭을 측정해 넣는다. 없으면 지금 크기를 유지한다.
- 버튼 부품에 선택 필드 `turns`를 더한다. 값이 커질 때마다 Swift가 아이콘 회전 효과를 한 번 재생한다. 카메라 전환이 웹의 `flipTurns`를 그대로 넘긴다.
- `systemImage`가 바뀌면 Swift가 아이콘 교체 효과로 바꾼다.
- 부품 공통 선택 필드 `faded`를 더한다. 참이면 Swift가 0.2초 동안 투명도를 0으로 낮추고 누름을 받지 않는다. 동작 줄이기를 켠 사용자에게는 효과 없이 바로 바뀐다.
- `set-inline-controls`에 선택 필드 `colorScheme`을 더한다. `dark`면 그 웹뷰의 본문 부품 층 전체를 다크로 그린다. 세션 화면이 `dark`를 보낸다.
- 앱은 이 필드들을 그릴 수 있을 때 URL의 `glassControls` 목록에 `button-style` 표시를 더한다. 웹은 이 표시가 있을 때만 세션 버튼을 앱에 맡기고, 없으면 지금 웹 버튼을 그린다.
- 파서는 새 필드의 형식을 BY-957 규칙대로 검사하고 틀리면 메시지 전체를 버린다. 웹도 같은 상수로 먼저 거른다.

### 동작

- 세션 화면은 스크롤되지 않으므로 BY-957의 문서 좌표 그대로 자리가 맞는다.
- 회전 뒤에는 기존 `resize` 처리가 위치를 다시 측정해 보낸다. 회전 중 잠깐 어긋나는지는 실기기에서 확인한다.
- 버튼을 누르면 지금 웹 `onClick`이 그대로 불려서 햅틱과 일시정지·종료 흐름은 바뀌지 않는다.
- 배경음·과목 페이지가 열리면 기존 모달 감지가 네이티브 부품을 숨기고, 닫히면 다시 보인다.
- 전체 화면 간단 모드 전환 버튼은 네이티브 버튼 바깥을 누를 때 기존처럼 웹이 받는다.
- Android, iOS 26 미만, 구버전 앱, 브라우저는 지금 화면과 같다.

### 실기기 검토 뒤 바뀐 것

- 카메라 전환·종료·배경음·과목의 SF Symbol이 원을 꽉 채워 보여서, 웹이 측정 폭에 비율(`iconScale`)을 곱해 보낸다. 카메라 전환은 0.7배, 나머지 셋은 0.82배이고 일시정지는 그대로다.
- 하단 일시정지·종료 버튼은 웹 버튼까지 한 단계 키웠다. 지름은 54/64/80px에서 60/72/88px로, 아이콘은 23/27/34px에서 26/30/38px로 바뀌었다.
- 상단 상태 필은 네이티브로 바꾸지 않기로 했다.

## 첫 실험 (4-0)

- 가설: 네이티브 glass 버튼을 웹뷰 안 재생 중인 `<video>` 위에 올리면 영상이 glass를 통해 비쳐 보인다.
- 실험: iOS 26 시뮬레이터에서 영상이 재생되는 시험 페이지 위에 BY-957 버튼 부품을 붙여 캡처한다. 실기기 카메라 화면은 구현 뒤 확인한다.
- 판정: 영상이 비치면 구현을 계속한다. 회색 판이나 검정으로 보이면 구현을 멈추고 결과를 보고한다.

## 테스트

- 웹
  - 싱글룸 버튼 5개가 앱 모드(`button-style` 표시 있음)에서 웹 원본을 숨기고 올바른 `tone`, `systemImage`, `faded`, `turns`로 등록된다.
  - 일시정지 상태가 바뀌면 `systemImage`와 `tone`이 바뀌고, 간단 모드에서는 일시정지를 뺀 버튼이 `faded`가 된다.
  - `button-style` 표시가 없으면 웹 버튼이 그대로 보인다.
  - 앱 부품 누름이 기존 핸들러(일시정지, 다시 시작, 종료 요청, 페이지 열기, 카메라 전환)를 부른다.
  - 세션 화면이 `colorScheme: "dark"`를 보낸다.
- 모바일
  - 파서가 새 필드를 받고, 틀린 값이면 메시지를 버린다.
  - `SUPPORTED_INLINE_KINDS`에 맞춰 `button-style` 표시가 URL에 붙는다.
- Swift는 빌드 성공과 시뮬레이터 라이트·다크 캡처로 확인한다.

## 범위 밖

- 라이브룸 하단 조작 바는 바꾸지 않는다.
- 시트·대화상자 안 컨트롤은 BY-967에서 다룬다.
- 과목 라벨, 상태 표시 필, 타이머는 웹으로 남긴다.
