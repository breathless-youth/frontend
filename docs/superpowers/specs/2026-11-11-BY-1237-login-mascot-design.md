# BY-1237 로그인 화면 마스코트 시안 적용

- 티켓: BY-1237 (상위 BY-1145)
- 시안: Figma V3 `nmpEKUAgMwMtLdxIIXGFUB` 노드 `10168:783` (라이트 `10174:1321`, 다크 `10177:829`)

## 목표

로그인 화면이 비어 보이는 문제를 마스코트 시안으로 고친다.
로그인 화면을 본 사람 중 로그인에 성공한 비율을 버튼 누름·취소까지 나눠 볼 수 있게 계측을 보탠다.

## 결정

| 항목            | 결정                                                                                                              |
| --------------- | ----------------------------------------------------------------------------------------------------------------- |
| 마스코트 자산   | Figma 컴포넌트 기본 상태 5개를 SVG로 내보내 `<img>`로 겹쳐 그린다. 기울기는 SVG에 들어 있다                       |
| 로고            | 이미지(`splash-logo`)를 `<h1>` 텍스트로 바꾼다. 색은 `text-primary`(soft-blue 테마). 시안 값과 다름을 PR에 적는다 |
| 배경            | `theme-soft-blue bg-soft-blue`. 그룹 탭 다른 화면과 같다                                                          |
| 다크 Apple 버튼 | 흰 바탕·검은 글자·검은 로고                                                                                       |
| 기록 안내 상자  | 삭제. 문구 네 언어, 공부한 날 조회, 테스트 3개도 함께 삭제                                                        |
| 모션            | 넣지 않는다                                                                                                       |
| 계측            | `social_login_tapped {provider}`, `social_login_cancelled {provider}` 추가                                        |

## 구조

- 마스코트 층은 `aria-hidden`, `pointer-events-none`이고 버튼 층보다 아래다.
- 스톱워치·연필·플래너는 로고 영역 기준, 책·램프는 화면 바닥 모서리 기준으로 배치한다.
- `<main>`에 `overflow-hidden`을 걸어 화면 밖으로 나간 마스코트가 가로 스크롤을 만들지 않게 한다.
- 뒤로 가기 헤더, 버튼 동작, 동의 문구 링크는 그대로다.

## 계측

- `social_login_tapped`는 `login()`에서 진행 중 가드를 통과한 뒤 남긴다. 겹쳐 누른 건 세지 않는다.
- `social_login_cancelled`는 앱 응답이 `cancelled`일 때 남긴다.

## 테스트

- 버튼을 누르면 `social_login_tapped`가 그 공급자로 한 번 남는다.
- 앱이 취소로 답하면 `social_login_cancelled`가 남는다.
- `포커스 메이커스` heading이 보인다.
- 마스코트는 접근성 트리에 나오지 않는다.
- 기록 안내 테스트 3개는 삭제한다.

## 범위 밖

- PC 넓은 화면 전용 배치. `page-column` 열 안에서 같은 배치를 쓴다.
- 로고 색 토큰 추가. Figma 변수가 생긴 뒤 별도 작업으로 한다.
