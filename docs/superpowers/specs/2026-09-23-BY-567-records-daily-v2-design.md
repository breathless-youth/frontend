# BY-567 일간 탭 V2 화면 설계

작성 2026-09-23. 대상 티켓 BY-567(일간 탭 화면 구현). 상위 BY-556, 선행 BY-735.

## 목표

기록 탭을 Figma V2 시안의 일간 뷰로 바꾼다. 한 달 순공시간과 지난달 대비 증감을 위에서 보고, 달력에서 날짜별 공부량을 농도와 시간 라벨로 훑고, 그 아래 선택한 날의 세션 목록을 본다.

시안은 Figma V2 `YcyImcuVORDbBneii41Byh`의 라이트 `5303:3981`·`5303:4513`·`5303:4937`과 다크 `5354:3779`이다.

## 범위

### 이 티켓에서 하는 것

- 헤더의 `일간`·`주간` 세그먼트와 월 이동 컨트롤
- 월 순공시간 합계와 지난달 대비 증감 줄
- 월 달력을 농도 3단계와 시간 라벨로 다시 그리기
- 선택일 제목과 세션 목록
- V2 소프트블루 리스킨 적용과 달력 농도 토큰 추가

### 이 티켓에서 안 하는 것

| 항목                                                        | 담당   |
| ----------------------------------------------------------- | ------ |
| 날짜 상세 카드(순공·총공부·집중률·과목별·24시간 타임테이블) | BY-568 |
| 세션 바텀시트, 과목 색 토큰                                 | BY-568 |
| 주간 뷰 내용과 세그먼트 활성화                              | BY-566 |

## 화면 구조

위에서 아래로 이렇게 쌓는다.

```
main.theme-soft-blue.bg-soft-blue
├─ 제목 "기록" + [일간 | 주간] 세그먼트 (주간은 비활성)
├─ 월 이동: ‹  2026년 9월  ›
├─ 월 요약: "9월 순공시간" / 34시간 48분 / ▲ 지난달보다 6시간 늘었어요
├─ 월 달력 카드 (농도 3단계 + 시간 라벨 + 범례)
├─ 선택일 제목 "9월 18일 금요일"
│   └─ (날짜 상세 카드 자리 — BY-568이 채운다)
└─ 세션 목록 카드  또는  "이 날은 기록이 없어요"
```

## 데이터 흐름

| 영역                | 출처                                      | 상태      |
| ------------------- | ----------------------------------------- | --------- |
| 월 요약 합계·증감   | `GET /api/stats/period`로 그 달과 직전 달 | 신규 연동 |
| 달력 농도·시간 라벨 | 같은 `period` 응답의 `dailyList`          | 신규 연동 |
| 세션 목록           | 기존 `dailyStatsQuery(선택일)`            | 이미 있음 |

핵심 전환은 달력의 데이터 출처다. 지금 달력은 일별 응답의 `studiedDatesInMonth`로 도트만 찍는데, V2는 날짜별 순공시간이 필요해 `period` 조회로 바꾼다. 도트 자리를 농도와 시간이 대신한다.

`period` 조회 범위는 보이는 달의 1일부터 말일까지, 비교 범위는 직전 달이다. `recordsPeriod.ts`의 `monthRanges`가 이미 이 범위를 만든다.

## 순수 함수

`recordsFormat.ts`와 `recordsPeriod.ts`에 둔다. 컴포넌트는 그리기만 한다.

- `heatLevel(focusSec)`는 `"none"`·`"low"`·`"mid"`·`"high"`를 준다. 경계는 0, 1시간 미만, 1시간 이상 3시간 미만, 3시간 이상이다.
- 월 합계와 증감은 이미 있는 `sumFocusSec`와 `focusDeltaSec`를 그대로 쓴다.
- `dailyList`를 `Map<날짜키, focusSec>`로 바꾸는 헬퍼를 더한다. 달력이 날짜별 순공시간을 O(1)로 찾는다.
- 시간 라벨은 `2:30` 형태다. 시:분이고 분은 두 자리, 시는 앞자리 0을 빼며, 1시간 미만도 `0:42`처럼 시를 0으로 적는다.

## 디자인 토큰

페이지 루트에 `.theme-soft-blue`와 `.bg-soft-blue`를 붙여 V2 소프트블루 리스킨을 상속받는다. 이러면 `--primary`·`--foreground`·`--border`·`--muted` 같은 시맨틱 변수가 이 서브트리에서만 V2 값으로 바뀌고, 화면 코드는 기존 시맨틱 클래스를 그대로 쓴다. BY-717 설정 화면과 소셜 화면이 이미 이 방식이다.

달력 농도와 증가 성공색은 이 리스킨에 없어 새 토큰을 더한다. 값은 Figma V2 변수의 라이트와 다크를 그대로 옮긴다. `index.css`의 `.theme-soft-blue` 라이트 블록, `@media (prefers-color-scheme: dark)` 다크 블록, `:root[data-theme="dark"]` 다크 블록에 넣고, `@theme inline`에 매핑해 유틸리티 클래스를 만든다.

| 토큰                 | 라이트    | 다크      |
| -------------------- | --------- | --------- |
| `--chart-heat-low`   | `#dbe7fb` | `#24344f` |
| `--chart-heat-mid`   | `#a9c6f5` | `#35558a` |
| `--chart-heat-high`  | `#6f9ff0` | `#4f86e4` |
| `--chart-empty`      | `#eef1f6` | `#1e2636` |
| `--feedback-success` | `#0e9f5d` | `#32d583` |

증감이 줄었을 때는 새 토큰 없이 기존 `text-muted-foreground`를 쓴다. 과목 색 토큰은 BY-568이 더한다.

## 상태와 접근성

- 주간·월간 모드와 선택일은 컴포넌트 state다. 딥링크 요구가 없고 search param으로 두면 허용 목록과 분석 노출까지 끌려온다.
- 달 이동은 선택일을 건드리지 않는다. 다른 달로 갔다 돌아오면 이전 선택이 그대로 남는다.
- 달력 칸은 44px 터치 영역을 지키고, 칸마다 날짜와 순공시간을 읽어주는 `aria-label`을 붙인다. 농도만으로 뜻을 전하지 않는다.
- 증감 화살표는 색과 함께 텍스트로도 늘고 줆을 밝힌다.
- 월 이동 모션은 기존 `MonthCalendar`의 슬라이드를 그대로 두고 `motion-reduce:animate-none`을 지킨다.

## 오류와 빈 상태

- 세션이 없는 날은 세션 카드 안에 `이 날은 기록이 없어요`를 가운데 정렬로 보여준다.
- `period` 조회가 실패해도 화면을 막지 않는다. 합계·증감은 비우고 달력은 농도 없이 날짜만 그린다. 포커스 재조회가 복구 경로다.
- 선택일 세션 조회 실패는 기존 `ErrorState`가 대표한다.

## 검증

- 순수 함수는 vitest로 `heatLevel` 경계값, 시간 라벨 형식, 날짜별 순공시간 맵을 단언한다.
- 화면은 402px 브라우저에서 라이트와 다크 두 모드로 확인하고 스크린샷을 남긴다.
- `pnpm lint`, `pnpm typecheck`, `pnpm --filter web test`가 통과한다.
- 접근성은 `accessibility-audit`로 44px 터치 타겟, `aria-label`, 대비를 점검한다.
