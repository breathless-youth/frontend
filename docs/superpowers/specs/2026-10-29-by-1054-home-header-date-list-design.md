## 범위

홈 탭(`HomeTabPage`)을 날짜별 과목 목록 화면으로 바꾼다. 과목 카드 조작(할 일 펼침·스와이프·☰ 메뉴 내용)은 BY-1055, 고른 과목으로 세션 시작은 BY-1056, 손잡이 플래너는 BY-1057, 탭 바 재생 버튼은 BY-1058이 맡는다.

## BY-1053 전까지의 한계

지난 날짜에도 지금 있는 과목이 전부(그날 기록이 없으면 0분) 보이고, 그날 공부했다가 지금은 삭제한 과목이 그 뒤에 붙는다. 지금 플래너와 같은 동작이고, BY-1053의 날짜 기준 과목 목록이 들어오면 "그날 있던 과목"으로 바꾼다. 과목 완료 표시는 BY-1055에서 붙인다.

## 분석 이벤트

| `home_date_selected` (신규)       | `days_ago`                | 날짜 줄에서 다른 날을 눌렀을 때 |

| `focus_start_tapped` (기존)       | `source: "home_fallback"` | `순공 시작` 버튼                |

## 테스트 계획

- `homeDateStrip` 순수 함수: 오늘 기준 30일 키 목록, 오늘이 마지막, 날짜 라벨 `N일 (요일)`.
- 과목 0개 판정 순수 함수: 기록 없음 → 환영, 기록 있음 → 빈 화면, 1개 이상 → 목록이며 기록을 남긴다. userId별로 나뉜다.
- `HomeTabPage` 렌더 테스트(기존 921줄 파일을 새 구성에 맞게 다시 쓴다):
  - 오늘 화면에 날짜 제목·D-Day·순공과 과목 줄(재생 버튼)이 보인다.
  - 순공을 누르면 총 공부가 보이고 3초 뒤 순공으로 돌아온다(가짜 타이머).
  - 날짜 줄에서 지난 날을 누르면 제목이 바뀌고 과목 줄이 색 막대로 바뀐다.
  - 날짜 줄에 미래 날짜가 없고 30일까지만 있다.
  - `tabBarPlay=1`이 없으면 `순공 시작`이 보이고, 있으면 보이지 않는다.
  - 환영 화면과 빈 화면이 조건대로 갈린다. 시트에서 과목을 만들면 목록에 생긴다.
  - 지운 카드(연속 공부·통계·초대·최근 타임랩스·홈 플래너 버튼)가 없다.
  - 팝업 순서 테스트는 유지한다.
- `RecordsPage` 테스트: 타임랩스 버튼과 플래너 버튼이 보이고 각각 해당 경로를 연다.
- 웹 뷰포트 확인: 라이트·다크 스크린샷, reduced-motion, 44px 터치 영역, aria 이름.
