# BY-728 공부 종료 화면 V2 UI 적용

작성일: 2026-09-22

## 배경

V2 디자인 시안이 Figma V2 파일(`YcyImcuVORDbBneii41Byh`)에 올라오면서 공부 종료 화면이 Soft
Blue 시각 언어로 다시 그려졌다. 화면 구조 자체는 BY-560에서 이미 도장 히어로, 타임라인 카드,
누적 요약 카드, 2단 CTA로 바꿔 뒀다. 이번에 남은 것은 색과 배경, 그림자를 V2 팔레트로 맞추고,
히어로의 크기·문구·필을 시안 값에 맞추며, 순공시간 카운트업이 0에서 시작해 `1분 미만`이 잠깐
뜨던 것을 1분부터 오르게 고치는 일이다.

시안은 `S4-1 · 공부 종료 (Soft Blue)` 섹션이고 라이트와 다크 각각 Step1(도장 + 요약),
Step2(도장 + 타임라인 + 누적) 두 프레임이다. 시안은 아직 완성본이 아니다.

## 범위

대상은 공부 종료 화면 `ResultPage` 하나다. 솔로 `/room/:id/result`와 소셜
`/social/room/:roomId/result`가 같은 컴포넌트를 쓰므로 두 진입 모두 함께 바뀐다.

### 히어로는 시안 값에 맞춘다

처음에는 색만 리스킨하고 BY-560 문구·크기를 유지할 계획이었으나, 작업 중 히어로를 시안과
똑같이 맞추기로 방향을 바꿨다. 크기, 필 스타일, 문구를 시안 값으로 옮긴다.

문구 두 개만 예외로 유지한다. `순공시간`은 glossary 노출 표기가 SSOT라 붙여 쓰고, `총 공부시간`은
2026-09-14 사용자 결정이라 그대로 둔다. 시안의 `순공 시간`·`총 공부` 띄어쓰기는 따르지 않는다.

아래는 시안대로 바꾼다.

- 타이틀 `오늘 공부 완료!` → `오늘 공부 완료`
- 설명 `끝까지 해낸 시간이 그대로 기록됐어요` → `끝까지 해내셨네요!`
- 인장 크기 100px → 72px
- 타이틀 24px → 20px, 순공 숫자 44px → 40px, 순공 라벨 13px Medium → 12px Bold, 총 공부 줄 13px → 14px
- 집중률 필의 체크 아이콘을 없앤다. 시안 필은 텍스트만 있다.
- 집중률 필을 흰 배경 그림자에서 옅은 브랜드색 배경으로 바꾼다.

아래는 시안이 달라도 유지한다.

- 타임라인 범례 첫 항목 `순공`
- 최장 구간 라벨 `최고 집중 시간`과 바 위 배지
- 도장 프레스 인트로 연출과 색종이

### 건드리지 않는 것

- `index.css`는 수정하지 않는다. Soft Blue 토큰은 BY-716과 BY-717이 이미 넣어 뒀고 이 작업은
  소비만 한다.
- 자동 종료 안내와 세션 복구 모달은 BY-722 범위다. 같은 `Card` 프리미티브를 쓰지만 이 작업이
  건드리지 않는다.

## 설계

### 팔레트 스코프

`ResultPage`의 `<main>`에서 `bg-background`를 빼고 `theme-soft-blue bg-soft-blue`를 건다. 이
한 줄로 그 아래 `text-foreground`, `text-muted-foreground`, `bg-muted`, `border-border`,
`text-primary`가 전부 V2 값을 가리킨다. BY-716의 소셜 홈, BY-717의 설정과 프로필 수정이 같은
방식을 쓴다.

다크는 `.theme-soft-blue`와 `.bg-soft-blue`의 모드별 재정의가 처리한다. 다크용 코드를 따로
쓰지 않고 `dark:` 변형도 쓰지 않는다.

### 카드 안 `bg-background`를 `bg-muted`로 바꾼다

`.theme-soft-blue`는 `--background`를 재정의하지 않는다. 지금 타임라인 카드의 최고 집중 조각
바탕과 말꼬리가 `bg-background`라서, 배경이 그라디언트로 바뀌면 카드 안에서 카드색과
어긋난다. 라이트에서는 둘 다 흰색이라 드러나지 않지만 다크에서는 카드가 `#1b2333`, 배경이
`#10151f`라 눈에 띈다.

다음 세 곳을 `bg-muted`로 바꾼다.

- 타임라인 바의 최고 집중 조각 바탕
- 최고 집중 배지의 말꼬리
- `Badge` 프리미티브의 기본 배경

`Badge`는 히어로 집중률 배지와 타임라인 최고 집중 배지가 전 사용처라 프리미티브에서 바꿔도
다른 화면으로 번지지 않는다.

### 인장 색

`SealIcon`의 `text-stamp-seal`을 `text-primary`로, 충격 링의 `border-stamp-seal/30`을
`border-primary/30`으로 바꾼다.

도장 PNG는 그대로 둔다. 주황 도장 도구에 파란 인장이 남는 조합이 되는데, 지금도 주황 도장에
빨간 인장이라 색이 같은 적이 없었다. 도장은 소품이고 인주만 브랜드색이라는 해석이다.

`--stamp-seal` 토큰은 쓰는 곳이 이 화면뿐이라 미사용으로 남는다. `index.css`를 건드리지 않는
범위라 지우지 않고 PR 본문에 적는다.

### 그림자

타임라인 카드와 요약 카드의 호출부에 `shadow-sb-card`를 준다. `Card` 프리미티브에 넣지
않는다. 같은 프리미티브를 BY-722 대상인 자동 종료 안내와 복구 모달도 쓰고 있어서, 프리미티브에
넣으면 범위 밖 화면이 같이 바뀐다.

기록으로 가기 CTA의 손으로 적은 그림자 값을 `shadow-sb-cta`로 바꾼다.

### 아이콘

집중률 필의 손으로 그린 체크 SVG는 시안에 필 안 체크가 없어 통째로 없앤다. lucide `Check`로
바꾸지 않는다.

인장의 발바닥은 손으로 그린 SVG를 그대로 둔다. lucide `PawPrint`는 발가락 패드가 셋이고 한쪽으로
기울어진 발자국이라 발가락 넷 대칭인 시안과 어긋난다. 아이콘 출처를 통일하는 것보다 시안 모양을
따르는 편이 낫다.

상태 도트와 타임라인 바 세그먼트는 shadcn에 대응 프리미티브가 없어 그대로 둔다.

### 집중률 필 대비

집중률 필은 시안대로 옅은 브랜드색 배경(`bg-brand-subtle`)에 브랜드색 글자(`text-primary`)다.
이 조합은 홈 필, 에러 버튼 등 앱 곳곳이 쓰는 확립된 패턴이다. `.theme-soft-blue` 값으로 계산하면
글자 대비가 라이트 4.07대 1, 다크 4.498대 1로 일반 텍스트 AA 기준 4.5대 1에 라이트와 다크 모두
근소하게 못 미친다.

색값은 BY-717이 소유한 `index.css` 토큰이고 이 티켓 범위 밖이다. 필 하나만 다른 색을 쓰면
시안·앱 공통 패턴에서 벗어나므로, 시안대로 두고 이 사실을 PR의 디자인 확인 필요 목록에 적어
토큰 조정은 별도 작업으로 넘긴다.

## 테스트

리스킨은 대체로 색·클래스 교체라 기존 `ResultPage.test.tsx` 통과로 회귀를 잡는다. 기존 테스트가
클래스 문자열을 단언하지 않는지 먼저 확인한다.

카운트업 시작값을 0에서 1분으로 바꾼 것은 색이 아니라 동작 변경이라 테스트를 하나 더한다.
인트로 단계에서 시작 프레임이 `1분`이고 `1분 미만`이 아님을 단언한다. 시작값이 0이면 실패하는
회귀 가드다.

## 완료 조건

- 화면이 라이트와 다크에서 시안과 같은 색, 배경, 그림자로 보인다.
- 히어로 크기·문구가 시안 값과 같다. 집중률 필에 체크 아이콘이 없다.
- 인장 발바닥은 손으로 그린 SVG를 유지한다.
- 순공시간, 총 공부시간, 집중률, 누적 두 행의 값이 지금과 같게 나온다.
- 카운트업이 0이 아니라 1분부터 올라 `1분 미만`이 뜨지 않는다.
- 누를 수 있는 요소가 모두 44px 이상이다.
- 모션 축소 환경에서 인트로 연출과 색종이가 빠진다.
- 글자 대비가 WCAG AA를 넘는다. 집중률 필만 예외로 시안·앱 공통 토큰 조합이라 라이트 4.07대 1, 다크 4.498대 1이고, 디자인 확인 필요로 넘긴다.
- 라이트와 다크 화면을 인트로와 펼침 각각 브라우저에서 직접 확인한다.
- `ResultPage.test.tsx`, `sessionResult.test.ts`, `resultCopy.test.ts`가 통과한다.
