## BE 확인 항목 (BY-408 코멘트 게시됨)

재-join 멱등 / SNAPSHOT 내 본인 포함 여부 / 발행 페이로드 userId 미포함 가정 / 재연결 시
SNAPSHOT 재전송 / 순수 WebSocket(SockJS 아님). FE는 어느 쪽이든 동작하게 방어했다
(내 타일 로컬 값 우선, 미지 userId 무시).
