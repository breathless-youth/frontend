# BY-990 타이머·뽀모도로 진입 버튼 통합 설계

상위 BY-989. 후속 BY-991(가로 배치)·BY-993(소셜룸 타이머 버튼)이 이 페이지를 기준으로 한다.

## 목표

싱글룸 오른쪽 버튼 열의 타이머·뽀모도로 버튼 두 개를 타이머 버튼 하나로 합치고,
모드 화면 안의 `기본`/`뽀모도로` 토글로 두 모드를 오간다.

## 결정 (사용자 부재로 권장안 적용, 2026-10-26)

| 항목                    | 결정                                                                                                                  | 이유                                                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 진행 중 토글            | 모드가 `running`·`paused`이면 고르지 않은 칸을 비활성으로 둔다. 지금 칸은 또렷하게 남긴다. `setup`에서만 바꿀 수 있다 | 끄는 길(✕)과 처음부터 버튼이 이미 있다. 확인 다이얼로그를 더하면 모달 위 모달이 되고 휴식 신호 정리 경로가 하나 더 생긴다     |
| 토글 위치               | 머리 줄(✕ · 제목) 아래, 본문 열 맨 위                                                                                 | 제목은 `타이머` 하나로 고정해 시트 이름이 모드에 따라 바뀌지 않게 한다                                                        |
| 토글 모양               | 기록 탭 `SegmentedControl`(알약 세그먼트)을 재사용하되 웹으로만 그린다                                                | 같은 역할에 다른 룩을 만들지 않는다. 앱 glass 세그먼트는 밀려 들어오는 모달 시트 안에서 검증된 적이 없어 이번에는 쓰지 않는다 |
| 토글 이름               | `기본` / `뽀모도로`, 목록 이름 `타이머 종류`                                                                          | 티켓 문구 그대로                                                                                                              |
| 마지막 모드 기억        | 토글로 고른 모드를 localStorage 별도 키에 저장하고, 버튼으로 열 때 그 모드로 연다. 값이 없거나 깨졌으면 `기본`        | 설정 키(`focuson.multiTimer.v1`)는 저장 때 알려진 필드만 다시 써서 같은 객체에 넣으면 지워진다                                |
| 진입 버튼               | `타이머` 하나. 아이콘은 Figma V2 `icon/timer`(7000:23773). 앱 glass는 SF Symbol `timer` 그대로                        | 사용자 지시. iOS glass는 달라도 된다                                                                                          |
| 닫은 뒤 포커스          | 항상 타이머 버튼                                                                                                      | 버튼이 하나뿐이다                                                                                                             |
| 뽀모도로 아이콘·앱 그림 | 웹 `PomodoroIcon`은 쓰는 곳이 없어지면 지운다. 앱 `pomodoro*.png` 자산은 네이티브 빌드가 걸려 이번에 건드리지 않는다  | 후속 정리 후보로 남긴다                                                                                                       |
| 분석 이벤트             | 새로 만들지 않는다                                                                                                    | 기존 모드 화면에도 이벤트가 없다                                                                                              |

## 실기기 검증 뒤 추가 결정 (사용자 지시, 2026-10-26)

| 항목               | 결정                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | 이유                                                                                                                                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 남은 시간 숫자     | 세션 순공시간의 휴대폰 값(52px, bold, 자간 -0.5px, 줄높이 60px)으로 맞춘다. 태블릿 확대는 따르지 않는다. 설정 휠 숫자는 아래 설정 휠 항목을 따른다                                                                                                                                                                                                                                                                                                                                              | 시트 본문은 태블릿에서도 휴대폰 폭이라 96px이면 넘친다. 휠 숫자는 칸 높이에 묶여 있다                                                                                                                                       |
| 알림음             | 두 음을 한 번만 울리고 음량을 0.25에서 0.6으로 올린다                                                                                                                                                                                                                                                                                                                                                                                                                                           | 한 번 짧게 울려 자각하기 어려웠는데, 되풀이하면 길게 끌려 소리를 키우는 쪽을 골랐다                                                                                                                                         |
| 알림음 스위치      | 종 아이콘 + 스위치를 뽀모도로는 다이얼 오른쪽 아래, 기본 타이머는 휠 높이 영역의 오른쪽 아래에 둔다. 기본은 켜짐이고 고른 값을 기억한다. 꺼도 진동은 울린다                                                                                                                                                                                                                                                                                                                                     | 조용한 곳에서 소리만 끌 수 있게 한다. 기본 타이머는 휠이 남은 시간으로 바뀌어도 스위치가 같은 자리에 남게 한다                                                                                                              |
| 설정 휠            | iOS 시계 앱 타이머처럼 열 사이 `:`와 휠 아래 단위 글자를 없애고, 가운데 줄 숫자 오른쪽에 `시간`·`분`·`초`를 고정해 둔다. 시·초 열을 가운데로 당기고 숫자는 40px medium, 단위는 15px medium으로 줄인다                                                                                                                                                                                                                                                                                           | 375px 폭에서도 `초`가 선택 밴드 안에 들어가게 한다                                                                                                                                                                          |
| 휠 양 끝           | 시 0~~23, 분·초 0~~59에서 멈추고 반대쪽 끝으로 넘어가지 않는다. 첫 값 위와 마지막 값 아래는 비워 둔다. 끝을 넘겨 끌면 고무줄처럼 버티며 따라오다 손을 떼면 끝 값으로 돌아오고, 끝 너머로 튕긴 만큼은 끝에서 멈춘다. 모션 줄이기에서는 끝을 넘지 않는다. 키보드는 화살표가 끝에서 멈추고 Home·End로 양 끝에 간다                                                                                                                                                                                 | 사용자 결정. 0 아래가 23으로 이어지면 시간을 줄이려다 최대값이 되었다                                                                                                                                                       |
| 종료 진동          | 앱이 `alertHaptic=1`을 알리면 `alert` 한 번만 보내고, 앱이 시스템 진동 3번(iOS는 같은 박자에 Error 알림 햅틱 3번을 겹침)을 낸다. 표시가 없는 구버전 앱에는 heavy 3번을 0.18초 간격으로 보낸다                                                                                                                                                                                                                                                                                                   | iOS heavy는 짧은 Rigid라 약했다. iOS 시스템 진동은 햅틱 설정이 '무음 모드에서 재생 안 함'이면 무음 모드에서 막혀 Taptic을 겹친다(실기기 확인). 구버전 앱 파서는 모르는 세기를 버려 표시가 필요하다                          |
| 하단 버튼          | 큰 시작 버튼과 `처음부터` 글자 버튼을 세션 화면과 같은 둥근 버튼 두 개로 바꾼다. 왼쪽 아래 재생·일시정지, 오른쪽 아래 X(처음부터)이고 X는 시작 전 비활성이다                                                                                                                                                                                                                                                                                                                                    | 세션 화면과 조작 위치를 맞춘다                                                                                                                                                                                              |
| 기본 타이머 끝     | 0이 되면 알림(소리·진동)을 한 번 내고 같은 설정의 시작 전 화면(휠)으로 바로 돌아간다. `다시 시작` 버튼과 끝난 상태는 없앤다. 뽀모도로는 단계를 계속 돌아 그대로다                                                                                                                                                                                                                                                                                                                               | 00:00에 멈춰 있던 화면을 다시 설정하려면 한 번 더 눌러야 했다                                                                                                                                                               |
| 뽀모도로 분 입력   | 집중·휴식 칸을 누르면 앱 안 숫자 키패드 시트 대신 OS의 한 줄 휠로 분만 고른다. 칸 위에 보이지 않는 `select`(5분 단위로 집중 5~~180분, 휴식 5~~60분. 다이얼로 맞춘 단위 밖 현재값은 끼워 넣는다)를 덮어 탭이 select에 바로 닿게 하고, 설정 중에만 그린다. 칸은 점 없이 한 줄(왼쪽 절반에 이름, 오른쪽 절반에 분)이고 고른 칸은 배경색으로만 가른다. iOS가 select 탭을 키보드 포커스로 보아 포커스 링은 마우스 기기에서만 그린다. 키패드 시트와 그 포털 자리(`contentRef`·`modeSurface`)는 지운다 | 사용자 결정. iOS 웹뷰는 select에 UIPickerView 휠을, Android 웹뷰는 목록 대화상자를 띄운다. iOS 웹킷은 select의 `showPicker()`를 지원하지 않아 직접 탭이 닿아야 하고, 글자 16px 미만이면 포커스 때 확대돼 `text-base`를 둔다 |
| 뽀모도로 진행 숫자 | 집중 중 남은 시간 숫자는 집중색(`--session-mode-focus`, 심플 모드 집중색과 같은 값)으로 그린다. 휴식·비집중·설정 색은 그대로다                                                                                                                                                                                                                                                                                                                                                                  | 기본 타이머 진행 숫자·다이얼과 색을 맞춘다                                                                                                                                                                                  |
| Android 진동 모드  | Android는 벨소리·진동 모드와 상관없이 미디어 음량으로 알림음을 낸다. 끄려면 앱 안 `알림음` 스위치를 쓴다                                                                                                                                                                                                                                                                                                                                                                                        | 웹은 벨소리 모드를 알 수 없고, 미디어 앱과 같은 동작이다. 벨소리 모드를 따르게 하려면 네이티브 모듈과 앱 출시가 필요하다                                                                                                    |
