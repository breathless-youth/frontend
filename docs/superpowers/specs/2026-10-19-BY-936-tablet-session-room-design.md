# BY-936 세션·소셜룸 태블릿 배치 설계

상위 티켓 BY-641(태블릿 반응형)의 세 번째 하위 작업이다. BY-934에서 정한 기준(`sm` 600 · `md` 840 · `lg` 1200 · `xl` 1600, `landscape-compact`)을 써서 공부하는 동안 오래 보는 두 화면에 태블릿 배치를 넣는다.

## 배경

- BY-934 이후 태블릿 가로·세로는 폰 세로 배치를 넓게 늘려 받는다.
- 솔로 세션은 타이머 52px, 버튼 54px라 거치해 두고 멀리서 보기에 작고, 과목 시트가 화면 전폭(1180px)으로 열린다.
- 소셜룸은 폰 기준 정사각 타일이라 태블릿 가로 3~4명에서 타일이 590px로 커져 스크롤이 생기고, 2명은 303px 두 장이 가운데에 쌓여 좌우가 빈다.

## 결정

| 세션 배치    | 지금 세로 배치 유지                                                                                 | 과목 UI는 별도 티켓에서 버튼 + 옆 시트로 바뀌므로 상시 패널을 만들지 않는다                                                     |
| 세션 크기    | 타이머 52→96px, 총 시간 15→22px, 컨트롤 바·옆 버튼 54→64px, 상태 필 글자 확대                       | 거치해 두고 멀리서 보는 기기라 시간과 조작부가 모두 커야 한다(사용자 선택 C)                                                    |
| 과목 시트    | 아래 시트 유지, 가운데 최대 480px, 손잡이 자리를 64px 버튼에 맞춤                                   | 곧 바뀔 UI라 폭만 제한한다                                                                                                      |
| 소셜룸 타일  | 정사각 유지, 타일이 가장 커지는 열 수를 순수 함수로 고름, 가운데 정렬, 스크롤 없음, 1명은 전체 화면 | 영상이 잘리지 않는 쪽을 택했다(사용자 선택 A). 3명은 가로 3×1, 세로 2×2가 크게 나오는 식으로 화면마다 다르므로 표 대신 계산한다 |

| Figma        | V2 파일에 `Tablet v2.0` 페이지를 새로 만들고 다크 프레임만 만든다                                   | 세션·소셜룸은 항상 다크다                                                                                                       |
| 과목 UI 개편 | 별도 티켓                                                                                           | 폰·태블릿 공통 기능 변경이다                                                                                                    |

## 소셜룸 열 수 계산

입력은 인원 수 `n`(2~6), 격자에 쓸 수 있는 폭 `w`와 높이 `h`, 타일 간격 `gap`이다. `cols`를 1부터 `n`까지 돌며 `rows = ceil(n / cols)`, `size = min((w - gap*(cols-1)) / cols, (h - gap*(rows-1)) / rows)`를 구하고 `size`가 가장 큰 `cols`를 고른다. 같으면 열이 적은 쪽을 고른다.

iPad 기준 결과(여백 위·좌우 16px, 아래 바 자리 112px, 간격 4px):

| 인원 | 가로 1180×820 | 세로 820×1180 |
| ---- | ------------- | ------------- |
| 2    | 2×1, 572px    | 1×2, 524px    |
| 3    | 3×1, 380px    | 2×2, 392px    |
| 4    | 2×2, 344px    | 2×2, 392px    |
| 5~6  | 3×2, 344px    | 2×3, 348px    |

## 건드리는 곳

- `routes/RoomPage.tsx`: 옆 버튼 위치, 타이머 슬롯
- `features/study-session/components/SessionTimer.tsx`: 글자 크기
- `SessionControlBar`·`AmbientSoundButton`·`SessionSideActions`: 64px
- `SubjectSheet.tsx`: 시트 최대 폭과 손잡이 자리
- `features/live-room/roomGrid.ts`(열 수 함수), `components/RoomGrid.tsx`(크기식·재마운트 경계), `RoomControlBar.tsx`, `RoomTile.tsx`(배지·글자)
- `useTileFlipAnimation.ts`의 재측정 경계

## 테스트

- 열 수 함수 단위 테스트: 인원 1~6 × 가로·세로·좁은 창.
- 클래스 문자열을 단언하는 기존 테스트(`sessionLandscape`, `LiveRoomPage`, `RoomPage`)는 값만 맞춘다.
- 실제 배치는 Playwright로 402×874, 874×402, 820×1180, 1180×820, 1366×1024를 `dev`와 비교한다.

## 범위 밖

- 과목 UI를 버튼 + 옆 시트로 바꾸는 작업(별도 티켓).
- 앱 셸 회전·iPad 상단 탭 바(BY-935), 나머지 화면 최대 폭(BY-937).
