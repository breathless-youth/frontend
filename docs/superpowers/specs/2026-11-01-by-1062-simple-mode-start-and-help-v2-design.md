# BY-1062 싱글룸 심플 모드 시작·카메라 확인 모달 + BY-1099 세션 도움말 v2 설계

2026-11-01. 티켓 BY-1062(심플 모드 시작, 카메라 확인 모달)와 BY-1099(도움말 5단계 개편)의 설계를 한 문서에 둔다. 두 티켓은 같은 화면을 바꾸고 BY-1099가 BY-1062에 의존한다. Figma 시안은 V2 파일 Screens 페이지의 `BY-1005 세션 도움말 (다크) · 심플 모드 기본 5단계` 섹션(7762:14263)과 `S3 · 카메라 확인 모달 (싱글룸)` 프레임에 있다.

## 왜

- 첫 세션에서 얼굴부터 전체 화면에 비치는 첫인상이 부담스럽다(BY-738). 그래서 세션을 심플 모드로 시작하고, 카메라 화면은 사용자가 고르게 한다.
- 원안(BY-1062 구 본문)은 사람이 감지될 때까지 타이머를 멈추는 것이었지만, 측정 흐름을 바꾸지 않고 화면만 바꾸는 쪽으로 결정했다. 카메라·감지·타이머는 지금처럼 입장 즉시 돈다.
- 도움말 퍼널(BY-1089)은 촬영 화면 기본을 전제로 한 6단계라, 심플 모드 기본과 맞지 않는다. 5단계로 다시 짠다.

## 무엇을 (BY-1062)

### 심플 모드 시작

- `RoomPage`의 `simpleMode` 초기값을 `true`로 바꾼다. 저장하지 않으며 세션마다 심플 모드로 시작한다.
- 심플 모드는 지금처럼 `CameraPreviewSurface`를 `opacity: 0`으로 가리는 표시 모드다. 카메라 스트림과 감지기는 입장 즉시 켜지고 타이머도 바로 돈다.
- 화면 탭으로 촬영 화면과 심플 모드를 오가는 동작은 그대로다.

### 카메라 확인 모달

- 소셜룸 `CameraOnConfirmDialog`를 재사용한다. 제목·설명·자물쇠 줄·확정 버튼 글자를 props로 받게 하고, 기본값은 지금 소셜룸 문구 그대로 둔다. 소셜룸 호출부는 바꾸지 않는다.
- 싱글룸 문구: 제목 `카메라 위치를 확인해 주세요`, 설명 `얼굴과 책상이 보이게 자리를 잡아 주세요`, 자물쇠 줄 `영상은 기기 밖으로 나가지 않아요`, 버튼 `심플 모드로 시작`(취소 자리)·`카메라 켜기`(확정 자리).
- 미리보기는 `ClonedTrackPreview`에 세션 `cameraStream`·`cameraFacing`을 넘긴다. `targetAspect`는 `useCameraPreviewAspect`로 세션 루트(전체 화면)를 재서 넘겨 촬영 화면과 같은 영역이 잘리게 한다.
- 딤 탭으로는 닫히지 않는다(기존 동작). Escape는 `심플 모드로 시작`과 같다(`dismissable` 기본값 유지).
- `카메라 켜기` → `setSimpleMode(false)`. `심플 모드로 시작` → 심플 모드 유지. 어느 쪽도 타이머·감지에 손대지 않는다.
- 포털 `container`는 세션 루트(`theme-dark`)다. 닫힌 뒤 초점은 더보기 버튼으로 돌린다(`returnFocus`).

### 띄우는 시점

- 세션에 들어올 때마다 한 번 띄운다. 상태 `cameraPromptAnswered`(마운트마다 `false`)로 다시 뜨지 않게 한다.
- 도움말이 자동으로 뜰 조건인 계정은 도움말이 끝나거나(`seen`) Escape로 닫힌(`helpDismissed`) 뒤에 띄운다. 이미 본 계정은 입장 직후 띄운다.
- 조건: `phase.name === "studying" && !cameraPromptAnswered && !helpOpen && !helpAutoPending && page === null && !exitDialogOpen && invite === null && !modeOpen`. `helpAutoPending`은 `userId !== null && !helpDismissed && shouldShowSessionGuide({ state: guideState, blocked: false })`다.
- 신원은 기다리기만 한다. 진입 게이트가 첫 토큰(`useIdentityPending`)을 기다린 뒤에 세션 화면을 만들므로 그동안은 뜨지 않는다. 기다림이 끝났는데도 신원이 없으면(`userId === null`, 기기 등록 전·브라우저 단독) 도움말이 자동으로 뜨지 않으니 입장 직후 띄운다.
- 모달은 `aria-modal`이라 떠 있는 동안 `useModalOverlayOpen`이 참이 되어 도움말이 숨는다. 위 조건이 도움말 뒤에만 열리게 보장하므로 둘이 동시에 뜨지 않는다. 더보기 `도움말 보기`로 연 도움말(`helpOpen`)이 떠 있는 동안도 열지 않는다. 이 창 자체가 `aria-modal`이라 `modalOverlayOpen`은 조건에 넣지 않는다(뜨자마자 스스로를 닫는 순환이 된다).
- 종료 확인·초대 대화상자, 과목 페이지, 타이머 화면이 열려 있는 동안은 띄우지 않고, 닫히면 그때 띄운다(마운트마다 한 번 규칙은 그대로). 모달이 열려 있는 채 세션이 끝나면(`phase`가 `studying`을 벗어남) 조건이 거짓이 되어 닫힌다.

### 계측

- 열릴 때 `study_session_camera_prompt_shown { room_type }` 한 번.
- 답할 때 `study_session_camera_prompt_answered { choice: "camera" | "simple", room_type }` 한 번. Escape는 `simple`.
- `amplitude.ts`에 `trackStudySessionCameraPromptShown(roomType)`, `trackStudySessionCameraPromptAnswered({ choice, roomType })`를 기존 함수와 같은 모양으로 둔다. `session_simple_mode_toggled`는 그대로. 분석 설계 문서(`2026-09-04-native-analytics-bridge-design.md`) 표에 행을 더한다.

### 바뀌지 않는 것

- 소셜룸 모달 문구·동작. 일시정지·종료·과목·배경음·타이머·타임랩스 흐름. 세션 훅(`useStudyRoomSession`)은 손대지 않는다.

## 무엇을 (BY-1099)

### 단계

- 심플 모드 배경(1~3)은 PNG가 아니라 실제 요소로 그린다. `SimpleModeSurface`(배경·엣지 글로우), 가짜 상태 필, `SessionTimer`의 `glow` 모드와 같은 꼴의 가짜 발광 숫자(총 공부 줄 없음), 과목 줄(`수학 01:10:00` 꼴 고정), 일시정지 버튼 자리. 상태 색은 `sessionGlowStyle`로 1단계 `distract`, 2·3단계 `focus`.
- 1단계 숫자는 고정(순공 멈춤), 2·3단계는 1초씩 올라간다. 기존 `FakeTimer`의 `ticking` 개념을 순공 하나로 줄인다.
- 기존 자산 `session-simple-mode.png`·`session-simple-mode-landscape.png`는 더 쓰지 않으면 삭제한다.

### 이동 막대

- 아래쪽 가운데 반투명 막대 하나: 높이 48, 좌우 패딩 20, 모서리 24, 배경 흰 12% + 블러, 테두리 1px 흰 15%. 내용은 `‹ 이전`(16 Bold, 흰 70%) · `n/5`(14 Medium, 흰 70%) · `다음 ›`(16 Bold, 흰 100%), 항목 간격 20.
- 세로는 바닥(안전 영역 포함)에서 172px 위, 가로(`landscape-compact`)는 40px 위.
- 1단계 `‹ 이전`은 보이되 `disabled`·`aria-disabled="true"`(흰 30%).
- 5단계 막대는 `‹ 이전 · 5/5`만. 끝내기는 정중앙 필 버튼 `순공 시작하기`(높이 52, 좌우 패딩 32, primary 배경, 16 Bold 흰색)다.
- 덮개 탭은 1~4단계에서 다음으로 간다. 5단계에서는 덮개 탭이 아무 일도 하지 않는다.
- 버튼 접근 이름은 화살표 기호 없이 `이전`, `다음`, `순공 시작하기`다. 터치 타겟은 44px 이상.
- 우측 하단의 기존 `< 이전 · n/6 · 다음 >` 줄은 없앤다.

### 가로 모드

- 가로 시안(1·3·4단계, 874×402): 1단계 필 콜아웃은 필 오른쪽, 숫자 콜아웃은 숫자 왼쪽(오른쪽 정렬, 화살표 왼쪽 방향). 3단계 문구는 왼쪽 빈 영역에 두 줄 + 손 아이콘. 4단계 일시정지 콜아웃은 버튼 위 오른쪽, 사이드 콜아웃은 버튼 묶음 왼쪽.
- 2단계는 1단계 배치, 5단계는 4단계 배치를 따른다. 막대는 바닥 40px 위 가운데.

### 계측

- `study_session_help_step_viewed`·`study_session_help_dismissed`에 `step_id`(`away`/`measuring`/`camera`/`buttons`/`finish`) 추가.
- 네 도움말 이벤트 전부에 `help_version: 2` 추가. 운영에 v1 데이터가 쌓이고 있어 단계 번호 뜻이 바뀌면 섞인다. 콘솔 차트는 `help_version`으로 거른다.
- `trackStudySessionHelp*` 함수의 인자를 넓히고 분석 설계 문서 표의 행을 고친다.

### 바뀌지 않는 것

- 노출 조건(`seen`만 제외, 모두에게), 더보기 `도움말 보기`, Escape 닫기, 가려졌다 같은 단계로 복귀, 세션 레이어 `inert`·glass 버튼 `faded`, 비모달 대화상자 루트 초점.


### 테스트

- 심플 모드 기본: 마운트 직후 `data-session-surface="simple"`, 탭하면 `camera`.
- 모달: seen 계정은 마운트 직후 열림, 미완료 계정은 도움말 끝난 뒤 열림, Escape·두 버튼의 결과, 딤 탭 무시, 세션마다 한 번, `userId` 늦게 도착, 이벤트 2개.
- 도움말: 5단계 문구, 1단계 이전 비활성, 5단계 덮개 탭 무시, `순공 시작하기`로 완료, `step_id`·`help_version`.
