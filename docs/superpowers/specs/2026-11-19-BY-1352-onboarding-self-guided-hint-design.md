# BY-1352 온보딩 1단계 자율 모드 안내

## 배경

온보딩 1단계(카메라 자동 측정 소개)에서 이탈이 많다.
카메라가 부담된다는 문의가 이어지는데, 온보딩 어디에도 카메라 없이 공부하는 방법이 안내되지 않는다.
BY-1321에서 만든 자율 모드가 있다는 것을 1단계에서 알린다.
기본 모드는 계속 관리 모드다.

## 결정 (2026-11-19 사용자 승인)

| #   | 항목    | 결정                                                                                   |
| --- | ------- | -------------------------------------------------------------------------------------- |
| 1   | 문구    | `카메라 없이 공부하는 자율 모드도 있어요`                                              |
| 2   | 위치    | 1단계 제목 8px 아래 보조 문단(Figma 시안 A, 섹션 `12186:21418`)                        |
| 3   | 단계 수 | 그대로 5단계다. 새 단계를 만들지 않는다                                                |
| 4   | 측정    | 새 이벤트 없이 `onboarding_step_viewed`의 `auto_timer`→`auto_record` 전환율을 비교한다 |

## 문구

| 언어    | `onboarding:autoTimer.hint`                       |
| ------- | ------------------------------------------------- |
| ko      | `카메라 없이 공부하는 자율 모드도 있어요`         |
| en      | `There's also Self-guided Mode, no camera needed` |
| ja      | `カメラなしで勉強する自主モードもあります`        |
| zh-Hant | `也有不用相機讀書的自主模式`                      |

모드 이름은 BY-1351에서 정한 공식 이름을 그대로 쓴다.

## 구현

- 안내는 1단계 `h1` 아래 별도 문단이다. 제목 `h1`에는 넣지 않는다.
- 제목과 같은 전환(흐림·이동·투명도)으로 나타나고 사라지며, 모션 줄이기에서는 투명도만 바뀐다.
- 14px, 보조 글자색 토큰, `break-keep`을 쓴다.
- 영어가 넘치면 두 줄로 내려간다. 제목 끝(682px)과 `다음` 버튼 위(742px) 사이에 두 줄이 들어간다.
- 1단계가 아니면 `aria-hidden`으로 숨기고, 제목 변경을 알리는 live 영역은 1단계일 때 안내도 함께 읽는다.

## 테스트

- 1단계에 안내 문구가 보인다.
- 2단계로 가면 안내 문구가 화면 읽기에서 숨겨진다.
- 이전으로 1단계에 돌아오면 안내 문구가 다시 보인다.
- 4개 언어 안내 문구에 자율 모드 공식 이름이 들어간다.

## 범위 밖

- 온보딩에서 바로 자율 모드를 고르게 하는 일. 모드는 홈의 전환 버튼에서 바꾼다.
- 온보딩 다크 시안. 온보딩은 밝은 테마로 고정돼 있다.
