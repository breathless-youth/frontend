# BY-1202 PC 홈: 월페이퍼·왼쪽 레일·공부시간 패널

## 배경

PC 브라우저(앱 밖, 폭 1200px 이상)는 BY-1195부터 상단 바와 둥근 상자 안에 모바일 화면을 그대로 그렸다.
홈도 모바일 홈을 넓은 상자에 그대로 그려 화면이 비어 보였고, PC에서만 줄 수 있는 「집중 공간」이 없었다.
PC 첫 출시는 홈과 공부 세션(시작~종료)만 내보내기로 했고(2026-11-19), 이 문서는 그중 홈을 다룬다.
공부 중 화면과 배경음·타이머는 BY-1199가 맡는다.

## 구조

```
PcShell (상단 바 · 둥근 상자)
└─ HomeTabPage (공지 · 세션 복구 · 계획 이월은 그대로, PC면 바깥 여백 없이 상자를 채움)
   └─ HomeV3Entry (데이터 · 동작)
      ├─ 모바일: HomeV3Content
      └─ PC:     PcHomeContent (지연 로딩, apps/web/src/desktop/home/)
         ├─ PcWallpaper        선택값을 구독해 심플 / 내 사진을 상자 전체에 깐다
         ├─ PcHomeRail         버튼 목록을 받는다 (D-Day, 공간)
         │   └─ PcSpaceFlyout  모바일 세션 공간 시트 본문(SpaceContent)을 비모달 창에 담는다
         ├─ PcStudyPanel       끌기 · 최소화 · 위치 기억
         │   └─ HomeProgressBand · HomeStudyCard(HomeSubjectSelect) · HomeStartButtons
         └─ PcContactButton    /contact 를 새 탭으로
```

- `PcHomeContent`는 `HomeV3Content`와 같은 props(`HomeV3ContentProps`)를 받는다.
- PC 판정은 기존 `usePcShell()`을 쓴다. 토큰 출처가 없는 문서(검색 로봇)는 지금처럼 옛 홈을 그린다.
- 홈은 스크롤하지 않는다. 월페이퍼는 상자를 꽉 채우고, 그 위의 레일·패널·문의는 상자 기준 절대 위치다.

## 공부시간 패널

- 폭은 400이고 진행 띠는 폰과 같은 362폭이다. 바탕은 불투명한 흰색이라 월페이퍼와 상관없이 글자 대비가 유지된다.
- 처음 위치는 상자 오른쪽에서 24, 위에서 24다.
- 머리줄(`공부시간` 제목과 최소화 버튼)을 잡고 끌면 따라온다. 라이브러리 없이 포인터 이벤트와 포인터 캡처로 만든다.
- 패널은 상자 가장자리에서 16px 안쪽까지만 움직인다.
- 위치는 상자의 오른쪽 위 모서리에서 떨어진 거리(`right`, `top`)로 저장한다. 창을 넓혀도 오른쪽에 붙어 있고, 창을 줄여 밖으로 나가게 되면 안쪽으로 당긴다.
- 머리줄에 포커스가 있을 때 방향키는 16px, Shift+방향키는 64px씩 옮긴다. 머리줄에는 옮기는 방법을 읽어 주는 접근성 이름을 단다.
- 최소화 버튼을 누르면 머리줄만 남고 머리줄에 `공부시간 4:18:32`(오늘 공부시간)가 보인다. 버튼은 `+`로 바뀌고 `aria-expanded`를 단다. 접힌 상태에서도 끌 수 있다.
- 위치와 최소화 여부는 localStorage `focusmakers.pc.studyPanel`에 둔다. 값이 깨졌거나 저장소를 못 쓰면 기본 위치로 연다.
- 고정 플라이아웃은 끌어 옮기는 패널보다 늘 위에 그린다.
- 진행 띠, 목표 링, `변경하기`, 시작 미션, 과목 선택, 관리·자율 모드 전환과 토스트는 폰과 같은 부품이라 같게 동작한다.

## 월페이퍼

- `심플`이면 단색 `#0b0f14`, `내 사진`이면 기존 `TimerBackgroundLayer`로 저장된 확대·위치대로 덮어 채운다.
- 고른 사진이 지워졌거나 읽히지 않으면 `심플`로 그린다.
- 공유 선택값(`focusmakers.timerBackground`)에 구독을 더한다. 측정 모드 저장소와 같은 방식(`useSyncExternalStore` + 같은 탭 사용자 이벤트 + 다른 탭 `storage` 이벤트)이다. 세션 화면은 지금처럼 열 때 한 번 읽는다.
- 레일·패널·문의가 모두 불투명 카드라 월페이퍼 위 어두운 막은 두지 않는다.

## 레일과 공간 플라이아웃

- 레일은 상자 왼쪽 위에 떠 있는 카드다. 버튼은 44px 이상이고, 열린 플라이아웃의 버튼에는 `aria-expanded`와 눌린 모양을 준다.
- D-Day는 기존 `DdaySection`에 PC 레일 모양을 더해 쓴다. 설정됐으면 `수능 / D-120`, 아니면 `D-Day`를 보인다.
- D-Day 시트(`DdaySheet`)와 목표 시트(`HomeGoalSheet`)는 내용·저장·분석은 그대로 두고 겉 틀만 고른다. `usePcShell()`이 참이면 Dialog, 아니면 Drawer다. 겉 틀을 고르는 작은 부품 하나를 두 시트가 함께 쓴다.
- `공간`을 누르면 레일 오른쪽에 폭 380 안팎, 상자 아래 16px까지 닿는 플라이아웃이 열린다.
- 닫기는 `닫기`, Esc, 바깥 클릭, `공간` 다시 누르기다. 닫으면 포커스가 `공간` 버튼으로 돌아온다. 플라이아웃은 한 번에 하나만 열린다.
- 이미 설치된 Radix Dialog를 비모달(`modal={false}`)로 쓴다. 새 의존성(Popover)은 들이지 않는다.
- 본문은 모바일 세션 공간 시트의 `SpaceContent`를 그대로 쓴다. 내 사진(3장), 사진 올리기·지우기, `심플`, 누르면 바로 적용, 하단 지금 공간 이름과 음량 줄(사진·심플이면 비활성)이 같다.
- `SpaceContent`에 두 props를 더한다. 영상 공간이 없을 때 탭 줄을 숨기는 값(PC만 켬)과, 분석용 `surface` 값이다.
- 검색창은 넣지 않는다. 공간이 최대 4개(내 사진 3 + 심플)라 찾을 일이 없고, 서버 공간 목록이 들어올 때 더한다.

## 문의

- 상자 오른쪽 아래의 둥근 `문의` 버튼은 `target="_blank" rel="noopener"` 링크로 `/contact`를 연다.
- 새 탭이라 보던 홈과 공부 상태가 그대로 남는다.

## 오류 처리

- 통계·진행 띠·과목을 못 불러오면 폰과 같은 인라인 오류와 `다시 시도`가 같은 자리에 뜬다.
- 사진을 못 읽으면 월페이퍼는 `심플`로 그리고, 플라이아웃은 지금 시트처럼 사진 읽기 실패를 알린다.
- 저장소가 막혀 공간 저장에 실패하면 지금 시트의 실패 안내를 쓰고 배경을 바꾸지 않는다.

## 범위 밖

- 배경음·타이머 플라이아웃과 공부 중 화면은 BY-1199에서 한다.
- 플래너·미션 레일, 유휴 모드는 첫 출시 뒤에 한다. 과목 추가와 시작 미션은 지금처럼 플래너 화면을 연다.
- 영상 공간, 동작 줄이기·창 숨김 시 영상 멈춤은 영상 공간을 열 때 한다.
- 직접 만든 공간 이미지와 첫 접속 기본 공간은 BY-1331에서 한다.
- PC 그룹·기록·랭킹 화면은 BY-1196·BY-1197에서 한다.
