## 1. 목적

랭킹 탭에서 내 순위와 바로 위 한 명까지 남은 차이를 보여주고, 홈과 공부 결과 화면에서도 순위 변화를 알 수 있게 한다.
순위 계산은 서버가 하고, 웹은 받은 값을 판별 화면으로 그린다.
순공·시간대 판은 보는 동안 15초마다 다시 받고, 그 사이에는 집중 중인 사람의 시간을 화면에서 1초씩 올린다.

## 4. 서버 API

모두 토큰이 필요하고 `API-Version: 1`이다.
시각은 UTC ISO-8601, 날짜는 KST `yyyy-MM-dd`로 온다.
값과 차이의 단위는 시간 판이 초, 일수 판이 일, 집중률이 %(소수 1자리)다.

| 엔드포인트                                            | 쓰는 곳                                   | PR  |
| ----------------------------------------------------- | ----------------------------------------- | --- |
| `GET /api/rankings/board?type=&period=&slot=&offset=` | 랭킹판 전체, 5k의 직전 기간 결과          | ①   |
| `GET /api/rankings/records/summary`                   | 메달 버튼, 기록 시트(5q·5s), 5r 요약 카드 | ①   |
| `GET /api/rankings/records?rank=&type=&cursor=&size=` | 시트의 순위 칩, 모두 보기(5r)             | ①   |
| `GET /api/rankings/records/unseen`                    | 마감 모달                                 | ②   |
| `POST /api/rankings/records/seen`                     | 마감 모달을 띄운 뒤                       | ②   |
| `GET /api/rankings/home?since=`                       | 홈 한 줄 카드, 추월 팝업                  | ②   |
| `GET /api/rankings/session-gains?startedAt=`          | 공부 결과 카드                            | ②   |

- 타입은 `packages/types/src/ranking.ts`에 두고 `index.ts`에서 내보낸다.
- 파일 머리 주석에는 타입이 dev 백엔드 Swagger(`/v3/api-docs`)를 따른다는 것과 대조한 날짜(2026-10-11)를 적는다.
- 엔드포인트는 `apiVersion.ts`의 `API_ENDPOINTS`에 `{ version, parsedBy }`로 등록한다.
- 다른 사람의 `userId`는 오지 않으므로 목록의 React key는 `nickname`이다 (서버에서 고유하다).
- `eligibility.expectedTopPercent`는 BE가 추가해 dev에 배포했다(backend PR #87). 미달일 때 지금 집중률로 참가하면 받을 상위 %이고, 참가 조건을 채웠으면 `expectedRank`와 함께 null이다. 예상 순위가 3위 밖이고 상위 %도 없으면 이 줄을 숨긴다.

## 6. 판 선택과 기억

```ts
type BoardSelection =
  | { type: "FOCUS_TIME"; period: "DAILY" | "WEEKLY" | "MONTHLY" }
  | { type: "FOCUS_RATE"; period: "WEEKLY" | "MONTHLY" }
  | { type: "TIME_SLOT"; period: "DAILY" | "WEEKLY"; slot: TimeSlot | null }
  | { type: "TOTAL_TIME" | "TOTAL_DAYS" | "MAX_STREAK" };
```

- 처음 열면 `랭킹 › 순공 › 주간`이다.
- `slot: null`은 지금 구간이라는 뜻이고, 요청에서 `slot`을 빼면 서버가 지금 구간을 골라 응답의 `slot`에 담아 준다.
- 종목을 바꿨을 때 지금 기간이 그 종목에 없으면 주간으로 바꾼다.
- 랭킹과 명예의 전당은 각자 마지막 판을 기억한다.

### 기억과 넘겨주기

- localStorage 키 하나(`ranking.board.v1`)에 `{ active, ranking, hall }`을 적는다.
- 구간은 적지 않는다.
- 메달처럼 특정 구간으로 보내야 할 때는 한 번 읽고 지우는 `requestedSlot`을 함께 적는다.
- 랭킹 페이지는 마운트될 때와 포커스를 다시 받을 때 이 값을 읽고, 판을 바꿀 때마다 다시 적는다.
- 홈 카드, 추월 팝업, 결과 카드(PR ②)는 이 키에 `순공 · 주간`을 적고 `navigate-tab`으로 랭킹 탭을 연다.
- 기록 시트와 5r에서 메달을 누를 때도 같은 방식으로 적고, 5r에서는 히스토리가 있으면 뒤로, 없으면 `/ranking`으로 replace한다.
- 읽기·쓰기에 실패하면 기본 판으로 연다.

## 7. 데이터 받기와 폴링

### 보이는 중의 기준

- 셸이 보내는 `tab-focus`가 참이고 `document.visibilityState`가 `visible`일 때 보이는 중이다.
- `lib/nativeTabFocus.ts`가 두 신호를 합쳐 `focusManager.setEventListener`에 연결한다.
- 첫 `tab-focus`가 오기 전에는 보이는 중으로 본다.
- 셸이 없는 브라우저에서는 TanStack 기본 동작을 그대로 쓴다.
- 이 연결은 문서 전체에 걸리므로 홈·기록 탭도 탭에 다시 들어올 때 오래된 쿼리를 새로 받는다 (두 탭 코드 주석이 의도한 동작이다).

### 쿼리

| 쿼리                        | 키                                                 | staleTime | 다시 받기                                                 |
| --------------------------- | -------------------------------------------------- | --------- | --------------------------------------------------------- |
| 순공·시간대 판 (`offset=0`) | `["ranking", "board", type, period, slot, 0]`      | 10초      | 보이는 중 15초마다 (`refetchIntervalInBackground: false`) |
| 집중률·명예의 전당 판       | 위와 같은 형태                                     | 60초      | 포커스를 다시 받을 때                                     |
| 직전 기간 (`offset=-1`)     | 위와 같은 형태, 끝이 `-1`                          | 5분       | `me`가 없을 때만 받는다                                   |
| 기록 요약                   | `["ranking", "records", "summary"]`                | 60초      | 포커스를 다시 받을 때                                     |
| 기록 목록                   | `["ranking", "records", "list", rank, type, size]` | 60초      | 끝에 닿으면 다음 페이지                                   |

- 서버 캐시가 기간 판 10초, 그 밖 60초라서 staleTime을 그에 맞췄다.
- 공부를 마치면 `nativeSessionClosed`의 무효화 목록에 `["ranking"]`을 더해 랭킹을 새로 받는다.
- 기록 목록은 이 저장소의 첫 `useInfiniteQuery`이고, 목록 끝의 감시 요소(IntersectionObserver)가 보이면 다음 페이지를 받는다 (`size` 20).

## 8. 실시간 (순공·시간대 판)

### 보간

- 집중 중인 줄의 값은 `값 + (지금 − dataUpdatedAt)초`로 그린다.
- 서버의 `asOf`가 아니라 응답을 받은 기기 시각을 기준으로 해서 기기 시계가 틀려도 숫자가 튀지 않는다.
- 나도 다른 기기에서 공부 중이면 내 줄도 같은 방식으로 올린다.
- 보간은 마감 시각을 넘지 않는다.
- 시간대 판은 그 구간이 끝나는 시각에서 보간을 멈추고, 응답의 계산 시각(`asOf`)이 구간 밖이면 올리지 않는다.
- 집중률 판과 지난 기간 판(`offset=-1`)은 `startNowRank`가 늘 null이다(BE 전달사항).
- 참가 미달 응답의 `around`는 `expectedRank − 1`을 가운데 둔 실제 다섯 줄이고 "나" 줄은 없다(BE 코드 대조). 이 화면은 목록 대신 잠긴 카드를 보여 해당 값을 쓰지 않는다.
- 바로 위가 집중 중이면 순위 카드의 `다음 순위까지 N분`이 늘고, 바로 아래가 집중 중이면 따라오는 차이가 준다.
- 줄 순서는 폴링이 올 때만 바뀌고, 그 사이 보간 값은 바로 위 줄 값에서 멈춘다.
- 1초 tick은 보이는 중이고 집중 중인 줄이 하나라도 있을 때만 돈다.

### 추월 판정

- 같은 판에서 연달아 받은 두 응답을 비교한다.
- 내 순위가 N만큼 내려가면 내 줄에 `▼N`을 4초 붙이고, 한 응답 안에서 여러 명이 넘어와도 배지는 하나다.
- 판을 바꾸거나 보이는 중이 끝나면 비교 기준을 버린다.
- `▼N`은 스크린리더에 `순위가 N계단 내려갔어요`로 한 번 읽힌다.
- `▼N` 배지는 알약 모양과 크기를 그대로 두고, 카드 면에 빨강을 조금 섞은 바탕(`--rank-alert-badge-bg`, 라이트는 연한 빨강, 다크는 어두운 빨강)에 빨간 글자(`--rank-alert-badge-fg`)로 칠한다.
- 배지 글자는 라이트와 다크 모두 배지 바탕 위에서 4.5:1을 넘긴다.

### 순위 카드 아랫줄 문구

위에 있는 조건이 먼저다.

| 우선 | 조건                                  | 문구                                                                   | 색                 |
| ---- | ------------------------------------- | ---------------------------------------------------------------------- | ------------------ |
| 1    | 바로 위가 집중 중                     | `OO님이 집중 중이라` 다음 줄에 `차이가 벌어지고 있어요`                | 진하고 차분한 빨강 |
| 2    | 바로 아래가 집중 중이고 차이 5분 이내 | `OO님이 N분 차로 따라오고 있어요`                                      | 진하고 차분한 빨강 |
| 3    | 1위                                   | `OO님과 N분 차이예요` (2위가 없거나 2위와 값이 같으면 비움)            | 회색               |
| 3    | 순공 판                               | `한 세션이면 따라잡을 수 있어요`                                       | 회색               |
| 3    | 시간대 판                             | `{구간}이 끝나기 전에 따라잡을 수 있어요` (지금 구간이 아닌 판은 비움) | 회색               |

- 1번은 바로 위 한 사람만 보는데, `다음 순위까지 N분`을 늘리는 사람은 바로 위 한 사람뿐이기 때문이다.
- 바로 위가 집중 중이면 그 사람이 나를 넘어온 사람이 아니어도 1번 문구를 쓴다.
- 두 칸 이상 위에 있는 사람은 집중 중이어도 아랫줄 문구를 바꾸지 않는다.
- 앞사람 여러 명을 세던 `앞사람 N명이 집중 중이라 차이가 벌어지고 있어요` 문구는 없앴다.
- 1번 문구는 늘 `집중 중이라` 뒤에서 줄을 바꿔 `차이가 벌어지고 있어요`를 따로 한 줄에 둔다.
- 줄을 바꿔도 글자는 한 문단의 한 덩어리라 스크린리더는 한 문장으로 읽는다.
- 1·2번은 빨강을 어두운 쪽으로 눌러 채도를 낮춘 진한 빨강 `--rank-alert`로 쓰고, 굵기는 `font-medium`이다.
- 이 글자색은 라이트와 다크 모두 카드 위에서 4.5:1을 넘긴다.
- 회색 문구는 색과 굵기(`font-semibold`)가 그대로다.
- 지금 구간이 아닌 시간대 판은 누가 집중 중이어도 그 판 값이 움직이지 않으므로 1·2번 문구를 쓰지 않는다.
- 같은 판에서는 시간대 문구도 비우고, 1위의 회색 차이 문구만 그대로 쓴다.
- 1위가 2위와 값이 같으면 차이가 최소 단위인 `1분`이나 `1일`로 적혀 바로 아래 목록과 어긋나 보이므로, 판 종류와 상관없이 1위 아랫줄을 비운다.

### 줄 이동 연출

- 웹에는 애니메이션 라이브러리가 없어서 브라우저 Web Animations API로 움직인다(CSS transition은 React가 줄 순서를 바꿀 때 끊겨 쓰지 않는다).
- 줄은 `nickname`을 key로 두고 세로 위치를 `transform`으로 300ms 동안 바꾼다.
- 5줄 창 밖으로 나가거나 들어오는 줄은 투명도로 사라지고 나타난다.
- reduced motion이면 위치를 바로 바꾸고, `▼N`은 정보라서 그대로 4초 보여준다.

## 9. 화면

### 머리 부분

- 왼쪽에 큰 글자 `랭킹 | 명예의 전당`, 오른쪽에 메달 버튼을 둔다.
- 메달 버튼은 겹친 금·은·동 메달과 `summary.total`이고, 0이면 메달을 흐리게 그린다.
- 랭킹 쪽에는 종목 칩(순공·집중률·시간대)과 기간 세그먼트를 한 줄에 둔다.
- 시간대를 고르면 아래에 구간 칩 5개(`새벽 4–7시` 등)를 두고 지금 구간에 초록 점을 붙인다.
- 명예의 전당 쪽에는 칩(누적 시간·누적 일수·연속 공부)만 둔다.
- 칩 줄(구간 칩이 있으면 구간 칩)과 시상대 사이는 카드 사이와 같은 12px이다. Figma의 5·6px보다 넓혀 카드 간격과 맞췄다.
- 명예의 전당은 칩 줄이 기간 칸보다 낮아서 머리 줄 아래를 12px로 둬, 랭킹과 명예의 전당을 오가도 시상대 위치가 같다.

### 시상대

- 2·1·3 순서로 놓고 1위에 왕관을 올린다.
- 빈자리는 `?`로 둔다.
- 집중 중인 사람은 초록 점과 보간 값을 쓴다.
- 메달을 받은 자리는 아바타 둘레에 그 순위 메달 색의 3px 테를 두른다.
- 테 색은 메달 그림의 채움색과 같은 금 `#FFD262`, 동 `#F0BE8C`이고 라이트와 다크에서 같다.
- 은색만 채움색 `#D6DDE8`이 흰 카드에 묻혀서 메달 테두리색 `#AAB5C6`을 쓴다.
- 테와 아바타 사이는 2px 띄워 카드 배경이 보이게 한다.
- 테도 메달처럼 `icons.tsx`의 색 고정 그림으로 그리고 색 토큰을 더하지 않는다.
- 빈자리와 메달이 없는 자리에는 테를 두르지 않는다.
- 테가 아바타보다 5px씩 커서 왕관 아래와 닉네임 위 틈을 2px씩 넓히고, 그만큼 시상대를 올려 카드 높이를 유지한다.
- 내 자리는 파란 바탕에 내 닉네임 첫 글자를 넣은 아바타로만 알리고, 아바타 안에도 닉네임 옆에도 `나`를 쓰지 않는다.
- 화면 낭독기는 내 자리의 닉네임 뒤에 `나`를 함께 읽는다.
- 목록 줄의 `나` 표시는 시상대와 달리 유지한다.
- 순공·시간대 판에서 값이 1800초 미만인 자리는 메달과 테 없이 흐린 순위 숫자만 그린다(Figma 5k).
- 그런 자리가 하나라도 있으면 시상대 아래에 `메달은 30분 이상부터 받아요`를 한 줄 적는다.

#### 일수 판 묶음 시상대

- 누적 일수와 연속 공부는 같은 일수를 한 묶음으로 세우고, 일수가 많은 순서로 1·2·3번 자리에 놓는다.
- 자리마다 대표 아바타, 이름, `외 N명`, 일수(`15일`)를 위에서부터 쌓는다.
- 대표는 내가 그 묶음에 있으면 나이고 아바타가 파란색이며, 없으면 그 일수를 먼저 달성한 사람이다.
- 혼자인 묶음은 `외 N명` 줄을 뺀다.
- 메달과 테는 자리 순서를 따르고, 화면 낭독기는 묶음의 공동 순위를 읽는다.
- 데이터는 `podiumGroups`만 쓰고, 일수 판의 `podium`은 늘 빈 배열이라 쓰지 않는다.
- `podiumGroups`가 오지 않으면 빈 묶음으로 보고 세 자리를 모두 빈자리로 둔다.
- `외 N명` 줄만큼 카드가 높아지는 것은 받아들인다.

#### 상태별 세부

- 1위 카드 큰 글자는 `1위`만 파랑으로 강조하고 `지키는 중`은 기본 글자색으로 쓴다.
- 집중률 따라잡기 줄은 숫자 없이 `조금만 더 집중하면 따라잡아요`로 고정하고, `above.catchUpFocusSec`가 null이면 줄을 뺀다.
- `catchUpFocusSec`는 총공부 시간이 그대로라고 보고 센 값이라 분으로 적으면 실제로 더 해야 할 공부보다 훨씬 적어 보여서 숫자를 쓰지 않는다.
- 다음 구간 상자는 첫 줄 `상위 5%까지 28시간`, 둘째 줄 `지금 페이스면 약 9일 뒤`로 두 줄이고, `etaDays`가 없으면 둘째 줄을 빼고 `nextTier`가 없으면 상자를 뺀다(사용자 결정, Figma는 한 줄).
- 연속 공부 카드는 `최고 기록 13일 (9월 14일 – 9월 26일)`과 `지금 0일 (오늘 공부하면 1일째)`를 나란히 두고 아래에 `14일을 이어가면 최고 기록을 넘어요`를 둔다.
- `currentIsBest`이면 비교 대신 `지금이 최고 기록이에요`와 `내일도 공부하면 최대 N일 · M위로 올라가요`를 둔다.
- 공동 순위라 `nextRankIfContinue`가 지금 순위(`me.rank`)보다 앞서지 않으면 순위 없이 `내일도 공부하면 최대 N일이에요`로 쓰고, `nextRankIfContinue`가 null이면 이 줄을 뺀다.
- 연속 공부 판에 내 순위가 없으면 처음 카드 큰 글자는 `하루 10분 이상 공부하면 순위가 생겨요`다(연속 공부는 하루 순공 10분부터 세서, 공부했어도 순위가 없을 수 있다).
- 연속 공부와 누적 일수 목록의 일수 묶음 줄에는 내 줄을 포함해 이름(`OO 외 N명`)과 일수만 쓴다.
- 누적 일수 판은 1위와 순위 있음 모두 사람별 목록 대신 `aroundGroups` 묶음 목록을 쓰고, 이 필드가 오지 않으면 빈 묶음 목록으로 본다.
- 누적 일수와 연속 공부의 순위는 같은 일수면 같은 공동 순위이고 다음 순위는 그 인원만큼 건너뛴다(1, 1, 3).
- 공동 1위도 카드 큰 글자는 `1위 지키는 중`이고, 아랫줄은 일수가 다른 바로 아래 사람과의 차이다.
- 5m 진행바는 `focusSec ÷ requiredFocusSec`이고 아래에 `이번 주 순공 6시간 20분`과 `10시간`을 양 끝에 적는다.
- 5m에서 `eligibility`가 null이면 순공 0으로 보고 예상 줄을 뺀다.
- 예상 상위 % 줄은 집중률 숫자 없이 `현재 집중률이면 상위 15%예요`로 쓴다(사용자 결정, Figma는 `지금 집중률 94%면 …`).
- 예상 순위가 1~3위면 상위 %가 없어도 `현재 집중률이면 1위예요`처럼 순위로 쓴다(사용자 결정, 참가자가 적으면 1위도 상위 100%로 와 어색했다).
- 예상 순위가 3위 밖이면 상위 %로 쓰고, 상위 %도 없으면 예상 줄을 뺀다.
- 집중률 판은 5k·5l을 쓰지 않는다.
- 5k 새로 시작 문구는 일간 `00시에 일간 랭킹이 새로 시작됐어요`, 주간 `월요일 00시에 주간 랭킹이 새로 시작됐어요`, 월간 `1일 00시에 월간 랭킹이 새로 시작됐어요`이다.
- 시간대 판의 5k 문구는 `오늘 오전 구간 랭킹이 새로 시작됐어요`, `이번 주 오전 구간 랭킹이 새로 시작됐어요`이다.
- 지금 구간이 아닌 시간대 판에서는 지금 공부한 시간이 그 판에 들어가지 않으므로, 5k·5l 큰 문구를 `저녁 구간에 공부하면 순위가 생겨요`처럼 바꾸고 순위 숫자를 보이지 않는다.
- 같은 이유로 지금 구간이 아닌 시간대 판의 순위 카드(5e)는 경고 문구, 구간 문구, 작은 집중 시작을 모두 뺀다.
- 그 판의 1위 카드(5n)는 회색 차이 문구와 큰 집중 시작을 그대로 둔다.
- 5k에서 `startNowRank`가 null이면 순위를 지어내지 않고 5l 큰 문구 `첫 공부를 마치면 바로 순위가 생겨요`를 쓴다.
- 5k 결과 카드는 `어제 최종 결과`, `지난주 최종 결과`, `지난달 최종 결과`에 `1,240위 · 7시간 12분`과 `기록 보기 ›`를 둔다.
- 5l 윗줄은 왼쪽 `아직 내 순위가 없어요`, 오른쪽 마감 문구이고, 아랫줄은 `이번 주 순공으로 겨루는 중`처럼 기간과 종목을 적는다.
- 5l 목표 예시 막대 길이는 `100 − percent`%다 (시안의 상위 50%·20%·5% 막대와 같다).
- BE는 목표 예시를 최대 여섯 줄(1·5·10·20·30·50%) 오름차순으로 보내므로, 화면은 50·20·5%만 이 순서로 보이고 빠진 구간은 건너뛴다.
- 명예의 전당에서 `me`가 없으면 5l을 쓰고 목표 예시는 없다.

### 랭킹 기록

- 시트(5q) 머리는 `랭킹 기록`과 오른쪽 `모두 N번`이다.
- 순위 칩은 `전체 · 1위 · 2위 · 3위`이고 메달을 3열로 6개까지 놓는다.
- 메달을 누르면 6장 방식으로 판을 적고 시트를 닫는다.
- 시트 아래 `N개 모두 보기 ›`는 `/ranking/records`로 간다.
- 기록이 없으면(5s) 왕관 그림, `아직 TOP 3 기록이 없어요`, 안내 한 줄, `best`·`closest` 줄, 집중 시작 버튼을 두고, 없는 줄은 뺀다.
- 모두 보기(5r)는 `ScreenBackHeader`(`랭킹 기록`, 뒤로가기 폴백 `/ranking`), 요약 카드, 순위 칩, `모든 종목 ▾`, 달별 목록 순서다.
- 걸러서 남는 기록이 없으면 `조건에 맞는 기록이 없어요`를 보여준다.
- 기록 요약(`records/summary`)은 15초 폴링 대상이 아니다. 랭킹 탭에 들어올 때와 기록 시트를 열 때 받고, 메달은 마감 때만 바뀐다(BE 전달사항).

### 그 밖

- 로딩 중에는 시상대·카드·목록 모양의 Skeleton을 보여준다.
- 오류가 나면 `ErrorState`(재시도 버튼)를 보여주고, `ErrorState`와 `trackErrorRetryPressed`의 화면 유니온에 `ranking`을 더한다.
- 기기 등록 전과 첫 토큰 대기는 홈과 같은 방식으로 처리한다.
- 닉네임은 한 줄이고 칸 너비에서 말줄임하며, 숫자 칸을 먼저 잡고 남은 폭을 닉네임에 준다.
- 칩, 메달 버튼, 목록 줄, 메달은 누르는 영역을 44px 이상으로 둔다.
- 라이트와 다크를 모두 만든다.

| 대상             | 규칙                                                                    | 예                                                                           |
| ---------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 순위             | 세 자리마다 쉼표                                                        | `1,205`                                                                      |
| 시간 판 값       | `H:MM:SS`, 시는 자르지 않음                                             | `13:11:00`, `41:20:00`                                                       |

| 시간 차이        | 1시간 미만은 분 올림(최소 1분), 이상은 시간·분                          | `22분`, `3시간 20분`                                                         |
| 집중률 차이      | 소수 1자리                                                              | `0.4%`                                                                       |

| 기록 항목 이름   | 시간대는 구간 이름만                                                    | `오전 구간`, `순공`, `집중률`                                                |

| 기록 항목 값     | 시간은 `H:MM:SS`, 집중률은 %                                            | `3:04:20`, `98.7%`                                                           |

- 마감 남은 시간은 1분마다 다시 센다.
- 누적 시간이 딱 맞는 시간이면 `0분`을 붙이지 않고 `419시간`으로 쓴다.
- 일수 판은 공동 순위라 `above`가 나와 일수가 다른 가장 가까운 사람이고, 그 사람과 일수가 같아지면 같은 순위가 되므로 차이를 그대로 `다음 순위까지 N일`로 쓴다.
- 배포 전 응답처럼 차이가 0으로 오면 `다음 순위까지 1일`로 쓴다.
- `N월 N주`는 기록 탭의 주 표기 함수를 그대로 쓴다.
- 진행바 폭은 `max(6, round(100 × (1 − 차이 ÷ 창)))`%다.

## 11. 네이티브 탭 · 브리지 · 앱 버전 표시

- `app/(tabs)/ranking.tsx`는 기록 탭과 같은 틀로 `RemoteScreen path="/ranking"`과 `RankingTabSkeleton`을 쓴다.

## 16. PR ② 개요

| 화면             | 데이터                           | 정한 것                                                                                                    |
| ---------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 5b 홈 한 줄 카드 | `home?since=`                    | 연속 공부 카드 바로 아래에 둔다. `card`가 null이면 안내 문구를 보여준다. 누르면 `순공 · 주간`으로 넘겨준다 |
| 5a 추월 팝업     | `home`의 `overtaken`             | 그날(KST) 첫 접속이고 `overtaken`이 있을 때만 하루 1회 띄운다. `since`는 `loadLastHiddenAt`을 쓴다         |
| 5t~5w 마감 모달  | `records/unseen`, `records/seen` | 4개 이상이면 금·은·동 요약, 높은 순위 3개, `외 N개`를 둔다. 띄운 직후 `seen`을 보낸다                      |
| 홈 팝업 순서     | 없음                             | 공지 판단이 끝나고 공지·인터뷰·복구 창이 하나도 안 뜬 실행에서만 랭킹 팝업을 본다. 마감 모달이 먼저다      |
| 5i 결과 카드     | `session-gains?startedAt=`       | 오른 판이 있을 때만 세션 결과 바로 아래에 둔다. 솔로·소셜 결과 모두에 둔다                                 |

- 모든 진입점은 `hasRankingTab()`이 참일 때만 보인다.
- 집중 시작은 `useFocusStart`를 쓴다.
- 마감 모달이 뜬 날에는 추월 팝업을 띄우지 않는다.
- `records/unseen`은 한 번에 최대 100개를 주고, `seen`으로 표시한 뒤 다시 부르면 나머지가 온다(BE 전달사항).
- `records/seen`의 `ids`는 최대 100개이고 넘으면 400이며, 빈 배열은 아무것도 하지 않는다(BE 전달사항).
- 순공 1분 미만으로 끝난 세션은 결과 화면이 없어 `session-gains`를 부르지 않는다.
- `session-gains`는 그 `startedAt`으로 제출된 내 세션이 없을 때만 404를 준다. 오류가 아니라 오른 랭킹이 없는 것으로 처리한다(BE 전달사항).
- 순공 1분 미만 세션은 저장되지만 랭킹에서 빠져서 200에 `weekly: null`, `others: []`가 온다. 지금 앱은 1분 미만이면 결과 화면을 띄우지 않아 호출할 일이 없다(BE 전달사항).
- 자정을 넘긴 세션은 서버가 날짜별 조각마다 1분 기준을 봐서, 앱 기준 1분 이상이어도 빈 응답이 올 수 있다. 빈 응답이면 `랭킹이 올랐어요` 영역을 숨긴다(BE 전달사항).
- 랭킹 집계는 순공 1분 미만 조각을 빼고, 10분은 연속 공부 인정 기준이다(`StudySessionThresholds`).
- `home`의 `since`는 추월 팝업을 띄울 그날 첫 접속에만 붙인다. `since`가 있으면 호출마다 이번 주 전체를 다시 집계하므로, 나머지 홈 호출은 `since` 없이 부른다(BE 전달사항).

## 17. 후속 조치

- BY-828의 `eligibility.expectedTopPercent`는 BE가 추가해 dev에 배포했고(`me.topPercent`와 같은 식), 5m의 상위 % 줄을 실기기로 확인한다.
- .ai#23에 홈 팝업 순서, 진행바 창, 5m 상위 %, 5b 빈 카드 문구, 빈 상태 구분 규칙을 더한다.
- 디자인에 5k 시안의 맞지 않는 부분을 알린다: 순공 일간판인데 제목이 `새벽 구간 TOP 3`이고, 시상대의 `나`와 `지금 시작하면 3위예요`가 함께 있고, 마감이 `00시 마감`이 아니라 `마감 23시간 56분`이다.
