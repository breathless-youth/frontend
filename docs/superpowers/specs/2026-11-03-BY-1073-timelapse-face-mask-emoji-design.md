# 타임랩스 얼굴 가림 보완과 이모지 고르기 설계 (BY-1073)

## 목표

타임랩스 얼굴 가림을 켠 세션에서 고개를 숙이거나 돌려도 사진에 얼굴이 남지 않게 한다.
가림 그림을 포메라니안 스티커에서 소셜룸과 같은 동물 이모지 9개 중 사용자가 고른 것으로 바꾼다.
위치 계산은 소셜룸 얼굴 가리기(`2026-10-31-BY-1092-social-face-mask-design.md`)의 `nextFaceSpot`을 그대로 쓴다.

## 문제

- 가림 사진은 얼굴 모델이 본 프레임으로 만들고, 그 프레임에서 찾은 얼굴 위치에만 스티커를 덮는다.
- 고개를 숙이거나 돌리면 얼굴 모델이 얼굴을 놓치는 경우가 많고, 이때 사진이 스티커 없이 저장된다.
- 얼굴 모델을 불러오지 못한 세션은 사람이 보이는 장면을 아예 찍지 않아, 위키의 "얼굴 모델을 불러오지 못한 세션도 저장한다"와 어긋난다.

## 동작

### 촬영

- 한 프레임의 순서는 객체 검출, 상태 판정, 촬영 요청 확인, 얼굴 추론, 위치 갱신, 촬영이다.
- 사진은 얼굴 추론 안에서 같은 프레임으로 만들어지므로, 얼굴 추론 전에 `nextFaceSpot(faceSpot, { face: undefined, ... })`로 어림 자리를 구해 사진 요청(`PhotoSpec`)에 싣는다.
- 그리는 쪽은 그 프레임에서 얼굴 랜드마크를 찾으면 랜드마크로 자리를 구하고, 없으면 실려 온 어림 자리를 쓴다.
- 가림이 켜져 있고 사람이 보이면 지금처럼 얼굴 틱에서 찍는다.
- 얼굴 모델이 없거나 꺼진 세션은 얼굴 틱을 기다리지 않고, 어림 자리를 실어 추론 없이 찍는다.
- 사람이 없는 장면은 지금처럼 가림 없이 찍는다.
- 가림을 끈 세션은 바뀌지 않는다.

### 그리기

- 이모지 크기는 `FaceSpot`처럼 프레임 폭 기준 정사각형이다.
- 얼굴을 찾은 자리는 소셜룸과 같은 배율로 덮는다.
- 어림 자리는 그보다 큰 배율로 덮는다.
- 이모지 주소는 `PhotoSpec`으로 워커까지 넘긴다. 워커는 설정 저장소를 읽을 수 없다.
- 이모지 그림은 주소별로 한 번 받아 기억한다. 받지 못하면 사진을 남기지 않고 실패를 알린다.

### 설정 화면

- 얼굴 가림 스위치 아래에 이모지 줄을 넣는다. 소셜룸 확인 창과 같은 가로 스크롤 `ToggleGroup`이다.
- 스위치가 꺼져 있으면 이모지 줄을 흐리게 보이고 고르지 못하게 막는다.
- 설정 미리보기는 고른 이모지로 그린다.

## 개인정보

- 얼굴 위치 좌표는 사진에 그리는 데만 쓰고 진단 로그, 분석 이벤트, 서버로 보내지 않는다.
- 가림을 켠 세션에서 사람이 보이는 사진은 저장 전에 덮이므로 그 얼굴은 기기에 남지 않는다.
- 함께 찍힌 다른 사람 얼굴은 이번에도 가리지 않는다.

## 범위 밖

- 이미 기기에 저장된 사진은 다시 처리하지 않는다.
- 추론 주기(`FRAME_INTERVAL_MS` 1000, 얼굴 2초)는 바꾸지 않는다.

## 테스트

- 그리기: 얼굴을 놓친 프레임에서 어림 자리에 이모지가 덮인다. 랜드마크가 있으면 랜드마크 자리가 이긴다. 주소가 다르면 그림을 따로 받는다.
- 감지기: 얼굴 모델이 없는 세션에서 사람이 보이면 어림 자리를 실어 찍는다. 사람이 없으면 가림 없이 찍는다. `visible=false`여도 덮는다.
- 설정: `faceMaskEmoji` 파싱과 기본값, 옛 기록 대체, 이모지 줄 선택이 저장되고 이벤트가 나간다, 툴팁 문구.
- 미리보기: 고른 이모지로 그린다.
- 진단 로그 타입이 좌표를 받지 않는 상태가 유지된다.
