# BY-779 v2 디자인 UI 팀 내부 피드백 반영 설계

스토리 BY-779 아래 하위 작업 네 개(BY-780~783)를 브랜치 `feature/BY-779-v2-ui-feedback` 하나에서 처리한다. base는 `dev`다. 커밋은 하위 작업마다 하나씩 네 개로 나눈다.

## BY-780 배경음

### 전체 켜기·끄기

- 배경음 시트 맨 위, 제목 줄 아래·탭 위에 `배경음` 줄과 Switch를 둔다. 모양은 시트 하단의 `집중 연동` 줄과 같다.
- 스위치 상태는 믹스에 켜진 소리가 하나라도 있는지(`isOn`)를 그대로 보여 준다.
- 끄면 `changeMix({}, "dialog")`로 모든 소리를 멈춘다.
- 켜면 저장된 `lastMix`를 `changeMix(lastMix, "dialog")`로 되살린다.
- `lastMix`가 비어 있으면(한 번도 튼 적 없음) 스위치는 꺼진 채 비활성이다.

### 저장

- `AmbientSoundSettings`에 `lastMix: Mix`를 더한다. 키 `focuson.ambientSound.v1`은 그대로 쓴다.
- `commit`에서 새 믹스가 비어 있지 않으면 `lastMix`를 그 믹스로 갱신한다. 비어 있으면 이전 `lastMix`를 유지한다.
- 불러올 때 `lastMix`가 없거나 비어 있고 `mix`가 비어 있지 않으면 `mix`를 첫 `lastMix`로 쓴다(기존 사용자).
- `lastMix`도 `parseMix`를 거쳐 잘못된 값을 버린다.
- 분석 이벤트는 기존 `ambient_sound_changed`에 `source: "dialog"`로 나간다. 이벤트 형식은 바뀌지 않는다.

### ♪ 진입 버튼

- 오른쪽 위 절대 배치를 없애고 하단 컨트롤 바 안에 넣는다. 순서는 일시정지 · 카메라 전환 · ♪ · 나가기다.
- 컨트롤 바는 ♪ 버튼 자리를 슬롯으로 받는다. 멀티룸 바(`RoomControlBar`)에는 넣지 않는다.
- 모양은 바의 기본 버튼과 같은 54px 원이다. 소리가 켜져 있으면 아이콘이 `--state-focus` 색이 된다.
- `aria-haspopup="dialog"`·`aria-expanded`와 닫은 뒤 포커스를 돌려주는 동작(`triggerRef`)은 그대로 둔다.

- 새 테스트는 상태·aria·텍스트만 단언한다.

- 확인 대상은 다음과 같다.
  - `useAmbientSound`: 전체 끄기와 복원, 복원할 조합이 없을 때

  - 설정 화면: 토글 버튼 이름과 전송 메시지, 라벨은 버튼이 아니다
- 필·바 테두리와 색, 누적 글자 크기는 테스트하지 않는다. 라이트·다크 스크린샷으로 확인한다.

## 부가 기능 버튼 분리 (2026-09-30 변경, BY-780 "♪ 진입 버튼" 절을 대체)

배경음과 카메라 전환은 하단 바에서 빼서 화면 오른쪽 아래의 부가 기능 버튼으로 둔다(1depth).

- 하단 바에는 일시정지와 공부 종료만 남는다(폭 142px). `SessionControlBar`의 `ambientSlot`과 카메라 전환 관련 props는 지운다.

- 버튼은 44px 원이다. 바 컨테이너와 같은 유리 질감(`--session-bar-glass-*` 배경·블러·그림자, 테두리 없음, 라이트·다크를 따른다)이다. 아이콘은 배경음 20px, 카메라 전환 24px이다(28px 프레임 기준 벡터라 20px이면 가늘어 보인다).
- 자리는 화면 오른쪽 끝에서 16px(오른쪽 안전영역 포함), 버튼 줄 아랫선이 하단 바 아랫선과 같은 높이다. 세로·가로가 같다. 버튼 사이 간격은 12px이다. 바 윗선 위에 두면 폭 320px 화면에서 타이머 숫자와 카메라 전환 버튼이 겹쳐서 바 옆으로 내렸다(2026-09-30 확인).
- 심플 모드에서는 카메라 전환 버튼을 숨긴다. 배경음 버튼은 남는다.
- 배경음 버튼의 `aria-haspopup`·`aria-expanded`, 켜짐 색, 시트를 닫은 뒤 포커스 복귀는 그대로다.
- 카메라 전환의 화살표 반바퀴 회전과 Figma 28px 기준 아이콘은 그대로 옮긴다. 이 버튼에서는 44px 원 안에 맞게 그린다.
- 멀티룸 바(`RoomControlBar`)는 바꾸지 않는다.
- Figma 세션 화면 14개도 같게 고친다. 바는 2칸, 오른쪽 아래에 부가 기능 2개(심플 화면은 배경음 하나)다.

## 부가 기능 버튼 자리·크기 변경 (2026-09-30 두 번째 변경, 위 절의 순서·자리·크기 문장을 대체)

- 순서는 위에서 아래로 배경음, 카메라 전환이다. 위를 기준으로 붙이므로 심플 모드에서 카메라 전환이 빠져도 배경음은 움직이지 않는다.
- 버튼은 하단 바 버튼과 같은 54px 원이다. 모양도 바의 기본 버튼과 같게 맞추고(`--session-btn-default-*`), 바 밖에 떠 있으므로 유리 배경·블러·그림자는 유지한다. 아이콘은 배경음 23px, 카메라 전환 28px이다.
- 세로 화면에서 묶음 윗선은 "상태 필 아랫선 + 필과 화면 위끝 사이 간격" 지점이다. 코드 값으로 안전영역 위 13px + 필 38px + 13px = `calc(env(safe-area-inset-top)+64px)`이다.
- 가로 화면은 필 기준이면 오른쪽 위 타이머와 겹치므로 "타이머 아랫선 + 같은 위 간격"이다. 안전영역 위 18px + 타이머 60px(42+3+15) + 18px = `calc(env(safe-area-inset-top)+96px)`이다. 가로 심플 모드도 같은 자리를 쓴다.
- 오른쪽 끝에서 16px(안전영역 포함), 버튼 사이 12px은 그대로다.
- Figma는 필이 22px 아래에 있어 세로 윗선 82(60+22), 가로 윗선 109(타이머 아랫선 89+20)로 둔다.

- Figma는 9개 배너의 링크 위 여백을 8에서 14로 바꿔 같은 18px을 맞춘다. 글자 스타일은 폰트 잠금으로 사용자가 직접 고친다.

## ⓘ 버튼 보이는 크기 (2026-09-30)

- 공용 `InfoTooltip`의 버튼이 44px(`size-11`)을 실제 크기로 차지해 글자와 아이콘 사이가 홈 스트릭 19px, 설정 카메라 권한 행 21px로 벌어졌다.
- 버튼의 보이는 크기를 아이콘 크기로 줄이고, 44px 이상의 터치 영역은 보이지 않는 `after` 가상 요소로 바깥에 덧댄다. 배경음 시트 ⓘ와 같은 방식이다.
- 보이는 간격은 부모 `gap`만 남는다(스트릭 4px, 설정 6px). 탭·키보드 동작은 그대로다.

## 공용 버튼 눌림 효과 (BY-791, 2026-09-30)

- `buttonVariants` 기본 클래스에 눌림 상태를 넣는다. 누르는 동안 98%로 줄고 85%로 흐려진다. `transform`·`opacity`·`background-color` 전환 150ms, ease-out이다.
- 모션 줄이기 설정에서는 크기를 바꾸지 않고 흐려지기만 한다.
- `unstyled` 호출부(세션 바 등)의 자체 눌림 클래스가 병합으로 이기므로 기존 동작이 유지돼야 한다.

## 비집중 필 색 (BY-781, 2026-09-30)

- 비집중 필 배경을 디자인 시스템 경고 색 `#ff8a00`(state-distract) 불투명으로 바꾸고, 글자를 진한 남색 `#1f2a3d`로 바꾼다. 흰 글자로는 선명한 주황과 대비 4.5를 함께 얻을 수 없어서다. 대비는 약 6:1이다.
- 값은 `sessionTheme.ts`의 세션 변수(`--session-pill-bg-distract`, 새 `--session-pill-fg-distract`)에만 둔다.
- 측정 중·일시정지 필은 그대로다.

## 설정 버전 복사 아이콘 위치 (BY-783, 2026-09-30)

- 복사 버튼이 44px을 실제 크기로 차지해 아이콘이 위 행 셰브론보다 약 12px 안쪽에 있었다.
- 버튼의 보이는 크기를 아이콘(16px)으로 줄이고 44px 이상의 터치 영역은 `after` 가상 요소로 둔다. 아이콘 중심을 셰브론 중심(행 오른쪽 끝에서 10px)에 맞추도록 오른쪽 2px 여백을 둔다.
- 버전 글자와 아이콘 사이는 8px이다.

## 실기기 확인 뒤 최종값 (2026-09-30)

앞 절들과 다른 값은 이 절이 우선한다.

- 공용 버튼 눌림은 99%로 줄고 85%로 흐려진다. 결과 화면 CTA도 99%다.
- 세션 하단 바와 부가 기능 버튼 눌림은 95%다. 모션 줄이기에서는 크기가 변하지 않는다.
- 비집중 필은 배경 `#f0a257`, 글자 `#1f2a3d`다. 대비는 약 6.9다.
