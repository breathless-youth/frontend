# BY-975 소셜룸 버튼 네이티브 glass 설계

상위 BY-714(소셜룸 UI/UX 개선)의 마지막 하위 작업이다. 싱글룸 세션 버튼(BY-965)과 같은 `useNativeControl` 방식으로 소셜룸 하단 바 버튼을 iOS 앱의 glass 버튼으로 그린다. 앱(Swift)은 고치지 않고 웹만 바꾼다.

## 조사 결과

- 앱에는 소셜룸을 막는 코드가 없다. 지금 glass로 안 그려지는 것은 웹이 등록하지 않아서다(`apps/web/CLAUDE.md`의 "라이브룸 하단 조작 바는 등록하지 않는다", ADR 0018, 배경음 `native={false}`, 테스트 두 곳).
- 앱 릴리즈는 어차피 필요하다. 싱글룸 glass(BY-957·BY-965)도 아직 main과 스토어 빌드에 없다. 이 작업은 웹만 바꾸므로 다음 앱 릴리즈와 함께 켜진다.
- 바는 5초 자동 숨김 때 `translate-y` 500ms로 미끄러져 내려가는데, 앱은 transform 이동을 따라가지 못한다(크기 변화가 없어 다시 측정되지 않는다).
- 더보기 `DropdownMenu`는 `aria-modal`이 없어 열려도 앱 부품이 숨지 않는다.
- 바의 카메라·나가기 아이콘은 `<img>`라 `measureIcon`(첫 `svg`만 측정)이 크기를 못 잰다.
- 앱 메뉴(UIMenu)는 지원하지 않는다. 쓰려면 Swift와 앱 빌드가 필요하다.

## 결정 (2026-10-26, 사용자가 권장안으로 승인 없이 진행하도록 지시)

- 하단 바의 카메라, 과목, 배경음, 나가기 버튼을 앱 glass 버튼으로 등록한다.
- 더보기 버튼과 메뉴는 웹으로 남긴다. 메뉴가 버튼 자리를 덮으며 열리는데 앱 부품은 늘 웹 위에 그려져 메뉴 위로 겹친다. 앱 메뉴는 Swift 변경이 필요해 범위 밖이다.
- 과목 알약과 시간 글자는 웹으로 남긴다(싱글룸 과목 라벨·상태 필과 같은 이유).
- 바의 유리 배경은 웹으로 남고, 그 위에 앱 버튼만 올라간다.
- 조작이 숨으면 앱 버튼은 `faded`로 0.2초 동안 흐려지고, 웹 바 배경은 지금처럼 미끄러져 내려간다.
- 앱 버튼은 바와 함께 미끄러지도록, 웹이 CSS 전환이 도는 동안 매 프레임 좌표를 다시 재서 앱에 보낸다.
- 이 측정은 `nativeControls.ts`의 공통 관찰에 있어 모든 등록 부품에 적용된다.
- 다시 보일 때는 앱 버튼이 흐림에서 돌아오면서 올라오는 바를 따라간다.
- 처음 구현은 등록 때 한 번만 재서, 숨긴 뒤 다시 부르면 앱 버튼이 화면 밖 자리에 남았다(최종 리뷰에서 WebKit으로 재현했다).
- 더보기 메뉴가 열린 동안 웹 바는 누름을 막는데(`inactive`), 앱 버튼도 같은 동안 `disabled`로 막는다.
- 제출 중 잠금(`controlsLocked`)도 `disabled`로 보낸다.
- 아이콘은 SF Symbol이다. 카메라 켜짐 `video.fill`, 꺼짐 `video.slash.fill`, 과목 `book`, 배경음 `music.note`, 나가기 `rectangle.portrait.and.arrow.right`(과목·배경음·나가기는 싱글룸과 같다).
- 색 역할은 웹 색을 따른다. 카메라 꺼짐은 반투명 빨강이라 `danger`, 켜짐은 `default`, 나가기는 `danger`, 고른 과목과 켜진 배경음은 `active`다.
- 아이콘 폭은 `measureIcon`으로 보낸다. `<img>` 아이콘도 잴 수 있게 측정 대상을 버튼 안 첫 `svg` 또는 `img`로 넓힌다. 크기 배율 `iconScale`은 싱글룸 값을 따른다.
- 구버전 앱과 Android, 브라우저에서는 지금처럼 웹 버튼이 그려진다(`useNativeControl`의 기존 대체 경로).
- `apps/web/CLAUDE.md`와 ADR 0018의 "라이브룸 하단 조작 바는 등록하지 않는다"는 문장을 이번 결정으로 고친다.
- Figma와 위키는 바꾸지 않는다. 버튼 모양과 정책이 그대로이고, 앱이 그리는 glass는 실기기에서 확인한다.

## 테스트

- 앱이 `button-style`을 알린 환경에서 바 버튼 4개가 정한 id·심볼·색 역할로 등록되고 웹 원본이 숨는다.
- 조작이 숨으면 4개 모두 `faded`가 참이 되고, 다시 보이면 거짓이 된다.
- 더보기 메뉴가 열리면 4개 모두 `disabled`가 참이 되고, 닫히면 원래대로 돌아온다.
- 카메라를 끄면 심볼이 `video.slash.fill`, 색 역할이 `danger`로 바뀐다.
- 과목을 고르거나 배경음을 켜면 그 버튼의 색 역할이 `active`가 된다.
- 앱 버튼 누름이 웹 버튼과 같은 동작(카메라 토글, 과목 페이지, 배경음 페이지, 나가기 확인)을 부른다.
- 앱이 glass를 알리지 않은 환경에서는 등록 메시지가 나가지 않고 웹 버튼이 보인다.
- `<img>` 아이콘 버튼의 아이콘 폭이 `iconSize`로 나간다.

## 범위 밖

- 더보기 앱 메뉴(Swift 변경).
- 앱이 프레임 사이를 보간하는 일. 웹이 프레임마다 보내는 좌표로 충분한지는 실기기에서 본다.
- 실기기 확인: glass 모양과 크기, 숨김·표시 때 배경과 버튼의 어긋남, 회전, 태블릿, 페이지·확인 창이 열릴 때 앱 버튼이 숨는지.
