## 1. 시계 라벨과 보기 형식 (BY-1278)

- `SessionClock`에 `view: "focus" | "study"`를 더한다.
  - `focus`: 큰 숫자는 `focusSec`, 오늘 줄은 `todayFocusSec`.
  - `study`: 지금처럼 `studySec`, `todayStudySec`.
- 위 라벨은 집중일 때 `현재 집중`(또는 `현재 공부`)이고, 다른 상태에서는 상태 문구가 그 자리를 대신한다(지금 구조 유지).
- 오늘 순공은 플래너 하루 조회의 `focusSec`에 이번 세션 순공을 더한다. `loadTodayStudySec`를 오늘 공부·순공을 함께 돌려주는 함수로 넓힌다.
- 비집중 문구는 `status.away/phone/device/sleep`를 화면에서 하나의 키 `status.distracted`(`자리를 확인해 주세요`)로 바꾼다. 원인별 키는 기록·분석에서 계속 쓰므로 지우지 않는다.
- 비집중에서 숫자 색은 회색으로 둔다. 순공 보기에서는 숫자가 저절로 멈춘다.
- 심플 모드는 시간을 가운데 두고 오늘 줄을 숨긴다. 월페이퍼 좌하단 배치는 같은 보기 값을 따른다.
- 보기 값은 `localStorage`(`focuson.sessionClockView.v1`, 마스코트 설정과 같은 규칙)에 저장한다. 설정 화면과 세션 화면이 다른 웹뷰라 같은 주소 저장소를 쓴다.
- 더보기 메뉴에 `공부 시간으로 보기`/`순공으로 보기` 항목을 더한다.
- 이벤트: `session_clock_view_changed { view }`.

## 2. 일시정지 휴식 화면과 앱 안 알림 (BY-1280)

- `useStudyRoomSession`이 일시정지 시작 시각(`pausedSinceMs`)을 함께 돌려준다. 지금은 내부에만 있다.
- 새 컴포넌트 `SessionRestOverlay`
  - 싱글룸에서 `PAUSE`이고 이유가 `BREAK`가 아닐 때 세션 화면 위에 뜬다. 하단 바(다시 시작·종료)는 덮지 않는다.
  - 배경을 블러 처리하고 어둡게 한 뒤(시안 값 `blur 18px`, `rgba(16,18,24,0.45)`), 흑백 마스코트, `쉬는 중` 라벨, 휴식 시간을 보인다.
  - 휴식 시간은 `pausedSinceMs`부터 올라간다(`mm:ss`, 1시간이 넘으면 `h:mm:ss`).
  - 우하단 말풍선 3개(`5분 휴식 후 알림`·`10분 휴식 후 알림`·`알림 없음`)는 하나만 고르는 라디오 그룹이다. 기본값은 `알림 없음`이고, 일시정지할 때마다 기본값으로 시작한다.
  - 알림을 고르면 라벨이 `쉬는 중 · N분 뒤 알려줄게요`가 되고, 숫자는 남은 시간을 거꾸로 센다.
  - 시간이 되면 멀티 타이머의 알림음(`alarmSound`)과 `haptic("alert")`로 알린다. 라벨은 `휴식이 끝났어요`, 숫자는 총 휴식 시간으로 돌아가고 말풍선은 `알림 없음`이 된다.
  - 다시 시작·종료·자동 종료하면 예약을 취소한다.
- 앱을 나가 있다 돌아오면 웹뷰 시각으로 다시 계산한다. 이미 지난 알림은 앱 안에서 다시 울리지 않고 `휴식이 끝났어요` 상태로 보인다.
- 심플 모드와 월페이퍼 모드에서도 같은 화면을 띄운다. 가로 화면은 시안 2c·3g 배치를 따른다.
- 이벤트: `session_rest_alarm_set { minutes }`, `session_rest_alarm_fired { channel: "in_app" | "os" }`. 알림이 앱 밖에서 울렸는지는 웹이 알 수 없어, 돌아왔을 때 지난 알림이 있으면 `os`로 남긴다.

## 3. 휴식 종료 OS 알림 (BY-1281)

- 앱에 `expo-notifications`를 추가하고 Android에 `USE_EXACT_ALARM`을 선언한다.
- 브리지 메시지(웹 → 앱)
  - `schedule-rest-notification { id, fireAtMs, title, body }`
  - `cancel-rest-notification { id }`
- 앱은 날짜 트리거로 예약한다. 같은 `id`로 다시 예약하면 앞의 것을 취소한다.
- 기능 플래그: 새 앱은 웹뷰 주소에 `restNotify=1`을 붙인다. 이 값이 없으면 웹은 말풍선을 숨긴다(`alertHaptic=1`과 같은 방식).
- 권한: 처음 알림을 고를 때 기존 `request-push-permission` 브리지로 한 번만 요청한다. 거부되면 앱 안 알림만 울린다.
- iOS 처리기: RNFB가 이미 알림 처리기를 갖고 있어 `expo-notifications`는 자기 처리기를 설치하지 않는다. 예약은 처리기와 상관없이 울린다. 앱이 앞에 있을 때는 앱 안 알림이 울리므로, OS 알림이 보이지 않는 것이 맞다. 이것은 실기기에서 확인한다.
- Android 알림 채널 `rest`를 만들고, 상태 표시줄 아이콘은 기존 `notification_icon`을 쓴다. `expo-notifications` 플러그인은 아이콘을 받지 못하면 RNFB가 넣은 FCM 아이콘 항목을 지우므로 같은 그림을 넘긴다. 그러면 그림을 복사하던 `withNotificationIcon` 플러그인은 할 일이 없어져 지운다.
- 알림을 누르면 앱이 열리고 세션 화면으로 돌아간다. 따로 딥링크를 붙이지 않는다.

## 4. 추가 타이머·스톱워치 칩 (BY-1282)

- 멀티 타이머 상태 기계에 `stopwatch` 종류를 더한다. 0부터 올라가고, 세션이 멈추면(`held`) 같이 멈춘다.
- 싱글룸 더보기 메뉴에 `스톱워치`와 `타이머`를 둔다. 뽀모도로 진입은 싱글룸에서 뺀다.
- `타이머`: 시간을 고르는 바텀시트(`SessionTimerSheet`, 기존 `TimerWheel` 재사용)에서 `시작`을 누르면 시트가 닫히고 칩이 생긴다. 칩의 이름을 누르면 같은 시트가 열린다.
- 시트는 고른 시간을 시작 전까지 따로 들고 있다. 돌던 타이머에서 `시작`하면 처음으로 돌려 새 시간으로 다시 시작하고, `취소`는 시작 전일 때만 타이머를 끄고 돌던 타이머는 그대로 둔다.
- `스톱워치`: 메뉴에서 누르면 바로 칩이 생긴다.
- 칩(하단 바 위 40px): 아이콘, 종류 이름, 시간(타이머는 `/ 전체`), `멈춤/계속`, `끄기`. 칩이 있으면 카메라 작은 창이 그만큼 올라간다.
- 타이머가 끝나면 지금처럼 알림음과 진동이 울리고 칩이 사라진다.
- 지금의 전체 화면 타이머(`MultiTimerScreen`·`TimerPanel`·`PomodoroPanel`·`PomodoroDial`)와 전체 화면 잠금 훅은 이제 쓰는 곳이 없어 지운다(사용자 결정). 소셜룸은 자체 시트(`RoomTimerSheet`)와 캡슐을 써서 영향이 없다.
- 이벤트: 기존 `multi_timer_*`에 `kind: "stopwatch"`를 더한다.

## 위험

- `USE_EXACT_ALARM` 심사 거절: 거절되면 권한을 빼고 근사치 예약으로 돌아간다. 절전 중에는 몇 분 늦을 수 있다.
- iOS 처리기 충돌: 앱이 앞에 있을 때 OS 알림이 함께 뜨면 앱 안 알림과 겹친다. 실기기에서 확인하고, 겹치면 웹이 앱 안 알림을 울릴 때 같은 `id`의 예약을 취소한다.
- 오늘 순공 중복 합산: 이어받은 세션에서 서버의 오늘 값에 이번 세션 몫이 이미 들어 있는지 확인한다. 지금 `오늘 누적` 계산도 같은 문제가 있는지 함께 본다.
- 소셜룸 회귀: `useMultiTimer`·`SessionMoreMenu`·`SessionClock`을 공유하므로 소셜룸 테스트를 함께 돌린다.
