# 태블릿 공부 화면 마스코트 설계 (BY-1271)

- 티켓: BY-1271 (하위 BY-1272 시안·스프라이트 시트, BY-1273 FE)
- 시안: Figma `FocusMakers V3` 스프라이트 `11013:633`, 태블릿 배치 `11040:17697`(세로 기본)·`11040:17762`(세로 심플)·`11040:17819`(가로 기본)·`11040:17884`(가로 심플)
- 선행: BY-1219 싱글 세션 v3 개편 (이 브랜치는 그 위에 쌓았다)

## 목표

AI 측정 중인 태블릿 공부 화면에서 스톱워치 마스코트가 공부 상태에 따라 표정을 바꾼다. v3 개편에서 상태 필이 빠졌고, 표정 변화는 필보다 눈에 덜 띄어서 집중을 덜 방해한다는 판단으로 도입했다.

## 확정한 결정

| #   | 결정            | 내용                                                                                                                                     |
| --- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |

### 표정 표

| 세션 상태                                     | 표정(시트 칸)      |
| --------------------------------------------- | ------------------ |
| `FOCUS`                                       | 집중(1)            |
| `DISTRACTION` + `SLEEP`                       | 졸림(4)            |
| `DISTRACTION` + `PHONE`·`DEVICE`              | 정색(3)            |
| `DISTRACTION` + `AWAY`                        | 놀람(6)            |
| `PAUSE` (직접 멈춤, 화면 꺼짐, 뽀모도로 휴식) | 기본(0)            |
| 집중이 아닌 상태에서 `FOCUS`로 바뀜           | 점프(7) 뒤 집중(1) |

시트 칸 순서는 기본(0), 집중(1), 기쁨(2), 정색(3), 졸림(4), 화남(5), 놀람(6), 점프(7)다.

## 구조

```
sessionState ──▶ mascotExpression.ts ──▶ 표정 칸 번호, 점프 여부
                       (순수 TS)                 │
                                                 ▼
regular 판정 ─┐                       SessionMascot.tsx
켜짐 설정 ────┴──▶ RoomPage가 마운트 여부 결정 ──▶ 상자 안 시트를 translateX로 이동
                                                 깜빡임·점프는 element.animate 한 번씩
더보기 메뉴 항목 ──▶ mascotSettings.ts(localStorage) + trackSessionMascotToggled
```

### 파일

- `features/study-session/mascot/mascotExpression.ts`: 상태를 칸 번호로 바꾸는 함수, 이전 상태와 다음 상태로 점프 여부를 고르는 함수, 깜빡임 키프레임 순서를 둔다.
- `features/study-session/mascot/mascotSettings.ts`: `focuson.sessionMascot.v1` 키에 `"on"`·`"off"`를 읽고 쓴다. 저장소를 쓸 수 없으면 켜짐으로 본다.
- `features/study-session/mascot/SessionMascot.tsx`: 시트 이미지 한 장을 상자 안에 두고 칸을 옮긴다.
- `assets/session/mascot-stopwatch-sprite.webp`: 1770×216px 무손실 WebP다. 칸은 72pt(3배 216px), 간격 2pt(3배 6px)다.
- `RoomPage.tsx`: 하단 바를 `relative` 상자로 감싸고 마스코트를 그 왼쪽 바깥에 둔다. 바(`role="toolbar"`) 안에는 넣지 않는다.
- `SessionMoreMenu.tsx`: 태블릿에서만 켜고 끄기 항목을 추가한다.
- `lib/amplitude.ts`: `trackSessionMascotToggled(visible)`를 추가한다.

### 칸 이동 계산

상자 크기를 `--mascot-box`로 두고, 시트 이미지 폭은 `var(--mascot-box) * 590 / 72`, 칸 이동은 `translateX(calc(var(--mascot-box) * -74 / 72 * n))`로 계산한다. 590pt는 시트 전체 폭이고 74pt는 칸 72pt와 간격 2pt를 더한 값이다. 칸 사이 간격이 투명해서 소수 배율에서도 옆 칸이 비치지 않는다.

### 깜빡임과 점프

- 깜빡임은 4~6초 사이 무작위 간격의 `setTimeout`이 시트 이미지에 `element.animate()`를 한 번 건다. 키프레임은 칸 이동 값을 `steps`로 넘겨 화남, 정색, 화남을 거쳐 원래 칸으로 돌아온다.
- 옛 WebKit이 애니메이션 키프레임 안의 CSS 변수를 풀지 못할 수 있어서, 깜빡일 때 상자 폭을 px로 측정해 키프레임에 px 값을 넣는다. 폭이 0이면 그 깜빡임은 다음 차례로 미룬다.
- 표정이 바뀌면 진행 중인 깜빡임을 `cancel()`하고 타이머를 다시 잡는다.
- `document.hidden`이면 타이머를 걸지 않고, `visibilitychange`로 다시 보이면 새로 잡는다.
- `prefers-reduced-motion`이면 깜빡임, 점프, 눌림 동작을 모두 건너뛰고 칸만 바꾼다.
- 점프는 상자에 `translateY` 애니메이션을 걸고, 끝나면 칸을 집중으로 바꾼다.

## 성능

- 컴포넌트는 `sessionState`가 바뀔 때만 다시 그려진다. 매초 바뀌는 시간 값은 넘기지 않는다.
- 움직임은 `transform`과 `opacity`만 바꿔 레이아웃과 페인트를 다시 하지 않는다.
- 이미지는 `decoding="async"`로 한 번만 받는다. 폰과 꺼짐 상태에서는 요청 자체가 없다.
- 실기기 성능 측정은 하지 않는다(사용자 결정).

## 범위 밖

- 폰 화면, PC 공부 화면(BY-1199·BY-1202 때 패널 왼쪽 바깥 72pt로 구현), PC PiP 창

## 테스트

- `mascotExpression`: 상태별 칸 번호, 점프 조건(집중 아닌 상태에서 집중으로, 시작 때는 아님, 집중에서 집중은 아님)
- `mascotSettings`: 기본값 켜짐, 저장한 값 읽기, 저장소 예외 때 켜짐
- `SessionMascot`·`RoomPage`: 폰 폭에서 마운트하지 않음, 태블릿 폭에서 상태에 맞는 칸으로 이동, 꺼짐 설정이면 마운트하지 않음
- `SessionMoreMenu`: 태블릿에서만 항목이 보이고 누르면 설정과 이벤트가 바뀜
