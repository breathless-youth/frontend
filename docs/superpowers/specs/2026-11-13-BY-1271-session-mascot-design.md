# 공부 화면 마스코트 설계 (BY-1271)

- 티켓: BY-1271 (하위 BY-1272 시안·스프라이트 시트, BY-1273 FE)
- 시안: Figma `FocusMakers V3` 스프라이트 `11013:633`, 태블릿 배치 `11040:17697`(세로 기본)·`11040:17762`(세로 심플)·`11040:17819`(가로 기본)·`11040:17884`(가로 심플)
- 선행: BY-1219 싱글 세션 v3 개편 (이 브랜치는 그 위에 쌓았다)

## 목표

AI 측정 중인 싱글룸 공부 화면에서 스톱워치 마스코트가 공부 상태에 따라 표정을 바꾼다. v3 개편에서 상태 필이 빠졌고, 표정 변화는 필보다 눈에 덜 띄어서 집중을 덜 방해한다는 판단으로 도입했다.

### 표정 표

| 세션 상태                                     | 표정(시트 칸)      |
| --------------------------------------------- | ------------------ |
| `FOCUS`                                       | 집중(1)            |
| `DISTRACTION` + `SLEEP`                       | 졸림(4)            |
| `DISTRACTION` + `PHONE`·`DEVICE`              | 정색(3)            |
| `DISTRACTION` + `AWAY`                        | 스톱워치 실루엣(8) |
| `PAUSE` (직접 멈춤, 화면 꺼짐, 뽀모도로 휴식) | 기본(0)            |

시트 칸 순서는 기본(0), 집중(1), 기쁨(2), 정색(3), 졸림(4), 화남(5), 놀람(6), 점프(7), 스톱워치 실루엣(8)이다. 기쁨, 놀람, 점프는 시트에만 있고 지금은 쓰지 않는다.

## 구조

```
sessionState ──▶ mascotExpression.ts ──▶ 표정 칸 번호, 전환 키프레임
                       (순수 TS)                 │
                                                 ▼
                                      SessionMascot.tsx
켜짐 설정 ───────▶ RoomPage가 마운트 여부 결정 ──▶ 상자 안 시트를 translateX로 이동
                                                 전환·깜빡임은 element.animate 한 번씩
더보기 메뉴 항목 ──▶ mascotSettings.ts(localStorage) + trackSessionMascotToggled
```

### 파일

- `features/study-session/mascot/mascotExpression.ts`: 상태를 칸 번호로 바꾸는 함수, 깜빡임 키프레임 순서, 새 칸으로 넘어가는 전환 키프레임을 만드는 함수를 둔다.
- `features/study-session/mascot/mascotSettings.ts`: `focuson.sessionMascot.v1` 키에 `"on"`·`"off"`를 읽고 쓴다. `"on"`일 때만 켜짐이고, 값이 없거나 저장소를 쓸 수 없으면 꺼짐으로 본다.
- `features/study-session/mascot/SessionMascot.tsx`: 시트 이미지 한 장을 상자 안에 두고 보이는 칸을 바꾼다.
- `assets/session/mascot-stopwatch-sprite.webp`: 칸 9개를 이은 1992×216px 무손실 WebP다. 칸은 72pt(3배 216px), 간격 2pt(3배 6px)이고 전체 폭은 664pt다.
- `RoomPage.tsx`: 하단 바를 레이어 폭을 다 쓰는 `relative` 줄 상자로 감싸 바를 가운데에 두고, 마스코트를 그 줄의 왼쪽 끝에 둔다. 바(`role="toolbar"`) 안에는 넣지 않는다.
- `SessionMoreMenu.tsx`: 켜고 끄기 항목을 추가한다.
- `lib/amplitude.ts`: `trackSessionMascotToggled(visible)`를 추가한다.

### 칸 이동 계산

상자 크기를 `--mascot-box`로 두고, 시트 이미지 폭은 `var(--mascot-box) * 664 / 72`, 칸 이동은 `translateX(calc(var(--mascot-box) * -74 / 72 * n))`로 계산한다. 664pt는 칸 9개와 간격 8개를 이은 시트 전체 폭이고 74pt는 칸 72pt와 간격 2pt를 더한 값이다. 칸 사이 간격이 투명해서 소수 배율에서도 옆 칸이 비치지 않는다.

### 표정 전환과 깜빡임

- 표정이 바뀌면 보이는 칸은 곧바로 새 칸이 되고, 화면이 그려지기 전에 시트 이미지에 전환 애니메이션을 한 번 건다. 각 키프레임은 `steps(1, end)`라 칸이 섞이지 않고 끊어서 넘어간다.
- 깜빡임은 4~6초 사이 무작위 간격의 `setTimeout`이 시트 이미지에 `element.animate()`를 한 번 건다. 키프레임은 화남, 정색, 화남을 거쳐 원래 칸으로 돌아온다. 기본과 집중 표정에서만 깜빡인다.
- 깜빡임 타이머는 전환이 끝난 뒤에 잡아서 전환과 깜빡임이 겹치지 않는다.
- 옛 WebKit이 애니메이션 키프레임 안의 CSS 변수를 풀지 못할 수 있어서, 재생할 때 상자 폭을 px로 측정해 키프레임에 px 값을 넣는다. 폭이 0이면 전환은 건너뛰고 깜빡임은 다음 차례로 미룬다.
- 표정이 다시 바뀌거나 마스코트가 사라지면 진행 중인 전환과 깜빡임을 `cancel()`한다. 이미 끝난 애니메이션의 후속 처리가 그 뒤에 돌아도 지난 표정의 깜빡임을 잡지 않는다.
- `document.hidden`이면 타이머를 걸지 않고, `visibilitychange`로 다시 보이면 새로 잡는다.
- `prefers-reduced-motion`이거나 Web Animations API가 없으면 전환과 깜빡임을 모두 건너뛰고 칸만 바꾼다.

## 성능

- 컴포넌트는 `sessionState`가 바뀔 때만 다시 그려진다. 매초 바뀌는 시간 값은 넘기지 않는다.
- 움직임은 `transform`과 `opacity`만 바꿔 레이아웃과 페인트를 다시 하지 않는다.
- 이미지는 `decoding="async"`로 한 번만 받는다. 꺼짐 상태에서는 컴포넌트를 마운트하지 않아 요청 자체가 없다.
- 실기기 성능 측정은 하지 않는다(사용자 결정).

## 테스트

- `mascotExpression`: 상태별 칸 번호(자리 비움은 실루엣), 점프 칸을 쓰지 않음, 깜빡임 키프레임, 전환 키프레임(일반 칸, 실루엣 칸, 정색 칸)
- `mascotSettings`: 기본값 꺼짐, 켠 값과 끈 값 읽기, 모르는 값은 꺼짐, 저장소 예외 때 꺼짐
- `SessionMascot`: 화면 크기별 상자 크기와 넘긴 자리 클래스, 상태에 맞는 칸, 첫 화면에서는 전환 없음, 전환 키프레임의 px 값과 끝 칸, 정색·실루엣으로 바뀔 때의 키프레임, 시트 폭, 빠르게 다시 바뀌면 앞 전환 취소, 전환 뒤에만 깜빡임, 끝난 애니메이션의 후속 처리가 늦게 돌아도 지난 깜빡임 없음, 상자 폭 0, 언마운트 때 취소, 모션 축소와 화면 숨김
- `RoomPage`: 처음에는 마운트하지 않고 `마스코트 보이기`를 고르면 나타나며 켜짐을 저장, 켜 둔 기기에서 바와 같은 줄 왼쪽 끝에 놓임, 월페이퍼가 있으면 가로 폰에서 바 왼쪽 옆으로 바뀌는 클래스, 숨기면 꺼짐 저장
- `SessionMoreMenu`: 항목을 넘긴 화면에서만 보이고, 보이는지에 따라 문구가 바뀌며 누르면 토글 함수를 부름
