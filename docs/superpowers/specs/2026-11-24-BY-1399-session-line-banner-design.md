# 세션 한 줄 배너와 노출 실험 설계 (BY-1399)

2026-11-24 작성. 결정은 같은 날 사용자와의 문답으로 정했다.

## 1. 목표

2026년 12월 4일 최종 발표에서 아래 두 가지를 실측으로 보인다.

- 혼자 공부하는 화면이 광고 지면으로 쓰일 수 있다.
- 배너를 봐도 공부 시간과 재방문이 줄지 않는다.

제3자 광고(AdMob)는 약관 개정이 시행되는 2026년 12월 24일 이후에 붙인다(BY-1396).
그 전에는 같은 형식의 자체 배너로 실험하고, 수익은 실측 노출 수에 공개 단가를 곱해 추정한다.

## 2. 배너

| 항목   | 결정                                                                                                                                                        |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 내용   | 프리미엄 사전 신청 홍보. 프리미엄 사전 신청 실험(BY-1392)의 두 번째 입구다                                                                                  |
| 형식   | `AD` 라벨과 글자 한 줄. 이미지와 움직임이 없다                                                                                                              |
| 위치   | 세로 폰의 일시정지·종료 버튼 줄 아래 가운데                                                                                                                 |
| 문구   | `AI가 오늘 할 일을 짜 드려요`, `이번 주 집중 리포트 받아 보기`, `프리미엄 사전 신청 받는 중`                                                                |
| 교체   | 배너가 보인 시간이 5분 쌓일 때마다 다음 문구로 바뀐다                                                                                                       |
| 누르면 | 타이머는 멈추지 않고 프리미엄 혜택 화면(`PremiumFakeDoorFlow`)이 세션 위에 열린다. 위치 값은 `SESSION`이다                                                  |
| 숨김   | 사전 신청을 마친 사용자, 가로 화면, 태블릿, 한국어가 아닌 화면                                                                                              |
| 끝     | 2026-12-03 23:59:59 KST 뒤에는 자동으로 꺼진다(2026-11-26 사전 신청 실험과 함께 연장). 더 일찍 끄려면 `SESSION_BANNER_ENABLED`를 false로 바꿔 웹만 배포한다 |

버튼 줄 아래에 있던 `카메라 화면은 어디로도 보내지 않아요`는 세로 폰의 로그인 사용자 전원에게서 뺀다.
배너를 보는 쪽에서만 빼면 지표 차이가 배너 때문인지 문구가 없어져서인지 구분할 수 없기 때문이다.
가로 화면, 태블릿, 카메라 확인 창의 같은 문구는 유지한다.

버튼 아래 여백은 8px뿐이라 배너를 보는 사용자에게만 버튼 줄 아래에 20px을 더해 배너 자리를 만든다.
처음에는 안전 영역이 12px 이상이면 그 안에 배너를 넣었는데, Android의 3버튼 내비게이션 바가 안전 영역 전체를 불투명하게 덮어 글자가 가려졌다.
그래서 안전 영역 크기와 관계없이 20px을 더한다.

## 3. 실험 대상과 분배

| 항목      | 결정                                                                                                                                                                                                                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 대상      | 토큰을 주는 앱으로 접속했고, 로그인했고, 한국어 화면이고, 판정일 전 14일 동안 순공 1분 이상인 날이 2일 이상인 사용자(2026-11-26 3일에서 2일로 낮춤)                                                                                                                                                   |
| 분배      | 대상 안에서 70%는 배너를 보고(`exposed`) 30%는 보지 않는다(`control`)                                                                                                                                                                                                                                 |
| 분배 방식 | `session-line-banner:${userId}`의 FNV-1a 해시를 한 번 더 섞은 뒤 10으로 나눈 나머지가 7보다 작으면 `exposed`. FNV-1a의 마지막 비트는 글자들의 홀짝으로만 정해져서, 섞지 않으면 해시의 홀짝을 쓰는 프리미엄 가격 분배와 같이 움직인다. 섞은 뒤에는 사용자 1만 명에서 두 군 모두 가격이 반반으로 나뉜다 |
| 고정      | 처음 판정한 값을 `focusmakers.sessionBanner.v1.{userId}`에 저장하고 실험 기간 동안 다시 판정하지 않는다                                                                                                                                                                                               |
| 대상 밖   | 조건을 못 채운 로그인 사용자는 `not_eligible`로 저장한다. 비회원과 브라우저 접속은 판정하지 않는다                                                                                                                                                                                                    |

판정일 당일은 기간에서 뺀다. 지금 하고 있는 세션이 자기 자신을 대상으로 만드는 일을 막기 위해서다.

## 4. 계측

| 이름                        | 종류        | 언제                                 | 속성                                 |
| --------------------------- | ----------- | ------------------------------------ | ------------------------------------ |
| `session_banner_group`      | 사용자 속성 | 실험군을 처음 판정했을 때            | `exposed`, `control`, `not_eligible` |
| `session_banner_shown`      | 이벤트      | 세션에서 배너가 처음 보였을 때 한 번 | `copy`                               |
| `session_banner_impression` | 이벤트      | 배너가 보인 시간이 5분 쌓일 때마다   | `copy`, `sequence`                   |
| `session_banner_clicked`    | 이벤트      | 배너를 눌렀을 때                     | `copy`                               |

`copy`는 문구 번호(1, 2, 3)이고 문구 글자는 싣지 않는다.
일시정지 중, 다른 화면이 세션을 덮은 동안, 앱이 뒤로 간 동안은 보인 시간으로 세지 않는다.
배너로 들어온 사전 신청 흐름의 이벤트는 프리미엄 실험의 기존 이벤트에 `placement: "SESSION"`으로 실린다.

판정 기준은 결과를 보기 전에 고정한다.
`exposed`와 `control`의 배너 전후 변화량을 비교해 세션당 순공 시간, 하루 평균 세션 수가 대조군 대비 5% 넘게 줄지 않고 5분 안에 끝낸 세션 비율이 5% 넘게 늘지 않으면 영향 없음으로 본다.
기간이 짧아 확정하기 어려우면 예비 실험이라고 적는다.

## 5. 구조

- `features/session-banner/sessionBanner.ts`: 기간, 문구 목록, 분배, 대상 판정 같은 규칙을 순수 함수로 둔다.
- `features/session-banner/sessionBannerStore.ts`: 실험군 저장과 읽기.
- `features/session-banner/useSessionBannerGroup.ts`: 프로필과 기간 통계를 읽어 실험군을 한 번 정한다.
- `features/session-banner/useBannerExposure.ts`: 보인 시간을 쌓아 문구를 바꾸고 노출 이벤트를 보낸다.
- `features/session-banner/SessionLineBanner.tsx`: 배너 버튼.
- `routes/RoomPage.tsx`: 배너 자리, 카메라 안내 문구 조건, 혜택 화면 열기.
- `lib/amplitude.ts`: 이벤트 함수 네 개.

새 의존성은 없다. 통계는 기록 탭이 쓰는 `periodStatsQuery`를 그대로 쓴다.

## 6. 프리미엄 사전 신청 실험과의 연결

이 문서를 쓸 때는 프리미엄 사전 신청 코드(BY-1393)가 `dev`에 없어서 배너, 분배, 노출 집계, 이벤트를 먼저 만들고 배너를 누른 뒤의 연결은 `onOpen` 하나로 열어 두었다.
BY-1393이 `dev`에 들어온 뒤 아래를 붙였다.

- `PremiumPlacement`와 `PremiumFakeDoorPlacement`에 `SESSION`을 더했다.
- RoomPage가 `onOpen`에서 `PremiumFakeDoorFlow`를 `placement="SESSION"`으로 연다. 결과 화면 카드와 같은 가격, 같은 신청 기록을 쓴다.
- 세션에서 연 신청 화면의 완료 버튼은 `공부로 돌아가기`다.
- `loadPremiumRecord(userId).applied`가 true면 배너를 숨기고, 신청 화면을 닫을 때 기록을 다시 읽는다.
- `PREMIUM_FAKE_DOOR_ENABLED`가 false면 배너도 보이지 않는다.

서버의 `PUT /api/premium-waitlist/me`가 `placement` 값 `SESSION`을 받는 변경은 백엔드에서 별도로 진행 중이다(BY-1394).
