# BY-1362 PC 공부 결과 모달 설계

## 배경

PC 홈에서 공부를 끝내면 지금은 모바일 결과 화면(`/room/1/result`)으로 이동한다. 월페이퍼와 패널이 사라지고, 다시 공부하려면 홈으로 한 번 더 가야 한다. PC 첫 출시에는 결과를 홈 위 모달로 보이고 닫으면 같은 홈으로 돌아오게 한다.

시안은 Figma `nmpEKUAgMwMtLdxIIXGFUB` 파일에 있다.

- 결과 모달 라이트 `11002:18855`, 측정 없음 라이트 `11002:19036`, 규칙 `11002:19160`
- 결과 모달 다크 `12316:2404`, 측정 없음 다크 `12316:2605` (2026-11-22, 같은 섹션 `11290:745`)

## 구조

```mermaid
flowchart TD
  E[useSoloSessionEngine onResult] --> S[PcSessionScreen]
  S -- onResult sessions, startedAtMs --> P[PcStudySession]
  P -- onResult --> H[PcHomeContent result 상태]
  H -- onSessionEnd --> HE[HomeV3Entry 세션 닫기]
  H --> M[PcResultModal]
  M --> T[StudyTimelineCard]
  M --> U[SessionSummaryCard]
  M --> L[ResultTimelapseCard share=browser]
  M -- 닫기·X·바깥·Esc --> H
  M -- 기록으로 가기 --> R[/records]
```

### 결과 넘기기

- `PcSessionScreen`의 `goToResult`는 주소를 바꾸지 않고 `onResult(sessions, startedAtMs)`를 부른다.
- 자동 종료 안내의 `결과 보기`도 같은 콜백을 부른다.
- `PcHomeContent`는 결과를 받으면 상태에 넣고 `onSessionEnd()`로 세션을 닫는다. 세션 자리는 홈 패널로 돌아오고 그 위에 모달이 뜬다.
- 모달을 닫으면 상태를 비운다.

### 모달

- shadcn `Dialog`를 쓰고 `container={box}`로 홈 상자 안에 띄워 홈 테마 변수를 물려받는다.
- 오버레이가 월페이퍼를 어둡게 깐다.
- 모달은 늘 한 열이다(D9). 측정 세션은 제목 숫자(순공시간, 총 공부시간, 집중률) → 공부 타임라인 카드 → 오늘 누적 카드 → 타임랩스 카드 순서다.
- 오늘 누적 카드는 `SessionSummaryCard`의 `layout="split"`으로 두 값을 반반 카드에 나눠 그린다(D10).
- 타임랩스 카드는 타임랩스가 켜져 사진이 있을 때만 오늘 누적 카드 아래에 붙는다. 사진이 없으면 그리지 않는 지금 카드 동작을 그대로 따른다.
- 재생기는 카드 안쪽 폭을 채우는 16:9 가로다(시안 478×269). 모달 폭은 560이고 최대 높이는 화면에서 위아래 40을 뺀 값이다(1440×900에서 820).
- 버튼 줄의 `닫기`와 `기록으로 가기`는 폭을 나눠 채운다. 측정 없음 모달과 같다.
- 모달이 화면 높이를 넘으면 제목 줄과 버튼 줄은 고정하고 그 사이 본문만 스크롤한다.
- 자율 모드(`isTimerSession`)는 제목 숫자에 총 공부시간만 보이고, 타임라인과 타임랩스 없이 `result.timerNotice`와 오늘 누적 카드를 보인다.
- 모바일 결과 화면처럼 제목 숫자와 타임라인은 첫 세션(`toSessionResultView(sessions[0])`)을 그린다. 자정으로 나뉜 세션의 순공 합산은 이탈 이벤트의 `focusSec`에만 쓴다. 합산 순공을 첫 세션의 총 공부시간 옆에 두면 순공이 총 공부시간보다 커질 수 있다.
- 제목은 `result.completeTitle`만 쓰고 부제는 없다. 버튼은 `닫기`·`기록으로 가기`다.

### 타임랩스 비율

- `useSoloSessionEngine`에 선택 옵션 `timelapseAspect`를 더한다. 값이 있으면 녹화기가 읽은 설정의 비율을 이 값으로 바꿔 기록에 남긴다(`createTimelapseRecorder({ loadSettings })`).
- `PcStudySession`이 `timelapseAspect: "16:9"`를 넘긴다. 창 폭이 아니라 PC 세션인지로 정해서 창을 줄여도 바뀌지 않는다.
- `TimelapseSettingsPage`는 PC 셸 안에서 비율 고르기 줄을 그리지 않는다. 저장된 값은 바꾸지 않는다.
- 모바일 세션은 옵션을 넘기지 않아 지금과 같다.

### 타임랩스 공유

- `ResultTimelapseCard`에 공유 방식을 고르는 prop을 더한다. PC는 공유하기를 누르면 공유 창 대신 브라우저 공유(`routes.share === "browser"`)를 바로 실행한다.
- 브라우저 공유가 없으면(`routes.share === null`) PC에서는 공유하기 버튼을 그리지 않는다.
- 다운로드는 지금 동작(`<a download>`) 그대로다.
- 모바일 기본값은 지금과 같다.

### 분석

- `trackStudyResultConfirmed`와 `stageStudyResultExit`에 선택 값 `surface`를 더하고, 값이 있으면 이벤트 속성에 실린다.
- 닫기는 `via: "home"`으로 확인 이벤트를 보내고, 이탈 예약을 `/home`으로 남긴 뒤 바로 `consumeStudyResultExit("/home")`를 부른다. 주소가 바뀌지 않아 경로 추적기가 다시 부르지 않기 때문이다.
- `기록으로 가기`는 `via: "records"`로 보내고 예약을 `/records`로 남긴 뒤 이동한다. 기록 화면의 경로 추적기가 지금처럼 보낸다.
- 보내는 값은 개인정보처리방침의 Amplitude "이용 기록" 항목에 들어가 방침은 고치지 않는다.

## 바뀌지 않는 것

- 모바일 결과 화면과 그 테스트
- 소셜 방 결과 화면
- 결과 데이터 형식(`StudySessionResponse[]`, `startedAtMs`)

## 오류와 경계

- 새로고침, 탭 닫기: 모달은 사라진다. 기록은 제출 때 이미 서버에 있다.
- 홈 통계: 세션 제출이 이미 `statsKeys.all`을 무효화해(`useStudyRoomSession`) 모달 뒤 홈 패널과 모달의 오늘 누적 카드가 같은 새 값을 받는다. 따로 무효화하지 않는다.
- 모달이 열린 동안 공부 시작: 모달이 위를 덮어 누를 수 없다. 닫은 뒤 바로 시작할 수 있다.

## 테스트

- `PcResultModal`: 측정 세션 한 열 내용, 자율 모드 안내와 타임라인·타임랩스 없음, 닫기·X·Esc·바깥 클릭이 `onClose`, `기록으로 가기`가 `/records` 이동, 분석 두 이벤트와 `surface`
- `PcStudySession`: 끝내면 `/room/1/result`로 가지 않고 `onResult`에 세션과 시작 시각이 넘어간다(자동 종료 `결과 보기` 포함). 기존 `ResultProbe` 단언을 바꾼다.
- `PcHomeContent`: 결과를 받으면 세션이 닫히고 모달이 뜨며, 닫으면 홈 패널만 남는다.
- `ResultTimelapseCard`: PC 공유 방식에서 공유하기가 브라우저 공유를 바로 부르고, 지원하지 않으면 버튼이 없다. 모바일 기본값은 기존 테스트 그대로 통과한다.
- `amplitude`: `surface`가 있을 때만 속성에 실린다.
- 타임랩스 비율: 엔진에 `timelapseAspect`를 넘기면 저장된 설정이 9:16이어도 기록이 16:9이고, 넘기지 않으면 설정 값 그대로다. PC 셸의 설정 화면에는 비율 줄이 없고 모바일에는 있다.

## UI 확인

- 실제 Chrome 1440×900에서 측정 세션과 자율 모드 결과를 라이트·다크로 찍어 시안과 비교한다.
- reduced-motion, Esc·Tab 포커스 가두기, 버튼 44px, 모달 `aria-labelledby`를 확인한다.
