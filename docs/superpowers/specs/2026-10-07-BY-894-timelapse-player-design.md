# BY-894 타임랩스 재생기와 결과 화면 카드 설계

- 티켓: BY-894 (BY-888에서 분할, 상위 BY-822, 선행 BY-834·BY-887, 후속 BY-895·BY-889)
- 명세: AI 위키 `product/specs/BY-822-타임랩스.md` §4·§6
- 시안: Figma V2 `YcyImcuVORDbBneii41Byh` S9-2 `결과 · 타임랩스 카드` 5988:7154(세로)·6009:7468(가로), 다크 6009:8402·6009:8828
- 브랜치: `feature/BY-894-timelapse-player` (base `dev`)

## 목표

결과 화면 맨 아래에서 방금 만든 타임랩스를 캔버스로 재생한다. 한 장면을 그리는 함수는 BY-889의 영상 파일 만들기가 그대로 쓴다.

## 저장소 (`features/timelapse/timelapseStore.ts`)

- `get(startedAtMs): Promise<TimelapseRecord | null>`를 추가한다.
- `annotate(startedAtMs, { ddayLabel, streakDays }): Promise<void>`를 추가하고 레코드에 선택 필드 `ddayLabel?: string | null`, `streakDays?: number | null`을 둔다.
- `annotate`는 ready 레코드만 고치고 없는 레코드는 무시한다.
- D-Day는 표기 문자열(`D-108 · 2027 수능`)로 남긴다. 나중에 홈에서 다시 볼 때도 그날의 남은 일수가 나와야 한다.

## 한 장면 그리기 (`features/timelapse/timelapseFrame.ts`)

- `drawTimelapseFrame(ctx, scene)` 순수 함수 하나가 사진, 오른쪽 아래 정보, 왼쪽 위 D-Day·연속 공부, 워터마크, 흐름 바를 그린다.
- `scene`은 캔버스 크기, 사진(`CanvasImageSource | null`), 진행률(0~1), 켠 정보, 표시 문자열, 흐름 바 구간을 받는다.
- 배치·글자 크기·색은 `TimelapsePreview`와 같다. 기준은 짧은 변 180px이고 실제 짧은 변에 비례해 키운다.
- 색은 영상 위 요소라 테마와 관계없이 고정이다(순공 `#5a90ea`, 자동 멈춤 `#ff9e1b`, 일시정지 `#b3bccb`, 워터마크 `#3671cf`).
- 흐름 바는 구간 전체를 그린 뒤 진행률까지만 보이게 채운다(명세 §1 "영상 진행에 맞춰 채워진다").
- 흐름 바 구간은 결과 타임라인의 `timelineSegments()`에 레코드의 `startedAtMs`·`summary.endedAtMs`·`summary.events`를 넣어 만든다. `events`가 없는 복구 세션은 흐름 바를 그리지 않는다.
- 사진 비율이 캔버스와 다르면 늘리지 않고 가운데를 잘라 채운다.
- 워터마크는 흰 바탕에 `#3671cf` 글자다.
- 얼굴 가림은 촬영 때 사진에 이미 입혀져 있어 다시 그리지 않는다.
- 글꼴 이름은 웹이 선언한 `"Pretendard Variable"`이다. 그릴 글자를 넘겨 `document.fonts.load`로 한글 조각 파일을 받되 기다리지 않고 바로 그리고, 글꼴이 도착하면 멈춘 화면도 다시 그린다.

## 재생기 (`features/timelapse/TimelapsePlayer.tsx`, `useTimelapsePlayer.ts`)

- 사진 바이트를 한 번 읽어 들고(최대 360장, 약 15MB), 재생하면서 몇 장 앞만 `createImageBitmap(new Blob([bytes]))`으로 풀고 다 그린 장은 `close()`한다. 360장을 한꺼번에 풀면 약 400MB가 된다.
- `requestAnimationFrame`으로 돌되 장면은 초당 12장으로 넘기고, 탭이 가려졌다 돌아와도 밀린 장은 최대 두 장만 따라잡는다.
- 풀지 못하는 사진은 기억해 두고 건너뛰며, 첫 사진이 깨지면 다음 사진을 첫 화면으로 그린다.
- 오버레이 값(D-Day 등)이 늦게 바뀌면 멈춰 있어도 지금 장을 다시 그린다.
- 마지막 장 다음에는 처음으로 돌아간다.
- `useInView({ threshold: 0.5 })`로 절반 이상 보일 때만 재생한다.
- 왼쪽 아래에 44px 재생/일시정지 버튼(지름 40px 원)을 두고 라벨은 `타임랩스 재생`·`타임랩스 일시정지`다. 오른쪽 아래는 영상 정보 자리다.
- 움직임 줄이기 설정이면 첫 장면을 그려 두고 버튼을 눌러야 재생한다.
- 진행 막대(흰색 30% 트랙과 `primary` 진행)는 DOM으로 그리고, 렌더 없이 ref로 너비만 바꾼다. 둥근 모서리에 닿지 않게 12px 안쪽에 두고, 흐름 바를 켠 영상에서는 흐름 바가 진행을 보여주므로 숨긴다.
- 캔버스와 진행 막대는 `aria-hidden`이다.
- 캔버스 픽셀 크기는 비율별 고정값(540×960, 960×540)이고, 상자 높이는 CSS `aspect-ratio`가 아니라 캔버스 자체 비율(`w-full h-auto`)이 정한다. 기기 웹뷰가 화면을 돌린 뒤 `aspect-ratio` 높이를 다시 계산하지 않아 영상이 찌그러졌다.
- 언마운트되면 rAF를 멈추고 남은 비트맵을 모두 닫는다.

## 결과 화면 카드 (`features/timelapse/ResultTimelapseCard.tsx`)

- 결과 화면 카드 묶음의 맨 끝에 둔다.
- 머리글은 공부 타임라인 카드와 같은 제목 `타임랩스`와 그 오른쪽 ⓘ `InfoTooltip`(`타임랩스 촬영은 설정에서 언제든 끌 수 있어요`)이고, 제목 아래에 안내 문구를 둔다.
- 영상 상자는 9:16이면 너비 240px(높이 427px), 16:9면 카드 안쪽 너비 전체이고 모서리는 14px다. 비율은 레코드에 저장된 설정을 따른다.
- 켬·끔은 레코드 `settings.info`를 따른다(지금 localStorage 값이 아니다).
- 날짜는 `startedAtMs`의 `M월 D일`, 순공은 `순공 N시간 M분`, 집중률은 `집중률 N%`(`focusSec/studySec` 반올림)이다.
- D-Day는 `ddayQuery(userId)`, 연속 공부는 `streakQuery`로 받고 성공하면 `annotate`로 한 번 기록한다.
- D-Day가 없거나 신원이 없으면 그 줄을 빼고, 불러오는 중에는 레코드에 기록된 값이 있으면 그 값을 쓴다.
- 카드를 그리지 않는 경우: 플래그(`VITE_TIMELAPSE`)가 꺼짐, 소셜 결과, 레코드 없음, ready가 아님, 사진 0장.
- 촬영 정리는 제출과 함께 시작해 결과 화면이 먼저 열릴 수 있어, 레코드가 `recording`인 동안은 0.5초마다 다시 읽는다.
- 신원이 없으면 레코드에 남은 D-Day·연속 공부도 보여주지 않는다.

## 결과 화면 연결

- RoomPage `goToResult`가 넘기는 state에 `startedAtMs`를 더하고 `readSessions` 검증도 함께 고친다. state에 없으면 `Date.parse(sessions[0].startedAt)`로 찾는다.
- 자동 스크롤은 카드 묶음이 다 떠오른 뒤 결과 화면의 스크롤 컨테이너(`overflow-y-auto` div)를 카드까지 `behavior: "smooth"`로 내린다.
- 자동 스크롤 중 화면 어디서든(`window`) `pointerdown`·`wheel`·`keydown`이 오면 그 자리에서 멈춘다.
- 움직임 줄이기 설정이거나 인트로를 이미 본 경우(`skipIntro`)에는 자동 스크롤하지 않는다.

## 테스트

- 저장소: `get`, `annotate`(ready만, 없는 키 무시).
- 그리기: 기록용 가짜 ctx로 켠 요소만 그리는지, 흐름 바가 진행률만큼 채워지는지, `events`가 없으면 흐름 바를 빼는지.
- 재생기: 가짜 타이머로 초당 12장, 마지막 장 뒤 반복, 보일 때만 재생(`react-intersection-observer/test-utils`), 일시정지 버튼, 움직임 줄이기면 멈춰 시작.
- 결과 화면: 카드를 그리는 조건과 숨기는 조건, 자동 스크롤과 터치 시 멈춤, 움직임 줄이기면 자동 스크롤 없음.
- 기존 "버튼은 `홈으로`·`기록으로 가기` 둘뿐" 테스트는 재생 버튼을 포함하도록 고친다.

## 시안과 문서

- 위키 명세에 반복 재생, 일시정지 버튼, 움직임 줄이기 동작, D-Day·연속 공부를 결과 화면에서 기록한다는 점을 적는다.
