# 그룹 이름·소개 번역 표시 설계 (BY-1192)

## 왜

백엔드가 그룹 조회 응답에 `translation`을 실었다(BY-1191, backend PR #159, dev 배포 확인). 영어·일본어·번체 화면을 쓰는 사람이 한국어로 만든 그룹을 자기 언어로 읽을 수 있게 한다. 번역은 틀릴 수 있어서 번역된 글이라는 걸 알리고 원문을 볼 수 있게 한다.

설정 화면의 앱 언어 선택은 탭바와 다른 탭 화면까지 바꿔야 해서 앱 업데이트가 필요하다. 이번에는 넣지 않는다(BY-813).

## 목표

- 그룹 조회 4개에 지금 화면 언어를 `Accept-Language`로 보낸다.
- 번역이 있는 필드는 번역을, 없는 필드는 원문을 보여 준다.
- 번역된 글이 보이는 화면에 "번역됨"과 원문 보기 버튼을 둔다.
- 조회 캐시를 언어별로 나눈다.

## 하지 않는 것

- 설정 화면 언어 선택, 간체 화면 문구, zh-TW와 zh-HK 화면 구분.
- 원문 언어 표시("한국어에서 번역됨"). 서버가 원문 언어를 주지 않는다.
- 내 신청 목록(`/api/group-applications/me`)의 그룹 이름 번역. 응답에 번역 필드가 없다.
- 원문 보기 상태를 저장소에 남기는 것.

## 실패로 보는 것

- `translation`이 비어 있다고 오류나 로딩을 보이는 것.
- 그룹 수정 화면 입력칸에 번역문이 들어가는 것.
- 다른 언어로 받은 응답이 캐시에서 섞여 보이는 것.

## 서버 명세 (dev Swagger 확인)

```ts
interface GroupTranslation {
  language: "ko" | "en" | "ja" | "zh-TW";
  name: string | null;
  description: string | null;
}
```

- `MyGroupCard`, `PublicGroupCard`, `PublicGroupDetailResponse`, `GroupHomeResponse`에 `translation: GroupTranslation | null`이 붙는다.
- 목록 두 응답은 소개를 번역하지 않는다(목록 카드에는 원래 소개가 없다).
- 번역 기능이 꺼져 있거나 무료량이 끝나면 `translation`은 `null`이고 응답은 정상이다.

## 동작

### 언어 헤더

- 대상: `GET /api/groups/public`, `GET /api/groups/me`, `GET /api/groups/public/{groupId}`, `GET /api/groups/{groupId}`.
- 값은 i18next의 현재 언어에서 정한다: `ko`→`ko`, `en`→`en`, `ja`→`ja`, `zh-Hant`→`zh-TW`.
- 간체·미지원 기기는 이미 화면이 `en`이라 `en`이 나간다.
- `Authorization`, `API-Version`은 지금처럼 `apiFetch`가 붙인다.
- 개발용 가짜 서버(`groupRoomMock`) 경로는 헤더와 관계없다.

### 번역 표시

- 이름은 `translation?.name ?? name`, 소개는 `translation?.description ?? description`.
- 응답을 화면 값으로 바꾸는 `fromApi.ts`의 `toMyRoomSummary`, `toPublicRoomSummary`, `toPublicRoomDetail`, `toRoomHome`이 번역문과 원문을 둘 다 넘기고, 화면이 원문 보기 설정에 따라 고른다.
- 원래 응답의 `name`·`description`을 직접 읽는 곳도 같은 규칙을 따른다: 그룹 홈 소개 화면, 신청 화면·신청 목록·멤버 화면 머리의 그룹 이름, 공부방 내보내기 안내의 그룹 이름.
- 그룹 수정 화면(`GroupFormPage`)은 원문 `home.name`·`home.description`을 그대로 쓴다.

### 원문 보기 설정 (공유 하나, 버튼 여러 개)

- 웹 문서 안에 메모리로 "원문 보기" 켬/끔 하나를 둔다. 처음은 끔(번역 보기).
- 문서를 새로 열면(앱 재실행, 웹뷰 다시 불러오기) 다시 번역 보기로 시작한다.
- 소셜 탭은 웹뷰 하나 안에서 화면만 바꾸므로 목록과 상세가 같은 설정을 본다.
- 어느 화면의 버튼을 눌러도 설정이 바뀌고, 그룹 이름·소개가 보이는 모든 화면이 같이 바뀐다.

### 버튼 위치 (시안 L1·T1 확정)

- 목록(L1): 공개 그룹 목록은 카테고리 칩 아래, 내 그룹 목록은 첫 카드 위에 한 줄. 아이콘 + `그룹 이름을 번역해서 보여주고 있어요` + `·` + `원문 보기`. 원문 상태에서는 `원문 이름으로 보여주고 있어요 · 번역 보기`.
- 상세(T1): 공개 그룹 보기의 소개 카드와 그룹 홈 소개 화면의 소개 카드 맨 아래에 한 줄. 아이콘 + `번역됨` + `·` + `원문 보기`. 원문 상태에서는 `원문 · 번역 보기`.
- 그 목록·카드에 번역된 필드가 하나도 없으면 한 줄을 그리지 않는다. 원문 보기 상태에서도 "번역이 있는 그룹이 있는가"로 판단해 버튼이 사라지지 않게 한다.
- 소개가 없는 그룹 상세는 소개 카드가 없어서 이름만 번역되고 한 줄은 생략한다.
- 버튼은 글씨 링크지만 누르는 높이 44px. 아이콘은 lucide `Languages`, `aria-hidden`.
- 시안 보드: https://claude.ai/artifact/WHex6LM7agzsuoYWFickxx (L1·T1, 실제 화면 줄).

### 문구 (4개 언어 모두 같은 키)

| 키           | ko                                   | en                         | ja                                 | zh-Hant          |
| ------------ | ------------------------------------ | -------------------------- | ---------------------------------- | ---------------- |
| 목록 번역 중 | 그룹 이름을 번역해서 보여주고 있어요 | Group names are translated | グループ名を翻訳して表示しています | 群組名稱已翻譯   |
| 목록 원문 중 | 원문 이름으로 보여주고 있어요        | Showing original names     | 原文の名前を表示しています         | 正在顯示原文名稱 |
| 상세 번역 중 | 번역됨                               | Translated                 | 翻訳済み                           | 已翻譯           |
| 상세 원문 중 | 원문                                 | Original                   | 原文                               | 原文             |
| 원문 보기    | 원문 보기                            | See original               | 原文を表示                         | 查看原文         |
| 번역 보기    | 번역 보기                            | See translation            | 翻訳を表示                         | 查看翻譯         |

### 캐시

- `groupKeys`의 그룹 키를 모두 `["groups", userId, locale, ...]` 모양으로 바꾼다. `locale`은 헤더에 보내는 값이다.
- `groupKeys.all(userId)`도 `["groups", userId, locale]`로 맞춰 기존 묶음 무효화·삭제가 그대로 동작하게 한다.
- `blocks` 키는 그룹 응답이 아니라 그대로 둔다.
- 화면 언어는 문서를 연 뒤 바뀌지 않아서 늦게 온 다른 언어 응답 처리는 따로 만들지 않는다. 키가 언어별이라 섞이지 않는다.

## 만드는 사람이 정할 것

- 헤더 값을 고르는 함수와 원문 보기 설정 저장소의 파일 위치·이름.
- 화면 모델에 번역문과 원문을 넘기는 필드 이름(예: `name`·`originalName`).
- 테스트는 승인된 테스트 계획(5-1)을 따른다.

## 내가 정한 것 (사용자 확인 전 판단)

- 그룹 홈 머리 제목, 신청 목록·멤버 화면 머리의 그룹 이름도 같은 설정을 따른다. 버튼은 소개 카드와 목록에만 둔다.
- 내 그룹 목록의 한 줄 위치는 공개 목록과 맞춰 첫 카드 바로 위로 했다.
