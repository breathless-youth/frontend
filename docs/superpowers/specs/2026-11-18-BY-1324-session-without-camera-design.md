# BY-1324 카메라 없이 공부하는 세션 화면 설계

상위 스토리 BY-1321(카메라 없이 타이머만으로 공부)의 두 번째 프론트 하위 항목이다. BY-1323에서 홈 전환 버튼과 기기별 저장 모듈(`features/measure-mode/measureMode.ts`)을 만들었다. 이 작업은 싱글룸 세션이 그 값을 읽어 카메라 없이 동작하게 한다.

## 결정 사항 (승인됨)

| #   | 항목                 | 결정                                                                                                                                                                                            |
| --- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 방식을 읽는 곳       | 새 세션은 기기 저장값(`readMeasureMode`)을 읽는다. 이어하기 복구는 서버 응답 `source`를 따른다(`TIMER`면 타이머, 없거나 `MEASURED`면 카메라). 시작 요청에 방식을 싣는 일은 BY-1326(앱)에서 한다 |
| 2   | 화면 탭 전환         | 유지한다. 심플 모드와 일반 모드의 배경·테두리 빛·공간 배경·조작 버튼 동작은 그대로이고, 일반 모드에서 작은 카메라 창과 확대 버튼만 뺀다                                                         |
| 3   | 상태 문구            | 카메라 없는 모드에서는 표시하지 않는다                                                                                                                                                          |
| 4   | 더보기 메뉴          | 카메라 전환과 도움말 항목을 뺀다                                                                                                                                                                |
| 5   | 첫 세션 가이드       | 카메라 없는 모드면 건너뛰고 '봤음'으로 기록하지 않는다                                                                                                                                          |
| 6   | 홈 AI 모델 미리 받기 | 카메라 없는 모드면 건너뛴다                                                                                                                                                                     |
| 7   | 분석 이벤트          | `study_session_started`·`study_session_ended`에 `measure_mode`(`camera`/`timer`)를 더한다. 카메라 없는 모드에서 `face_mask`는 false다                                                           |
| 8   | 구조                 | 새 화면을 만들지 않고 지금 세션 화면을 재활용한다. 마운트할 때 방식을 한 번 정하고 각 분기는 그 값만 본다                                                                                       |
| 9   | 시계 총 공부 줄      | 카메라 없는 모드는 순공과 총 공부가 같아서 큰 숫자 아래 총 공부 줄을 뺀다. 스크린 리더는 큰 숫자를 총 공부 시간으로 읽는다. 일반 모드 시계는 하단 버튼 위에 붙어 있어 그만큼 내려간다           |
| 10  | 홈 전환 토스트       | 홈에서 측정 방식을 바꾸면 공통 토스트로 바뀐 방식만 짧게 알린다(`카메라 없이 공부해요`, `카메라로 순공 시간을 측정해요`). 랭킹·포인트 제외 안내는 결과 화면에서 한다                            |

## 서버 명세 (BY-1322와 합의)

- `POST /api/study-sessions`, `PUT /api/study-sessions/active` 요청에 선택 필드 `source`(`MEASURED` | `TIMER`)를 더한다. 없으면 서버가 `MEASURED`로 저장한다.
- 프론트는 카메라 없는 세션일 때만 `source: "TIMER"`를 싣는다. 카메라 세션 요청은 지금과 똑같이 보낸다.
- `GET /api/study-sessions/active` 응답에 `source`가 더해진다. 값이 없으면(서버 배포 전) 카메라 세션으로 본다.

## 설계

### 세션 화면 (`routes/RoomPage.tsx`)

- 마운트할 때 방식을 정한다. 복구 세션이면 복구 값, 아니면 기기 저장값이다.
- 카메라 없는 모드에서는 세션 훅에 이미 있는 아무것도 열지 않는 카메라·감지기 구현을 넘긴다. 실제 카메라 어댑터, AI 감지기 시작, 움직임 센서가 돌지 않는다. 카메라 재연결·복귀·재개 재시도도 대상이 없어 돌지 않는다.
- 타임랩스 기록을 시작하지 않는다.
- 작은 카메라 창, 확대 버튼, 입장 카메라 확인 창을 그리지 않는다.
- 더보기 메뉴에서 카메라 전환과 도움말을 뺀다(`SessionMoreMenu`의 두 prop을 선택값으로 바꾼다).
- 상태 문구를 그리지 않는다. 과목 줄과 타이머 사이 간격이 어긋나지 않게 한다.
- 얼굴 가림을 쓰지 않고 종료 이벤트의 `face_mask`는 false다.

### 세션 훅 (`useStudyRoomSession.ts`)

- 옵션 `source?: "MEASURED" | "TIMER"`(기본 `MEASURED`)를 더해 스냅샷과 최종 제출 빌더로 넘긴다. 소셜룸은 옵션을 넘기지 않으므로 바뀌지 않는다.
- 시작·종료 이벤트에 측정 방식을 싣는다.

### 복구

- `restoreActiveSession`이 응답의 `source`를 읽어 복구 세션에 담는다.

### 시작 흐름과 홈

- `useFocusStart`와 `PlannerStudyStartSheet`는 카메라 없는 모드면 첫 세션 가이드로 보내지 않는다.
- 홈(새 홈, 옛 홈)의 AI 모델 미리 받기는 카메라 없는 모드면 건너뛴다.

## 테스트 계획

| 대상      | 케이스                                                                                                                                                                |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 요청 빌더 | 카메라 없는 세션이면 스냅샷·제출 요청에 `source: "TIMER"`가 실리고, 카메라 세션이면 `source` 필드가 없다                                                              |
| 복구 파서 | 응답 `source`가 `TIMER`면 타이머, 없거나 `MEASURED`면 카메라로 읽는다                                                                                                 |
| 세션 훅   | `source` 옵션이 스냅샷과 제출 요청에 전달된다. 감지 신호가 없으면 순공과 총 공부 시간이 같다                                                                          |
| 세션 화면 | 카메라 없는 모드에서 카메라 확인 창, 작은 카메라 창, 상태 문구, 카메라 전환·도움말 메뉴가 없다. 화면 탭 전환과 조작 버튼은 그대로 동작한다. 카메라 모드는 지금과 같다 |
| 세션 화면 | 카메라 없는 모드에서 `getUserMedia`를 부르지 않는다                                                                                                                   |
| 세션 화면 | 복구 세션은 기기 설정과 상관없이 복구 값의 방식을 따른다                                                                                                              |
| 분석      | 시작·종료 이벤트에 `measure_mode`가 실린다                                                                                                                            |
| 시작 흐름 | 카메라 없는 모드에서 가이드를 보지 않은 계정도 가이드로 가지 않고 세션을 시작하며, 가이드 '봤음' 기록이 생기지 않는다                                                 |
| 홈        | 카메라 없는 모드에서 AI 모델 미리 받기를 부르지 않는다                                                                                                                |
| 세션 화면 | 카메라 없는 모드 일반 모드에 총 공부 줄이 없고, 큰 숫자를 총 공부 시간으로 읽는다                                                                                     |
| 홈        | 전환 버튼을 누를 때마다 바뀐 방식의 토스트가 뜨고 이전 토스트를 대신한다                                                                                              |

## 범위 밖

- 앱의 카메라 권한 확인 건너뛰기와 권한 거부 화면 출구(BY-1326)
- 결과·기록 화면 표시(BY-1325)
- v3 레이아웃 브랜치(BY-1219)의 공부 화면 마스코트와 시작 카운트다운. 그 브랜치가 들어올 때 카메라 없는 모드 분기를 다시 본다. 그때 카메라 부분을 한 컴포넌트로 떼어내는 정리도 함께 검토한다
- 소셜룸과 그룹 공부방
