# 플래너 선택 기록의 초 단위 시간 표시

사용자 요청: 격자는 기존 분 단위 올림 표시를 유지하고 누르면 실제 길이를 표시한다. 7초는 1분 칸과 `7초`, 83초는 2분 칸과 `1분 23초`로 구분한다.

- 선택 패널, 과목 선택 안내, 기록 생성 말풍선은 동일한 실제 길이를 초까지 표시한다.
- 기존 측정 시각과 변경하지 않은 경계의 정밀도를 사용한다. 소수 초는 초 단위로 한 번 올림한다.
- 분 단위 시각 입력·드래그·격자·실제 겹침 판정·저장 요청과 통계 기준은 유지한다.
- 기존 초 포함 다국어 길이 포맷을 재사용한다. 전역 기록 요약 포맷은 바꾸지 않는다.

방법: 사용자 예시대로 표시만 분리한다. 원본 시간을 분으로 바꾸는 방법은 실제 값을 잃고, 전체 통계 포맷을 바꾸는 방법은 요청 범위를 넘으므로 사용하지 않는다.
