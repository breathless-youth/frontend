# BY-1057 홈 폴더식 탭과 타임테이블 조회 전용 설계

- Jira: BY-1057 (스토리 BY-949의 하위 작업)
- 기획 명세: `.ai/product/specs/BY-949-홈-개편-과목-시작.md` §5, `BY-817-기록-탭-개선.md` §6
- 앞선 작업: BY-1054 홈 헤더·날짜 줄·과목 목록, BY-1055 과목 카드 조작, BY-1056 과목 골라 시작, BY-1058 탭 바 재생, BY-1078 날짜 줄 후속
- 브랜치: `feature/BY-1057-handle-planner` → PR 대상 `feature/BY-949-home-redesign`

## 범위

홈 헤더 아래 끝에 `과목 목록`·`타임테이블`·`방해 앱 잠금`·`타임랩스` 폴더식 탭을 두고, 기록 탭에서 여는 전체 화면(`/planner`)을 조회 전용으로 바꾼다. 사용자에게 보이는 이름은 플래너에서 타임테이블로 바뀐다. 코드 이름(`PlannerPage`, `usePlannerDay` 등)과 분석 이벤트 이름(`planner_opened` 등)은 그대로 둔다.

처음 설계는 홈 목록 위에 끌어내리는 손잡이 패널(절반·끝까지 멈춤, history 항목, 목록 `inert`)이었다. 2026-10-30 사용자 결정으로 손잡이를 버렸고, 그다음 시험한 헤더 아래 별도 카드 탭도 같은 날 헤더 안 폴더식 탭으로 바꿨다. 파일 이름의 `handle`은 그 흔적이다.

### 폴더식 탭 모양

- 탭마다 둥근 사각형(`before`)을 아래 변 기준으로 뒤로 눕혀(`perspective(32px) rotateX(12deg)`) 위가 좁은 사다리꼴로 만든다. 눕히면 낮아지는 만큼 `scaleY(1.3)`로 늘려 보이는 높이를 탭 상자(32px)와 맞춘다. 그래야 가운데 둔 글자가 보이는 탭의 가운데에 온다.
- 이웃 탭과 8px 겹쳐 서류철 칸막이처럼 보인다. 모서리 둥글기와 테두리는 transform 뒤에도 그대로 남는다.
- 고르지 않은 탭은 `bg-control-track`, 고른 탭은 본문과 같은 `bg-muted`이고 앞으로 나온다.
- 탭 줄은 가로로 스크롤된다. 그러면 줄 밖으로 나간 부분이 잘려서, 기준선은 줄 테두리 대신 줄 안쪽 맨 아래 1px 그림자(`inset`)로 그린다. 고르지 않은 탭은 기준선 위에 서고, 고른 탭만 기준선까지 내려와 덮어 아래 본문과 이어진다.
- 탭이 적어 남는 폭은 탭들이 나눠 채운다. 320px에서도 네 탭이 한 줄에 들도록 글자는 12px이다.

### 타임테이블 칸

`PlannerTimetable` 칸은 높이 18px이고 표 너비는 232px이다. 좁은 화면에서는 왼쪽 범례보다 먼저 줄지 않도록 너비만 184px까지 줄인다. 홈 탭과 기록 탭 전체 화면이 같은 부품을 쓴다.

## 기록 탭 전체 화면(조회 전용)

| 항목      | 결정                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 뺀 것     | 과목 목록 저장소(`useSubjects(..., "planner")`), 할 일 체크, 과목·할 일 추가·이름 변경·삭제·순서 변경, 추천 과목 칩, `+ 과목 추가`, `시간 직접 입력` 버튼, 칸 누름 추가·수정, 숨은 수정 버튼                                                                                                                                                                                                                                                                                                                                                                                                 |
| 과목 목록 | 홈 타임테이블 탭과 같은 목록이다. 홈의 목록 계산을 `features/home/daySubjects.ts`의 `daySubjectItems`로 빼 홈과 이 화면이 함께 쓴다. 지금 과목은 홈과 같은 `loadLiveSubjects`(오늘 일간 조회, 없으면 과목 목록 API)로 열 때마다 받고, 지난 날은 `subjectsOnDayQuery`로 그날 있던 과목(뒤에 삭제한 과목 포함, 기록 없으면 0분)만 보인다. 날짜별 조회가 실패하면 홈처럼 지금 과목을 모두 보이고, 지금 과목 조회까지 실패하면 기록에 남은 과목만 보인다. 캐시에 남은 목록은 예전에 열었을 때의 것이라, 이번 마운트에서 두 조회를 다시 받아 끝날 때까지(`isFetchedAfterMount`) 스켈레톤을 보인다 |
| 오늘      | 홈과 같은 05시 기준(`plannerDateKeyOf(new Date())`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 미래      | 다음 날 꺾쇠는 오늘에서 비활성, 스와이프도 오늘에서 멈춤, 날짜 선택 시트는 오늘 뒤를 고를 수 없음, 주소로 미래가 오면 오늘을 연다                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 입구      | 기록 탭 머리의 원형 버튼은 그대로 두고 이름만 타임테이블. 입구가 기록 탭 하나라 `PlannerEntry`의 `home`과 스택 없이 열렸을 때 홈으로 돌아가는 분기를 삭제했다. 스택이 없으면 늘 기록 탭으로 돌아간다                                                                                                                                                                                                                                                                                                                                                                                         |

## 삭제한 코드

- `cellTapTarget`과 테스트, 시간 직접 입력의 칸 시각 경로(`start` 쿼리, `startMs`, `defaultSpan`의 `cellStartMs`)
- `PlannerTimetable`의 `onCellTap`·`onEditBundle`, 칸 누름 처리, 숨은 수정 버튼, `data-cell`. 이것만 쓰던 `manualBundles`와 테스트도 삭제했다(`subjectNameOf`·`readAloudLabel`·`bundleSpan`·`subjectIdOf`는 기록 탭·입력 화면이 써서 남긴다)
- 플래너 하루의 수동 기록 표시(`PlannerPaint.manual`·`PlannerCellFill.manual`·`data-manual`)와 `PlannerDay.sessions`. 칸 누름과 수동 기록 시트만 썼다
- 렌더러 복원 보고에서 입력 화면의 `from`. 플래너로 돌아갈 곳을 정할 때만 썼다. `/planner`의 `from`은 진입 이벤트의 `via`가 쓰므로 남긴다
- 수동 기록 입구 값 `planner_button`·`planner_cell`(타입·분석 타입·테스트). 예전 주소로 열려도 `records`로 보고 기록 탭으로 돌아간다. 스택 없이 입력 화면을 떠날 때 예전 칸 입구가 붙인 `start`는 삭제한다
- 시간 직접 입력의 플래너로 돌아가기 경로
- `PlannerSubjects`의 관리 코드(`ManagedSubjects`·길게 누르기·인라인 입력·추천 과목·할 일 줄). `subjectRowControls.tsx`는 홈 할 일이 쓰므로 남긴다
- `DayPickerSheet`의 `allowFuture`, `SubjectSurface`의 `planner`, `PlannerEntry`와 `planner_opened` `via`의 `home`
- 홈 헤더의 순공·총 공부 전환 버튼과 `trackHomeTotalTimeRevealed`

## 실기기 확인 남은 것

- 폴더식 탭의 라이트·다크 대비와 비스듬한 테두리.
- 긴 D-Day 제목의 말줄임과 둘째 줄 시간 글자와의 간격.
- 과목 줄을 밀어 연 채 본문을 세로로 스크롤할 때 가로로 밀리지 않는지.
