# BY-898 타임랩스 공유 다이얼로그와 공유 시트 설계

- 티켓: BY-898 (BY-889에서 분할, 상위 BY-822, 선행 BY-897·BY-899, 후속 BY-890)
- 명세: AI 위키 `product/specs/BY-822-타임랩스.md` §7·§8
- 시안: Figma V2 `S9-2 · 타임랩스 결과·공유·홈`의 공유 다이얼로그 3종(세로 9:16, 가로 16:9, 영상 준비 중), `S9-4 · 타임랩스 전체 목록`의 공유 다이얼로그, Icons 페이지 `brand/instagram`·`brand/kakaotalk`
- 브랜치: `feature/BY-898-timelapse-share-dialog` (base `dev`)

## 목표

전체 목록에서 타임랩스를 누르면 딤 위에 공유 다이얼로그와 공유 시트가 함께 올라온다. 결과 화면에서 `공유하기`를 누르면 딤 위에 공유 시트만 올라온다. 사용자는 거기서 영상을 저장하거나 공유한다. 홈 최근 타임랩스 썸네일은 누를 수 없다.

## 화면 구성

- Radix Dialog 하나가 화면 전체를 덮는다.
- 위쪽 가운데 흰 카드에 `TimelapsePlayer`와 파란 글자 `포커스 메이커스`를 둔다. 시안의 로고는 글자다.
- 아래쪽 시트에 손잡이, `공유하기` 제목, 버튼 4개, 안내 줄을 둔다.
- 카드는 시트 위에 남은 높이 안에서 비율을 지키며 줄어든다. 명세 §7의 "공유 시트에 가리지 않도록" 조건이다.
- 재생기 크기는 `aspect-ratio`가 아니라 캔버스의 고유 비율이 정한다. iOS 웹뷰에서 회전 뒤 `aspect-ratio` 높이가 옛 값으로 남은 일이 있었기 때문이다.
- 카드는 살짝 확대되며, 시트는 아래에서 올라오며 나타난다. 움직임 줄이기 설정이면 확대와 이동 없이 페이드만 한다(명세 §7).
- 카드와 시트 밖 빈 곳을 누르면 닫힌다.
- 결과 화면은 카드를 그리지 않고 시트만 둔다. 딤, 빈 곳 눌러 닫기, 포커스 가두기와 복귀, `aria-modal`, `data-covers-tab-bar`는 같다.
- 손잡이는 모양만 두고 끌어서 닫기는 넣지 않는다.
- portal이 body로 나가므로 `theme-soft-blue`를 Content에 다시 단다.
- 시트에는 `onTouchMove` stopPropagation과 `touch-manipulation`을 둔다. Radix 스크롤 잠금이 iOS에서 탭을 먹는 문제를 피하기 위해서다.
- 인스타그램·카카오톡 아이콘은 Figma `brand/*` 컴포넌트(Simple Icons CC0)를 SVG로 받아 쓴다.
- 영상 준비 중에는 재생기 위에 `공유할 영상을 생성하고 있어요`와 진행 막대를 덮는다. 결과 화면은 재생기가 없어 같은 문구와 막대를 시트 안내 줄 자리에 둔다. 문구와 막대를 합쳐도 안내 줄 자리 높이 안에 들어가 시트 높이가 바뀌지 않는다.

## 데이터

- 사진 쿼리를 결과 카드에서 꺼내 `timelapsePhotosQuery(startedAtMs, store)`로 `timelapseQueries.ts`에 둔다. 결과 화면 다이얼로그는 재생기를 그리지 않아 사진 쿼리를 읽지 않는다.
- 사진 쿼리의 `gcTime: 0`은 유지한다.
- 오버레이는 부르는 곳이 props로 넘긴다.
- 결과 카드는 이미 계산한 오버레이를 넘기지만 시트만 열어 화면에는 쓰이지 않는다.
- 전체 목록은 `overlayTextFor(record, { ddayLabel: record.ddayLabel ?? null, streakDays: record.streakDays ?? null })`로 레코드에 남은 그날 값을 넘긴다. 영상 파일도 레코드 값으로 그리므로 다이얼로그 화면과 영상이 같다.
- 영상은 다이얼로그가 열릴 때 `useQuery(timelapseVideoQuery(startedAtMs, store))`로 가져온다. 결과 화면은 미리 받아 두었고 목록은 이때 만들기 시작한다.
- 진행률은 `timelapseVideoProgressKey`를 `enabled: false` 쿼리로 구독한다. 값이 없으면 0으로 그린다.

## 누르는 곳

- 두 곳 모두 `<button>`이고 `aria-haspopup="dialog"`를 단다.
- 결과 카드는 재생기를 눌러도 재생과 일시정지만 한다. 재생기 아래에 초대코드 공유 화면과 같은 모양의 버튼 두 개를 둔다.
  - `다운로드`(흰 버튼)는 다이얼로그 없이 `saveTimelapse`로 바로 저장한다. 앱은 사진 앱에, 브라우저는 mp4 다운로드로 저장한다.
  - 영상이 아직이면 버튼에 `만드는 중 N%`를 보이고 누를 수 없다. 만들다 실패하면 다시 눌러 다시 만든다.
  - 앱 저장에 성공하면 카드 안내 줄 대신 토스트로 `사진 앱에 저장했어요`를 알린다. 그 밖의 결과는 버튼 아래 한 줄로 `shareResultNotice`와 같은 문구를 알리고, 권한 거부면 `설정 열기`를 함께 둔다.
  - 저장할 수 없는 환경(`shareRoutes().save === null`)이면 숨긴다. 분석은 시트와 같이 `button: "save"`, `entry: "result"`다.
  - `공유하기`(파란 버튼)는 공유 시트를 연다.
- 홈 가로 카드는 누를 수 없다. 버튼이 아닌 `<li>`이고 공유는 전체 목록에서 연다.
- 전체 목록 줄은 줄 전체가 버튼이고 휴지통 버튼은 형제 요소로 둔다.
- 닫으면 `useDialogFocusRestore`로 누른 곳에 포커스가 돌아간다.

## 버튼

| 환경                                         | 저장하기            | 인스타그램·카카오톡·더 보기                                   |
| -------------------------------------------- | ------------------- | ------------------------------------------------------------- |
| 새 앱 (`canUseNativeVideo()`)                | `saveVideoNatively` | `shareVideoNatively`                                          |
| 브라우저 (브리지 없음)                       | mp4 다운로드        | `navigator.share({ files, text })`, `canShare`가 안 되면 숨김 |
| 구 버전 앱 (브리지는 있고 `videoShare` 없음) | 숨김                | `canShare`가 되면 `navigator.share`, 안 되면 숨김             |

- `canShare`는 영상이 나오기 전에 빈 `video/mp4` File로 확인해, 버튼이 나타났다 사라지지 않게 한다.
- 다운로드 파일 이름은 `focusmakers-timelapse-YYYYMMDD.mp4`이고 날짜는 공부를 시작한 날이다.
- 브라우저 공유 본문도 `timelapseShareText`를 써 설치 링크와 UTM을 붙인다.
- 브라우저 결과는 공유 성공 `shared`, `AbortError`는 `dismissed`, 그 밖의 오류는 `failed`, 다운로드는 `saved`로 바꾼다.
- 저장이나 공유를 하나 보내면 결과가 올 때까지 버튼 4개를 비활성으로 둔다. 두 번 저장되는 일과 브라우저 공유 창이 겹쳐 `InvalidStateError`가 나는 일을 막는다.
- 비활성 버튼은 흐리게 그리고 `aria-disabled`를 단다.
- 버튼은 72×80, 아이콘 원은 56이라 44px 터치 타겟을 넘는다.

## 안내 줄

| 상황                                          | 문구                                                                         | 함께 두는 것              |
| --------------------------------------------- | ---------------------------------------------------------------------------- | ------------------------- |
| 영상 만드는 중                                | `공유할 영상을 생성하고 있어요` (전체 목록은 재생기 위, 결과 화면은 안내 줄) | 진행 막대, 버튼 비활성    |
| 앱 저장 `saved`                               | `사진 앱에 저장했어요` (결과 화면은 시트를 닫고 다 닫힌 뒤 토스트로)         | 없음                      |
| 앱 저장 `denied`                              | `사진 접근 권한이 꺼져 있어요`                                               | `설정 열기`               |
| 앱 저장 `failed`                              | `저장하지 못했어요. 다시 시도해 주세요`                                      | 없음                      |
| 공유 `failed`                                 | `공유하지 못했어요. 다시 시도해 주세요`                                      | 없음                      |
| 공유 `shared`·`dismissed`                     | 안내 없음                                                                    | 없음                      |
| 영상 만들기 실패                              | `영상을 만들지 못했어요`                                                     | `다시 시도` (`refetch`)   |
| `TimelapseVideoError.stage === "unsupported"` | `이 기기에서는 영상을 만들 수 없어요`                                        | 버튼 비활성 유지          |
| 쓸 수 있는 버튼이 하나도 없음                 | `앱을 업데이트하면 저장하고 공유할 수 있어요`                                | 없음                      |
| 브라우저 다운로드                             | 안내 없음 (브라우저가 다운로드 표시를 띄운다)                                | 결과 화면은 시트만 닫는다 |

- 안내 줄은 `role="status"`로 읽어 준다.
- 마지막 결과만 남긴다. 새로 누르면 지우고 다이얼로그를 닫으면 버린다.
- `설정 열기`는 `trackOsSettingsOpened("timelapse_share")` 뒤에 `open-settings`를 보낸다. source 유니온에 `"timelapse_share"`를 더한다.

## 분석 이벤트

- 결과가 정해진 뒤 `trackTimelapseShareTapped({ button, result, entry })`가 `timelapse_share_tapped`를 한 번 보낸다.
- `button`은 `save`·`instagram`·`kakao`·`more`다.
- `result`는 `VideoResultStatus` 5종이다.
- `entry`는 `result`·`home`·`list`다. 홈에서는 더 이상 열지 않지만 분석 스키마를 유지하려고 `home`을 남긴다.

## Figma

- S9-2와 S9-4의 공유 시트에 상태 프레임을 라이트·다크로 더한다.
- 대상은 준비 중 흐린 버튼, 안내 줄(저장함, 권한 꺼짐과 설정 열기, 실패, 만들기 실패와 다시 시도), 업데이트 안내다.

## 테스트

목록은 계획 단계(5-1)에서 따로 승인받는다.

- 다이얼로그: 환경별 버튼 노출, 준비 중 비활성, 결과별 안내 줄, 설정 열기, 이벤트 속성, 빈 곳을 누르면 닫힘.
- 결과 화면: 카드 없이 시트만 열림, 사진 쿼리 안 읽음, 앱 저장 성공이면 닫고 토스트, 브라우저 다운로드면 토스트 없이 닫힘, 준비 중 안내 줄에 문구와 진행 막대.
- 누르는 곳 2곳: 누르면 열리고 닫으면 포커스가 돌아온다.
- 홈: 썸네일은 버튼이 아니고 눌러도 다이얼로그가 열리지 않는다.
- 실기기: iPhone과 A23에서 결과·목록 진입, 저장·공유·권한 거부, 라이트·다크, reduced-motion.

## 범위 밖

- 인스타그램 스토리·카카오톡으로 바로 보내기는 BY-890에서 한다.
- 안드로이드 뒤로 가기로 다이얼로그 닫기는 다른 다이얼로그와 함께 따로 다룬다.
