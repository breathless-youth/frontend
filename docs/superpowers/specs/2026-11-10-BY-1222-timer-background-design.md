# 타이머 배경 설정 설계 (BY-1222)

- 티켓: BY-1222 (하위 BY-1223 설정 행·선택 화면, BY-1224 내 사진, BY-1225 미리보기·적용·공부 화면 표시)
- 시안: Claude Design `타이머 배경.dc.html`의 1a(배경 선택), 1m(선택 후 미리보기), 1d(설정 행)와 Figma `FocusMakers V3` 섹션 `10319:18208`
- 선행: BY-1219 싱글 세션 v3 개편 (이 브랜치의 base)

## 목표

사용자가 설정에서 타이머 배경을 골라 싱글룸 공부 화면(기본 모드) 뒤에 깔 수 있게 한다.

## 확정한 결정

| #   | 결정               | 내용                                                                                                                                                                                 |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1   | 배경이 보이는 모드 | 기본 모드의 공부 화면 뒤에만 깐다. 심플 모드는 지금처럼 어두운 화면이고, 카메라를 키운 동안은 카메라가 배경을 가린다.                                                                |
| 2   | 설정 행 문구       | 시안의 보조 문구 `심플 모드에서 보여요`는 빼고 지금 쓰는 배경 이름만 보인다. Figma에도 반영한다.                                                                                     |
| 3   | 기본 배경          | `심플`이다. 감독관은 자산이 없어 `출시 예정`으로 잠근다.                                                                                                                             |
| 4   | 감시·자연 타일     | 시안의 그라데이션 타일을 쓰고 모두 `출시 예정`으로 잠근다.                                                                                                                           |
| 5   | Android 사진 읽기  | 프로필용 네이티브 선택기 모듈에 배경용 함수를 더한다. 옛 앱과 iOS, 브라우저는 웹 파일 입력을 쓴다.                                                                                   |
| 6   | 사진 저장          | 긴 변 1920px JPEG로 줄여 기기 IndexedDB에 저장하고, 크기·위치 조정값을 함께 둔다. 원본은 저장하지 않는다.                                                                            |
| 7   | 기록               | 사진을 기기에만 두고 서버로 보내지 않는다는 결정을 ADR 0022로 남긴다.                                                                                                                |
| 8   | 저장 범위          | 고른 배경은 기기마다 따로 저장하고 서버나 다른 기기와 맞추지 않는다.                                                                                                                 |
| 9   | 글자 가독성        | 시안대로 배경 위에 검정 35% 덮개를 깔고 시간 묶음에 글자 그림자를 둔다. 처음에는 위아래 그라데이션으로 정했다가 Claude Design 1a·1m을 따라 바꿨다.                                   |
| 10  | 미리보기           | 도움말 화면처럼 실제 시계·하단 바 컴포넌트로 그린 가짜 세션 화면을 70%로 줄여 보여 준다. 뒤로 가기와 제목은 페이지 머리 줄이 맡고, 미리보기 중에는 제목이 고른 배경 이름으로 바뀐다. |
| 11  | 분석 이벤트        | `settings_row_pressed`에 `timer_background`를 더하고, `timer_background_applied`, `timer_background_photo_added`, `timer_background_photo_removed`를 새로 보낸다.                    |

## 구조

```
설정 › 타이머 배경 행 ──▶ /settings/timer-background (선택 화면)
                              │ 타일 누름
                              ▼
                        미리보기(70% 가짜 세션 + 적용하기, 내 사진은 핀치·드래그)
                              │ 적용하기
                              ▼
             localStorage: 고른 배경 ◀── 공부 화면(RoomPage)이 입장할 때 읽음
             IndexedDB: 내 사진 JPEG + 조정값 ◀── 배경 레이어가 사진을 읽어 그림
```

### 웹 (`apps/web/src/features/timer-background/`)

- `timerBackgroundCatalog.ts`: 묶음(내 사진·감시·자연·심플)과 프리셋 항목, 잠금 여부, 타일 그라데이션을 정의한다.
- `timerBackgroundSettings.ts`: 고른 배경(`simple` | `photo` + 사진 id)을 localStorage에 읽고 쓴다. 깨진 값이나 지워진 사진은 `simple`로 본다.
- `timerBackgroundPhotos.ts`: IndexedDB `focusmakers-timer-background`의 `photos` 저장소에 사진(JPEG Blob, 추가 시각, 조정값)을 10장까지 둔다.
- `prepareBackgroundPhoto.ts`: 웹 파일 입력 경로에서 사진을 긴 변 1920px JPEG로 줄인다. 프로필 사진 줄이기와 같은 방식(`createImageBitmap` + canvas)을 쓴다.
- `nativeBackgroundPhoto.ts`: 앱 선택기 경로. 프로필 사진 브리지와 같은 요청·응답 방식을 쓰되 메시지 이름과 표시를 따로 둔다(`pick-background-photo`, `backgroundPhotoPicker=1`). 프로필 선택기만 있는 앱이 이 메시지를 모르는 경우를 구분하기 위해서다.
- 화면: 선택 화면, 미리보기, 공부 화면 배경 레이어.

### 앱 (`apps/mobile`)

- `ProfilePhotoPicker` 모듈에 `pickBackground()`를 더한다. 시스템 사진 선택기로 고른 사진을 EXIF 방향대로 세우고, 자르지 않고 긴 변 1920px JPEG(품질 80)의 base64로 돌려준다.
- 브리지 처리기가 `pick-background-photo`를 받아 `background-photo-result`로 답한다.
- 모듈이 있는 Android 바이너리만 웹뷰 URL에 `backgroundPhotoPicker=1`을 붙인다.

### 공부 화면

- 기본 모드이고 카메라를 키우지 않은 동안 `CameraPreviewSurface` 뒤 단색 바탕 위에 배경 레이어를 그린다.
- 사진은 `object-fit: cover`로 그리고, 조정값의 위치를 `object-position`과 `transform-origin`에 함께 주어 같은 지점을 기준으로 키운다.
- 이 방식은 시안의 공식(cover 크기 × 배율, 넘친 길이만큼만 이동)과 같은 결과를 내면서 화면 크기를 재지 않아도 된다.

## 실기기 확인 뒤 바꾼 것

- `적용하기`를 누르면 저장한 뒤 설정 화면으로 돌아가고, `배경을 적용했어요` 토스트는 설정 화면에서 보인다.
- 저장(localStorage·IndexedDB)에 실패하면 적용·삭제됐다고 알리지 않고 실패 토스트를 띄우며, 적용은 미리보기에 머문다.
- 머리 줄 뒤부터 칩 줄 아래 끝까지 블러를 깔고 아래로 갈수록 옅어지게 해, 칩 아래 타일은 선명하게 둔다.
- 내 사진 묶음은 한 줄에 두고 좌우로 넘기며, 타일 너비는 세 칸 격자와 같고 타일 단위로 멈춘다.
- 스크롤하면 다음 묶음 제목이 화면 위쪽 40% 안으로 들어올 때 그 칩이 켜진다.
- 카메라를 키우거나 줄이는 움직임 동안에는 배경을 남겨 두어 끝에서 배경이 툭 나타나지 않는다.

## 위험

- 긴 변 1920px JPEG의 base64는 수백 KB라 브리지 메시지 하나로 보내는 첫 사례다. 실기기에서 크기와 전달 시간을 측정하고, 1MB를 넘으면 품질이나 크기를 낮춘다.
- 이미지 배경은 카메라·추론과 함께 돌아도 정지 이미지라 부담이 작다고 본다. 영상 배경은 범위 밖이다(BY-1118).
