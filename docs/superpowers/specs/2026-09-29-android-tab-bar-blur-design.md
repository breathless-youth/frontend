# Android 하단 탭 바 블러 잔상 수정 설계 (BY-790)

## 문제

- Android에서 탭 바의 아이콘·라벨·활성 알약 주변에 뿌연 잔상이 생겼다.
- 라이트 모드에서 탭 바 윤곽과 그림자가 보이지 않았다.
- iOS는 시안대로 보였다.

## 원인

- expo-blur 15.0.8의 `dimezisBlurView`는 가장 가까운 Screen 전체를 찍어 흐리게 한다.
- 알약·아이콘·라벨은 BlurView의 형제라 촬영에서 빠지지 않아, 탭 바가 자기 모습을 흐려 밑에 깔았다.
- 같은 네이티브 코드가 블러를 켜며 배경색을 투명으로 덮어써 `softBlue.glass.surface`가 사라졌다.
- `shadow*` 속성은 iOS 전용이고, Android `elevation`은 배경색 없는 뷰에 그림자를 그리지 않았다.
- 이 버전에는 블러 대상을 지정하는 `BlurTargetView`가 없다.

## 결정

| 항목                             | 결정                                                                         | 이유                                                                          |
| -------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| Android 배경                     | 블러를 끄고 불투명 `View`를 깐다                                             | 잔상과 배경색 소실이 함께 없어지고, 웹뷰를 매번 다시 그리는 비용도 사라진다   |
| Android 배경색                   | 라이트 `colors.bg.base`, 다크 `colors.bg.layer1`                             | 새 토큰 없이 기존 토큰을 쓴다, 다크 값은 유리색 원색과 거의 같다              |
| iOS 배경                         | 기존 `BlurView` + `glass.surface` 유지                                       | iOS는 문제가 없다                                                             |
| 탭 바 그림자                     | `boxShadow: 0 10px 30px glass.shadow` 하나로 양쪽 처리                       | iOS `shadowRadius: 15`는 CSS blur 30px에 해당한다                             |
| 라이트 알약 그림자               | `boxShadow: 0 2px 8px rgba(31,42,61,0.1)`                                    | 같은 이유                                                                     |
| 라이트 활성 알약 색              | 양 플랫폼 모두 `colors.bg.layer2.light`, 다크는 `glass.activePill.dark` 유지 | 라이트에서는 바가 사실상 흰색(Android 255, iOS 254)이라 흰 알약(255)이 묻혔다 |
| 테두리·하이라이트·딤·숨김 페이드 | 그대로                                                                       | 범위 밖                                                                       |

## 범위 밖

- 실제 블러가 있는 Android 유리 표현은 SDK 업그레이드(BY-762) 뒤 `BlurTargetView`로 다시 검토한다.
- 시스템 내비게이션 바 영역에 웹 콘텐츠가 비쳐 보이는 문제는 별도 건이다.

## 검증

- 단위 테스트: Android는 `BlurView`를 렌더하지 않고 불투명 배경을 렌더한다, iOS는 `BlurView`를 렌더한다.
- 단위 테스트: 라이트 활성 알약은 양 플랫폼 모두 `layer2`, 다크는 유리색이다.
- `glass.activePill.light`는 더 이상 읽는 코드가 없지만 토큰 쌍을 유지하려고 지우지 않았다.
- 실기기: Galaxy A23 Dev Client에서 라이트·다크 스크린샷으로 잔상·윤곽·그림자를 확인한다.
- iOS: 수정 전후 스크린샷으로 그림자 퍼짐을 대조한다.
