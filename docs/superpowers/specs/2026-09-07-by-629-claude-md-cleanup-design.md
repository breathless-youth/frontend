## 배경

세 `CLAUDE.md`(루트 97줄, `apps/web` 127줄, `apps/mobile` 208줄, 합계 432줄)의 상당수가 경위 서술과 날짜 박힌 결정 기록이다. 날짜 표기 문장만 세 파일 합쳐 51개다. 규칙서로 열었는데 변경 이력서가 돼 있어, 해당 폴더의 파일을 고칠 때 지켜야 할 규칙이 경위 사이에 묻힌다.

`CLAUDE.md`에는 그 폴더의 파일을 고칠 때 모르면 깨뜨리는 것만 남기고, 프로젝트 전반의 경위와 결정은 근거 문서로 링크한다.

## 기준

- 남기는 것: 하지 말 것, 명령어, 경계 규칙, 근거 문서로 가는 링크 한 줄.
- 각 규칙은 한두 문장으로 줄이고 이유는 링크 뒤에 둔다.
- 옮기는 것: 경위·실측·날짜·티켓 번호가 있는 문장.
- 세션마다 반드시 지켜야 하는 규칙은 링크로 보내지 않고 한 줄로 남긴다. 근거 문서는 자동으로 읽히지 않는다.

## 도착지

옮길 내용 대부분은 이미 근거 문서가 있다. 설계 문서와 테스트 파일, 기존 ADR이 근거를 담고 있어 `CLAUDE.md`는 규칙 한 줄에 링크만 붙인다. 근거 문서가 없는 것만 새로 만든다.

## 완료 조건

- 세 `CLAUDE.md`에 날짜가 박힌 경위 서술이 없다.
- 각 규칙이 근거 문서 링크를 가진다.
- 세 파일 합계가 216줄 이하다.
- 옮긴 내용의 링크가 `CLAUDE.md`에 있고 죽은 링크가 없다.

## 검증

- 날짜 표기: 세 파일에서 날짜 정규식 `20[0-9][0-9]-[0-9][0-9]-[0-9][0-9]` 검색 결과 중 마크다운 링크 목적지(설계 문서 파일명)를 뺀 나머지가 0. 링크 안 파일명은 저장소가 날짜로 파일명을 짓는 관례라 경위 서술이 아니다.
- 링크: 상대 경로 링크가 가리키는 파일이 실제로 존재하는지 확인한다.
- 줄 수: `wc -l` 합계 216 이하.
- 규칙 보존: 삭제 전후로 "하지 말 것"·경계·개인정보 규칙의 개수가 줄지 않았는지 대조한다.
