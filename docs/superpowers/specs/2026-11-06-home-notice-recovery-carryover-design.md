# 홈 안내 순서 변경

2026-11-06 사용자 요청으로 플래너 승인 설계의 홈 안내 규칙을 변경한다. 사용자가 메달 자동 팝업을 제거하고 그 판단 위치에 미완료 할 일 안내를 넣도록 두 번 지정했다. 마지막 문장의 ‘메달’은 앞의 구체적인 지시를 따라 미완료 안내로 해석했으며 이 해석을 작업 중 알렸다.

- 홈에서는 공지 → 세션 복구 → 미완료 할 일을 같은 진입에서 하나씩 표시한다. 대상이 없는 단계는 건너뛴다.
- 공지나 복구 창이 나왔다는 이유로 미완료 안내를 다음 홈 진입까지 보류하지 않는다.
- 홈의 메달 자동 조회·표시·본 것으로 처리하는 요청을 제거한다. 랭킹 화면의 메달 기록은 유지한다.
- 공지의 표시 제한, 복구 대상 기준, 알림 권한 완료 대기, 미완료 안내의 명시적인 보류·선택·재시도·사용자 범위는 유지한다.
- 미완료 안내가 열린 뒤 복구 결과가 늦게 도착하면 미완료 창만 잠시 숨긴다. 복구 확인 뒤 같은 후보와 선택으로 이어 표시한다.
- OS 권한과 업데이트 안내의 순서는 이번 변경 범위에 포함하지 않는다.

기존 홈 호스트와 가져오기 훅을 수정한다. 별도의 전역 모달 관리자나 새로운 API를 만들지 않는다. 다음 진입으로 넘기는 기존 방식은 같은 진입에서 순차 표시하라는 요청과 맞지 않아 사용하지 않는다. 모달의 색·문구·배치는 변경하지 않는다.

실기기와 배포 개발 API 검증은 기존 작업과 병렬로 계속하되, 자동 안내의 새 순서는 변경 후 테스트 결과로 구분한다. 전수 팝업 조합과 38장 픽셀 비교는 사용자 요청대로 추가 필수 검수에서 제외한다. 커밋·push·배포는 하지 않는다.
