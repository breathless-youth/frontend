# BY-974 소셜룸 과목 페이지 연결 설계

상위 BY-714(소셜룸 UI/UX 개선)의 하위 작업이다. 싱글룸 과목 페이지(BY-947·BY-939)를 소셜룸 세션에서도 쓰게 한다. 규칙은 위키 `BY-404-실시간-룸.md`의 "과목" 절과 "시간 표시" 절을 따른다. BY-973이 만든 바 버튼 자리와 모양을 이어 쓴다.

## 결정 (2026-10-25, 사용자가 중간 승인 없이 진행하도록 지시. 아래는 위키와 기존 결정에서 정한 값이다)

- 하단 바는 카메라, 과목, 배경음, 나가기 순서다(Figma 바 순서에서 타이머만 뺀 것). 과목 버튼은 바의 다른 버튼과 같은 웹 버튼이고 iOS 앱 glass로 등록하지 않는다.
- 과목을 고르면 과목 버튼이 켜짐 색이 된다(싱글룸과 같다).
- 과목을 골랐으면 왼쪽 위 내 시간 글자(순공, 총) 바로 아래에 왼쪽을 맞춰 과목 알약(과목 이름, 과목 시간)을 보인다. 과목을 고르지 않았으면 알약을 그리지 않는다. (2026-10-25 실기기 확인 뒤 사용자 결정. 처음에는 바 바로 위 왼쪽이었는데, 바가 자동으로 숨으면 알약이 타일 사이에 떠 보였다.)
- 조작이 숨으면(화면 탭, 5초 자동 숨김 모두) 총 줄이 사라지고 알약이 그 자리로 올라가 순공과 알약만 남는다. 조작이 다시 보이면 순공, 총, 알약 순서로 돌아온다. 움직임은 세션 조작과 같은 500ms 곡선이고 동작 줄이기에서는 끈다. 과목을 고르지 않았어도 총 줄은 조작과 함께 숨는다. 숨은 총 줄은 스크린리더에서도 빠진다. (2026-10-25 실기기 확인 뒤 사용자 결정)
- 세로 타일은 위로 순공, 총, 알약이 모두 보일 때의 높이를, 아래로 바 자리만 비운다. 그래서 조작을 숨기거나 보여도 타일이 움직이지 않고 알약에 겹치지 않는다. 가로는 그대로 따로 비우지 않고 겹침을 받아들인다.
- 과목 이름이 길면 알약이 화면 폭(좌우 16px 여백)을 넘지 않게 이름을 자른다.
- 과목 알약은 5초 자동 숨김과 상관없이 늘 보이고, 누르면 과목 페이지가 열린다. 일시정지 중에는 싱글룸 라벨처럼 멈춘 모양이다.
- 과목 페이지는 싱글룸과 같은 `SessionPage` + `SubjectPanel`이다. 아래쪽에 내 순공 시간을 보이고 가로 화면에서는 가로 배치로 연다.
- 카메라가 켜진 상태에서 재생 버튼을 누르면 그 과목으로 바꾸고 페이지를 닫는다.
- 카메라가 꺼진 상태에서 재생 버튼을 누르면 그 과목을 고르고 페이지를 닫은 뒤 카메라 켜기 확인 창을 연다. 취소하면 과목만 고른 채 일시정지를 유지한다.
- 과목 페이지와 배경음 페이지는 동시에 열리지 않는다. 열린 동안 조작은 숨지 않고, 닫으면 포커스가 연 버튼이나 알약으로 돌아온다.
- 페이지를 열 때 history 항목을 쌓지 않는다(BY-973과 같음). 세션이 공부 상태를 벗어나면 페이지를 닫는다.
- 페이지는 닫기 버튼과 Escape로만 닫고 iOS 가장자리 스와이프로는 닫지 않는다. 소셜룸은 탭 웹뷰 안에 있어 입장 때 스와이프를 끄는데, 꺼진 동안 쌓은 history 항목은 스와이프 미리보기가 하얗게 비거나 페이지 잔상이 남았다. 싱글룸처럼 하려면 소셜룸을 별도 네이티브 화면으로 열어야 해서 범위 밖으로 둔다. (2026-10-25 실기기 확인 뒤 사용자 결정)
- 과목 구간과 완료한 할 일은 싱글룸과 같은 세션 제출에 싣는다(`getCompletedTaskIds`).
- 과목 페이지 계측(`trackSubjectSheetOpened`·`Closed`·`ItemSelected`)은 싱글룸과 같이 보낸다.
- 내가 고른 과목은 다른 참가자에게 보내지 않는다.

## 테스트

- 바 순서가 카메라, 과목, 배경음, 나가기다.
- 과목 버튼을 누르면 과목 페이지가 열리고, 닫으면 포커스가 버튼으로 돌아온다. 알약으로 열면 알약으로 돌아온다.
- 과목을 고르면 알약에 이름과 시간이 보이고, 고르지 않으면 알약이 없다.
- 알약은 자동 숨김 뒤에도 남는다. 조작이 숨으면 총 줄이 접히고 알약은 시간 글자 바로 다음 칸에 남는다. 다시 보이면 총 줄이 펼쳐진다.
- 알약 위로 흐림 배경을 끊는 transform·opacity·filter 조상이 없다. 이름이 길면 알약이 화면 여백 안에서 잘린다.
- 카메라가 켜진 상태에서 재생 → 페이지 닫힘, 과목 선택.
- 카메라가 꺼진 상태에서 재생 → 과목 선택, 페이지 닫힘, 카메라 켜기 확인 창 열림. 취소 → 일시정지 유지, 과목 선택 유지. 확인 → 카메라 켜짐, 측정 재개.
- 세션 제출에 완료한 할 일이 실린다.
- 과목 버튼은 앱 glass로 등록하지 않는다.

## 범위 밖

- 타이머 버튼(별도 기획), 바 glass(BY-975).
- 실기기 확인 항목: 알약 위치와 총 줄 접힘 움직임, 회전, 두 기기에서 상대에게 과목이 보이지 않는지, 과목 알약 유리 배경(흐림) iOS·Android.
- 포커스 복귀 대체 대상(`fallback`)은 공용 `useDialogFocusRestore`에 선택 인자로 넣었다. 넘기지 않는 다른 다이얼로그는 동작이 그대로다.
- 태블릿에서 알약은 Figma대로 바와 같은 비율로 커진다. 싱글룸 과목 줄은 태블릿에서도 크기가 그대로라 둘이 다르다.
