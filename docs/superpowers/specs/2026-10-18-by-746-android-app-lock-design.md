## 목표

iOS와 같은 웹 화면·브리지 계약(`app-lock-*`) 그대로, Android에서도 공부하는 동안 고른 앱이 잠기고 끝나면 풀린다. 사용자 동작은 우선 동작하는 것을 기준으로 하고 화면 세부는 구현하며 다듬는다.

## 구조

웹과 브리지는 바꾸지 않는다(설정 화면의 미지원 문구만 플랫폼에 맞춘다). 네이티브 쪽에서 플랫폼을 가른다.

```
웹 ─app-lock-*─▶ appLockRelay(그대로) ─▶ appLock.ts(iOS: RNDA) / Android: modules/app-lock (Kotlin)
                                          └─ 고르기·고지·배터리 안내는 RN 모달 화면
Android 잠금: 포그라운드 서비스(specialUse) ─0.5초─▶ UsageStatsManager로 앞 화면 앱 확인 ─잠긴 앱─▶ 오버레이 창
```

| 단위                                                        | 역할                                                                                                                                                                                                                                                    |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `apps/mobile/modules/app-lock/` (로컬 Expo 모듈, Android만) | 권한 상태(사용정보 접근·다른 앱 위에 표시), 설정 화면 열기, 설치된 런처 앱 목록(이름·아이콘), 선택 저장(백업에서 빠지는 앱 파일, 기기 안), 잠금 시작·해제, 포그라운드 서비스와 오버레이. `AndroidManifest.xml`에 권한·서비스·`<queries>` 런처·홈 인텐트 |

## 흐름

**켜기(authorize).** 두 권한이 다 있으면 바로 허용. 없으면 고지·동의 모달을 연다. `동의하고 설정 열기` → 사용정보 접근 설정 화면 → 앱으로 돌아오면 다시 확인 → 다른 앱 위에 표시가 남았으면 A1-2 상태 → 둘 다 켜지면 모달을 닫고 허용으로 답한다. `나중에 할게요`나 쓸어 닫기는 허용 안 됨으로 답한다(토글 OFF, 알림 없음). 알림 권한은 아래 "구현하며 달라진 것"대로 이번에는 요청하지 않는다.

**처음 켠 뒤.** 삼성·샤오미(Redmi·POCO 포함)면 켜기가 허용으로 끝날 때 배터리 안내를 한 번 띄운다. 띄웠다는 기록은 `expo-secure-store`에 남기고, 켜기 응답은 안내를 기다리지 않는다. `설정 열기`는 이 앱의 앱 정보 화면(`ACTION_APPLICATION_DETAILS_SETTINGS`)을 열고, 그 화면이 없는 기기면 배터리 최적화 목록 화면(`ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS`)을 연다. 시트의 순서는 앱 정보 화면부터 센다. 삼성은 `배터리 › 제한 없음 선택`, 샤오미는 `배터리 절약 › 제한 없음 선택 › 자동 시작 켜기`, 다른 제조사는 기본 Android(12 이상)의 `배터리 사용량 › 제한 없음 선택`이다. 제한 권한(`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`)은 쓰지 않는다.

**잠그기·풀기.** `startStudyLock`이 서비스를 시작한다. 서비스는 0.5초마다 앞에 뜬 앱을 확인하고, 잠긴 앱이면 오버레이를 띄운다. 다른 앱(홈 포함)으로 가면 오버레이를 내린다. 기본 홈 앱과 포메는 고른 목록에 남아 있어도 잠그지 않는다. `포커스 메이커스로 돌아가기`는 포메를 앞으로 가져오고 오버레이를 내린다. `stopStudyLock`은 서비스에 해제 명령을 보내 멈추게 한다. 서비스는 시작 12시간 뒤 스스로 멈춘다(ST-D13). 기기가 잠든 시간까지 세서 12시간을 잰다. 앱 프로세스가 죽으면 서비스도 함께 끝나 잠금이 풀린다(Android는 잠금이 남는 쪽보다 풀리는 쪽으로 실패한다).

**실행 시 정리.** `cleanupOnLaunch`는 서비스를 멈춘다. 돌고 있지 않으면 아무 일도 없다.

**권한 꺼짐.** iOS와 같은 규칙. 허용 기록이 있는데 두 권한 중 하나라도 꺼져 있으면 `revoked`.

| 잠금 해제                      | `stopService`                                                               | 해제도 `startService`로 서비스에 명령을 보낸다. 시작 명령은 맨 앞에서 `startForeground`를 부르고, 서비스는 명령마다 지금 요청 상태대로 계속 돌거나 멈춘다. 돌고 있지 않으면 해제 명령을 보내지 않는다. 시작마다 번호를 매겨 12시간 마감은 자기 번호가 마지막 시작일 때만 요청 상태를 내리고, 시작 명령을 보내지 못하면 그 시작만 되돌린다. 해제 직후 다시 시작해 해제 명령이 멈추지 않고 지나가도 새 시작 명령이 새 번호로 마감을 다시 잡는다 | 공부 화면에 들어갈 때 시작과 해제가 잇달아 오면 서비스가 `startForeground`를 부르기 전에 `stopService`로 내려가 Android가 앱을 죽였다(A23 실기기, `ForegroundServiceDidNotStartInTimeException`). 앱이 죽으면 사용자는 직전에 쓰던 잠긴 앱으로 돌아가 잠금 없이 쓰게 된다. 앞 공부의 마감이 새 시작과 겹쳐 요청 상태를 내리면 새 공부가 잠기지 않는다                                                                                            |
| 배터리 안내 다시 열기          | 처음 켤 때 한 번만                                                          | 설정 화면에 `배터리 설정 안내` 행을 두고 `app-lock-battery-guide`로 같은 시트를 다시 연다. 잠금을 쓸 수 있는 Android 앱에서만 보이고 켜짐과 상관없다. 처음 한 번 띄운 기록과 권한 상태는 건드리지 않는다. 삼성·샤오미가 아니면 기본 Android의 순서를 보여 준다                                                                                                                                                                                | `다음에 할게요`를 누르면 다시 열 길이 없었다. 다른 제조사도 설정에서 열 수 있게 되어 삼성 순서를 그대로 보여 주지 않는다                                                                                                                                                                                                                                                                                                                         |
| 배터리 `설정 열기`             | 배터리 최적화 예외 목록 화면(`ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS`) | 이 앱의 앱 정보 화면(`ACTION_APPLICATION_DETAILS_SETTINGS`)을 열고, 없으면 예전 목록 화면을 연다. 시트 순서도 앱 정보 화면부터 센다                                                                                                                                                                                                                                                                                                           | A23(Android 14)에서 목록이 `최적화하지 않은 앱` 필터로 열려 이 앱이 보이지 않았고, 시트의 `설정 › 배터리 › 백그라운드 사용 제한` 순서와도 맞지 않았다. 앱 정보 화면은 제조사와 상관없이 같은 인텐트로 열리고 배터리 메뉴가 그 안에 있다                                                                                                                                                                                                          |
