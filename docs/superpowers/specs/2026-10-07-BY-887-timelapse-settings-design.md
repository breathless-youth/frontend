# BY-887 설정 › 타임랩스 페이지 설계

- 티켓: BY-887 (상위 BY-822, 선행 BY-834 완료)
- 명세: AI 위키 `product/specs/BY-822-타임랩스.md` §1
- 시안: Figma V2 `YcyImcuVORDbBneii41Byh` S9-1 `5986:6824`
- 브랜치: `feature/BY-887-timelapse-settings` (base `dev`)

## 목표

설정 화면에서 타임랩스 저장 여부, 영상 비율, 영상에 넣을 정보를 고르게 한다. 설정값 모델과 저장은 BY-834의 `timelapseSettings.ts`를 그대로 쓰고, 이 티켓은 화면과 화면용 상태만 만든다.

## 설정 화면 진입

- 서비스 섹션의 `카메라 권한` 행과 `서비스 이용 가이드` 행 사이에 `타임랩스` 행(chevron)을 둔다.
- 행과 라우트는 `import.meta.env.VITE_TIMELAPSE === "on"`일 때만 존재한다(촬영과 같은 조건이라 운영에 동작하지 않는 설정이 보이지 않는다, 플래그 제거는 BY-892).
- 경로는 `/timelapse-settings`이고 다른 하위 화면처럼 `slideNavigate("forward", ...)`로 열며 쿼리를 이어받는다.
- 라우트 등록은 `App.tsx` lazy, `routes/lazyRoutes.ts` 로더, `prefetchSettingsSubPages`, `lib/nativeTabBar.ts`의 `FULL_SCREEN_PATHS` 네 곳에 함께 넣는다.
- 행을 누르면 `trackSettingsRowPressed("timelapse")`를 보낸다(`row` 유니온에 `"timelapse"` 추가).

## 타임랩스 페이지

`routes/TimelapseSettingsPage.tsx`. 위에서 아래로 다음 순서다.

### 헤더

- `ScreenBackHeader`에 제목 `타임랩스`를 둔다.
- 배경은 설정 화면과 같은 `theme-soft-blue bg-soft-blue`다.

### 저장 카드

- `타임랩스 저장` 라벨, ⓘ 툴팁, 스위치를 한 행에 둔다.
- 툴팁 문구는 `기기 내에만 최대 7일, 7개까지 보관돼요.`다.
- 저장을 끄면 아래 영상 비율, 미리보기, 영상에 넣을 정보 섹션을 숨긴다(2026-10-07 사용자 결정, 꺼짐 상태 시안은 추후 보완).
- 숨기고 보일 때 애니메이션은 넣지 않는다.

### 영상 비율

- 섹션 라벨은 `영상 비율`이다.
- 이미 있는 `ui/toggle-group`을 `type="single"`로 쓰고 시안 세그먼트 모양(트랙 `bg-control-track`, 선택 칸 `bg-layer-1` + 그림자)으로 꾸민다.
- 항목은 `세로 9:16`, `가로 16:9`다.
- 선택된 칸을 다시 누르면 Radix가 빈 문자열을 넘기는데, 이 값은 무시해 항상 하나가 선택돼 있게 한다.
- 기록 탭 `SegmentedControl`은 Tabs라 탭 패널 의미가 붙어 값 선택에 맞지 않아 쓰지 않는다.

### 미리보기

- 섹션 라벨은 `미리보기`, 컴포넌트는 `features/timelapse/TimelapsePreview.tsx`다(BY-888 재생 화면이 같은 폴더에서 찾게 둔다).
- 9:16이면 180×320 세로 상자, 16:9면 카드 안쪽 너비에 맞춘 16:9 가로 상자다.
- 상자 배경은 시안의 예시 회색이고 실제 사진은 쓰지 않는다.
- 오른쪽 위 `포커스 메이커스` 워터마크는 항상 보이고, 모서리 곡선에 닿지 않게 위·오른쪽 12px 안쪽에 둔다.
- D-Day는 사용자가 정한 값을 `D-N · 제목`으로 보여주고, 불러오기 전이거나 실패하면 가짜 숫자가 내 D-Day로 읽히지 않게 숫자 없는 `D-Day`를 쓴다. D-Day가 없으면 켜 둔 값이 남아 있어도 그리지 않는다(2026-10-07 사용자 결정).
- 얼굴 가림을 켜면 가운데에 BY-834가 쓰는 `public/timelapse/face-sticker.png`를 그린다.
- D-Day와 연속 공부는 왼쪽 위에 왼쪽 정렬로 쌓고, D-Day는 순공 시간보다 작고 다른 정보보다 큰 글씨, 연속 공부는 오른쪽에 🔥를 붙인다(2026-10-07 실기기 검증 뒤 사용자 결정).
- 날짜, 순공 시간, 집중률은 오른쪽 아래, 흐름 바 바로 위에 이 순서로 쌓는다.
- 값은 시안의 예시 고정값이다(`10월 5일`, `순공 2시간 14분`, 집중률·D-Day·연속 공부 예시는 시안의 숨긴 텍스트 노드 `6008:8415`~`6008:8417`에서 읽어 쓴다).
- 흐름 바는 시안의 12칸 예시 색(순공·자동 멈춤·일시정지)을 고정으로 그린다.
- 켠 요소가 하나도 없으면 가운데에 `공부 중 화면`를 보여준다.
- 미리보기는 장식이라 상자 전체에 `aria-hidden`을 건다(같은 정보는 스위치가 이미 읽어 준다).
- 비율이 바뀌면 미리보기를 `key`로 새로 그린다. WebKit은 고정 크기에서 `aspect-ratio`로 클래스만 바뀌면 높이를 0으로 남긴다(실기기 검증에서 발견).

### 영상에 넣을 정보

- 섹션 라벨은 `영상에 넣을 정보`이고 `TIMELAPSE_INFO_KEYS` 순서대로 스위치 7행을 둔다.
- 라벨은 `얼굴 가림`, `집중 흐름 바`, `날짜`, `순공 시간`, `집중률`, `D-Day`, `연속 공부`다.
- 얼굴 가림 옆 툴팁 문구는 `처음 인식된 얼굴만 가려요.`다(2026-10-07 사용자 결정).
- D-Day 행은 `ddayQuery(userId)`의 데이터가 `null`(미설정)일 때만 스위치 대신 누를 수 없는 `디데이 설정 필요` 문구를 보여준다.
- 불러오는 중이거나 실패했거나 `userId`가 아직 없으면 스위치를 보여준다.
- D-Day가 없어 문구로 바뀌어도 저장된 `dday` 값은 건드리지 않는다(촬영·재생 쪽에서 D-Day가 없으면 빼면 된다).
- 홈 탭에서 D-Day를 바꿔도 설정 탭은 다른 웹뷰라 캐시가 바뀌지 않는다. `ddayQuery`의 `staleTime`을 0으로 두어 탭이 다시 보일 때마다 새로 읽는다(실기기 검증에서 발견, 기록 탭에서 여는 플래너도 같은 문제가 있었다).

## 상태와 저장

- `features/timelapse/useTimelapseSettings.ts` 훅 하나가 화면 상태를 맡는다.
- 마운트할 때 `loadTimelapseSettings()`로 읽고, 읽기 전에는 `null`을 돌려 페이지가 본문을 비워 둔다(기본값이 먼저 보였다가 바뀌는 일을 막는다).
- 값을 바꾸면 상태를 바로 갱신하고 `saveTimelapseSettings()`를 호출한다.
- 이 화면만 값을 쓰므로 localStorage 변경 구독은 두지 않는다.
- 세션 웹뷰는 BY-834대로 세션 시작 때 한 번 읽는다.

## 스위치

- `ui/switch`에 `size` prop을 더해 `"settings"`일 때 51×31 트랙과 27 노브를 쓴다.
- 이 크기의 색은 켜짐 `--color-primary`, 꺼짐 `--color-bg-layer-2`로 `PermissionToggle`과 같다(다크 모드가 이미 맞춰진 토큰이다).
- 기본 크기는 배경음 시트가 쓰는 지금 모양을 유지한다.
- 각 스위치는 라벨 텍스트와 `aria-labelledby`로 묶는다.

## 분석 이벤트

- 값이 바뀔 때마다 `trackTimelapseSettingChanged({ setting, value })`가 `timelapse_setting_changed`를 보낸다(2026-10-07 사용자 결정).
- `setting`은 `enabled`, `aspect`, `face_mask`, `flow_bar`, `date`, `focus_time`, `focus_rate`, `dday`, `streak` 중 하나다.
- `value`는 스위치면 boolean, 비율이면 `"9:16"` 또는 `"16:9"`다.
