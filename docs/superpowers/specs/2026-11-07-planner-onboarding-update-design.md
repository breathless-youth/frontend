# 플래너 온보딩과 홈 업데이트 표시

사용자는 비교 시안의 OP2를 골랐고, 홈은 제안했던 배지·카드 대신 플래너 버튼 오른쪽 위의 작은 파란 점으로 지정했다. 한 번 누르면 그 사람에게 다시 표시하지 않는다고 정했다.

온보딩 2단계는 지금 일간 플래너의 날짜·요일, 일간/주간 전환, 과목과 할 일, 원형 체크, 10분 격자를 보여 준다. 왼쪽 아래에 할 일을 확대하는 OP2 구성을 적용한다. 기존 제목과 다음 버튼, 다른 온보딩 단계는 유지한다. 목업은 합성 예시이며 실제 과목이나 할 일을 만들지 않는다.

홈은 플래너 버튼 오른쪽 위에 기존 primary 색의 작은 점만 표시한다. 웹과 네이티브 버튼에서 모두 누르면 사라지고, 다른 계정의 상태와 섞이지 않는다. 화면 배치나 공지 → 세션 복구 → 미완료 안내 순서는 바꾸지 않는다.

사용자 후속 요청으로 점을 버튼 테두리 쪽으로 2px 더 붙이고 흰 테두리를 없앤다. 점은 버튼 앞에 온전히 보인다. 현재 앱 부품은 배지를 지원하지 않으므로 점이 있는 동안에는 버튼과 점을 함께 웹으로 그리고, 확인 뒤에는 기존 네이티브 버튼으로 돌아간다.

기존 온보딩과 같은 계정별 기기 저장소를 사용하는 것은 구현 판단이다. 같은 기기에서 앱을 다시 열어도 확인 상태를 유지한다. 저장소가 막힌 경우에는 현재 문서 안에서 확인 상태를 기억한다. 다른 기기와 서버 동기화하는 기능은 새로 만들지 않는다.

추가 요청한 계정 작업의 성공 알림은 기존 하단 토스트를 사용한다. 로그인은 `로그인을 성공했어요!`, 로그아웃은 `로그아웃 되었어요`, 계정 삭제는 `계정이 삭제되었어요`로 표시한다. 성공한 경우에만 한 번 표시하며 취소·실패에는 표시하지 않는다. 설정에서 시작한 로그인·로그아웃·계정 삭제를 마쳐도 설정 화면에 남는다. 그룹 로그인은 기존 목적지를 유지한다. 계정 전환 때문에 알림이 사라지지 않도록 기존 성공 신호와 새 활성 설정 화면을 연결한다.

사용자 후속 요청으로 색이 순서대로 채워지는 6초 반복 효과를 복원한다. 합성 예시 기록은 06:40~19:10에 세 과목으로 나누고 합계는6시간54분, 예시 현재 시간은19:41로 맞춘다. 동작 줄이기 설정에서는 애니메이션 없이 전체 색을 표시한다.
