# BY-800 세션 상태 필 V1.4 디자인으로 되돌리기

## 배경

v2에서 바꾼 상태 필(상태별 색 배경)보다 V1.4의 어두운 반투명 필이 낫다는 쪽으로 팀 의견이 모였다. V1.4에 있던 왼쪽 색 점은 빼고 되돌린다.

- V1.4 원본: `zQOglXxTTaI88OuqIeOYQa` 노드 `68:905`, 컴포넌트 세트 `Session / Status Pill`(`State=Focus|Distract|Paused`)

## 결정

- 상태 구분은 V1.4 그대로 둔다. 비집중만 주황 테두리이고, 측정 중과 일시정지는 문구로 구분한다. 일시정지는 타이머가 회색으로 바뀌어 필 밖에서도 드러난다.
- 온보딩 가이드 목업 필에서도 색 점을 뺀다.
- 구조는 유지한다. `Badge`의 `session-*` variant 3개와 `sessionTheme.ts`의 CSS 변수 값만 바꾼다. 온보딩 목업과 컴포넌트를 합치지 않는다.

## 값

| 항목         | 측정 중                       | 비집중                   | 일시정지                   |
| ------------ | ----------------------------- | ------------------------ | -------------------------- |
| 배경         | `rgba(16, 20, 25, 0.65)`      | `rgba(16, 20, 25, 0.68)` | `rgba(16, 20, 25, 0.68)`   |
| 테두리 1.5px | `#3182F6`(brand primary 다크) | `#FF9E1B`                | `rgba(255, 255, 255, 0.4)` |

- 공통: 글자 14px Medium 흰색, 줄 높이 18px, 여백은 테두리 포함 위아래 9px·좌우 16px(CSS는 `py-[7.5px] px-[14.5px]` + 테두리 1.5px, 높이 36px), 배경 흐림 CSS 5px(Figma 배경 흐림 10), 그림자 없음. 배경색은 `withAlpha(colors.bg.base.dark, …)`, 테두리는 측정 중 `colors.brand.primary.dark`, 비집중 `sessionStateColors.DISTRACTION.dark`, 일시정지 `border-white/40`이다. V1.4 원본(1px, 흰색 12%·14%, 주황 35%)은 실기기에서 거의 보이지 않아 두께와 진하기를 올렸다.
- 비집중 전용 글자색 변수 `--session-pill-fg-distract`는 지운다.

## 영향

- `RoomPage.tsx` 부가 기능 묶음의 세로 화면 위치를 `calc(env(safe-area-inset-top)+62px)`로 바꾼다. 기준은 "필 아랫선 + 필과 화면 위끝 사이 간격"이고 13 + 36 + 13 = 62다. 가로 화면은 타이머 기준이라 그대로다.
- `SessionMockBackdrop.tsx`의 `MockStatusPillBlock`에서 색 점 `span`을 뺀다. 강조 링 색은 유지한다.

## iOS 배경음 시트 탭 누락 (2026-10-01 추가)

- 가로 세션에서 배경음 시트의 헤더 스위치와 탭이 3~5번 눌러야 반응했다.
- 원인은 Radix 시트의 스크롤 잠금이 스크롤 영역 밖 touchmove를 막고, iOS가 막힌 터치를 클릭으로 만들지 않는 것이다.
