# BY-1336 화면 응시를 시선으로 판정하고 비집중으로 기록하는 설계

- Jira: BY-1336 (하위 BY-1337 백엔드 `SCREEN`, BY-1338 화면 응시 판정, BY-1339 정착 시간)
- 브랜치: `feature/BY-1336-screen-gaze` (프론트 base `feature/BY-1219-session-v3-layout`, 백엔드 base `dev`)
- 범위: 싱글룸 감지만 바꾼다. 소셜·그룹룸은 화면 응시와 공부 흔적 판정을 쓰지 않아 동작이 그대로다.

## 1. 카메라 쪽 방향 (`toCameraDegOf`)

- 얼굴 모델의 자세 행렬에는 고개 회전과 얼굴 위치가 함께 들어 있다.
- 얼굴에서 카메라를 향하는 벡터(이동값의 반대)를 얼굴의 오른쪽·위·정면 축에 투영해, 카메라를 보려면 눈이 좌우·위아래로 몇 도 돌아야 하는지 구한다.
- 두 벡터가 같은 좌표계라 폰 기울기, 거치 높이, 앉은 자리가 달라도 같은 기준으로 나온다.
- 얼굴 위치는 각도 두 개로만 줄이고 밖으로 내보내지 않는다. 진단에도 각도만 싣는다.

## 2. 실제 눈 방향 (`eyeGazeOf`)

- 위아래는 눈 아래 보기 점수에서 위 보기 점수를 뺀다. 이를 위해 얼굴 모델에서 `eyeLookUp*` 점수를 더 받는다.
- 좌우는 양쪽 눈의 안쪽·바깥쪽 보기 점수 차다.
- 점수 1.0을 25도로 보고 카메라 쪽 방향과 비교한다.
- 방향이나 점수 중 하나라도 없으면 화면 응시가 아닌 것으로 본다.

## 3. 실측 근거

아이폰 17 Pro를 책상에 세로로 세우고 책을 폰 오른쪽에 둔 자리에서 쟀다(2026-11-17, 3회).

| 자세                  | 위아래 차이 | 좌우 차이 | 새 판정       | 예전 판정     |
| --------------------- | ----------- | --------- | ------------- | ------------- |
| 화면 보기             | 약 +1°      | 약 -12°   | 화면 응시 8/8 | 화면 응시 8/8 |
| 렌즈 보기             | 약 +1°      | 약 -3°    | 화면 응시 7/9 | 화면 응시 8/9 |
| 고개 숙여 책 보기     | -10~-20°    | +7~+20°   | 화면 응시 1/8 | 화면 응시 7/8 |
| 고개는 폰, 눈만 옆 책 | 약 0°       | 약 +7°    | 화면 응시 9/9 | 화면 응시 9/9 |

## 4. 알려진 한계

- 좌우 눈동자 점수는 작은 회전에 거의 반응하지 않는다. 15도 회전에 0.1 정도였다. 그래서 폰 바로 옆 책을 눈만 돌려 보면 화면 응시로 잡히고, 10초가 넘으면 비집중이 된다.
- 1.0 = 25도 계수와 범위는 한 사람, 한 거치에서 정했다. 가로 거치와 다른 사람은 다시 재야 한다.
- 책상에 세운 폰은 카메라에 책이 거의 잡히지 않아 "책을 보면 공부" 판정이 거의 작동하지 않는다.
- 얼굴 추론이 2초 간격이라 짧게 힐끗 보는 시선은 놓치거나 늦게 반영된다.
- 고개 숙임 게이트(졸음 오판 방지)는 카메라 축 기준 각도라 뒤로 기운 폰에서 작동하지 않는다. 별도 티켓으로 카메라 쪽 방향 기준으로 바꾼다.
