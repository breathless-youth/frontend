# BY-991 타이머 시트 가로 배치 설계

상위 BY-989. BY-990에서 만든 타이머 시트(`MultiTimerScreen`)를 폰 가로 화면에서 쓸 수 있게 하고, 실기기 검증을 거치며 세로 배치도 함께 다듬었다.

## 결정 (사용자 승인, 2026-10-26)

| 항목           | 결정                                                                                                                                                                                                                                               | 이유                                                                                             |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 회전 허용      | 시트가 열려도 세로로 잠그지 않는다. `useModeScreenLocks`에서 `set-orientation`만 빼고 가장자리 스와이프 끄기는 유지한다                                                                                                                            | 휠·다이얼이 가로 배치를 갖게 되어 잠글 이유가 사라졌다                                           |
| 가로 판정      | `landscape-compact:` CSS 변형으로만 바꾸고 엘리먼트 트리는 세로와 같게 둔다. 태블릿 가로는 세로 배치를 그대로 쓴다                                                                                                                                 | 다른 트리로 바꾸면 회전 때 고른 칸·굴러가던 휠이 초기화된다. 측정 화면과 같은 원칙이다           |
| 머리 줄        | 왼쪽은 배경음·과목 페이지와 같은 뒤로 가기 버튼(`SessionPageBackButton`, 이름 `타이머 끄기`)이다. 제목은 화면 낭독기용으로만 남기고 그 자리에 `기본 \| 뽀모도로` 토글을 둔다. 폰 가로에서는 머리 줄이 높이를 차지하지 않고 토글이 오른쪽 위로 간다 | 아래 `처음부터` X와 같은 모양의 ✕가 헷갈렸다. 제목과 토글이 같은 정보를 두 줄로 보여 주고 있었다 |
| 뽀모도로 숫자  | 다이얼 아래 시간 숫자를 설정·진행 모두 없앤다. 남은 시간은 화면 낭독기용 숨김 글자로 남긴다                                                                                                                                                        | 설정 중에는 카드와 겹치고, 진행 중에는 다이얼이 남은 시간을 보여 준다                            |
| 세로 뽀모도로  | 집중·휴식 카드는 재생·X 버튼 줄 바로 위에 둔다. 다이얼과 알림음 묶음은 머리 줄과 카드 사이의 세로 가운데에 둔다. 다이얼 크기 식은 `100svh−340px`이다                                                                                               | 숫자가 빠져 생긴 자리를 다이얼이 쓰게 했다                                                       |
| 폰 가로 무대   | 기본과 뽀모도로가 화면 정가운데의 같은 정사각형 무대를 쓴다. 크기는 `min(370px, 높이−16px−안전 영역, 폭−384px−안전 영역)`이다. 다이얼은 무대를 채우고 휠은 무대 가운데에 놓인다                                                                    | 모드를 바꿔도 버튼 자리가 그대로이게 한다                                                        |
| 폰 가로 휠     | 폭·높이에 따라 휠을 0.8·0.9·1배로 그린다(0.9배는 664×320 이상, 1배는 704×344 이상). 진행 중 숫자는 측정 화면 가로 숫자와 같은 0.85배다. 휠은 그려진 높이로 끌기를 환산해 줄여도 손가락을 따라간다                                                  | 좁은 가로 폰에서는 1배 휠이 토글과 겹친다                                                        |
| 폰 가로 버튼   | 재생·일시정지와 X는 무대 아래 양 모서리에서 버튼 한 폭(60px) 바깥에 둔다. 모드와 진행 상태가 바뀌어도 같은 자리다                                                                                                                                  | 실기기에서 타이머에 너무 붙어 보였다                                                             |
| 폰 가로 알림음 | 알림음 스위치는 화면 오른쪽 아래에 둔다. 아래 여백은 측정 화면 가로와 같은 식을 쓴다                                                                                                                                                               | 무대 주변을 버튼에 내주었다                                                                      |
| 폰 가로 카드   | 뽀모도로 카드는 오른쪽 열의 세로 가운데에 쌓고 사이를 16px 띄운다. 무대·X와 24px 이상 떨어지게 카드 폭을 줄인다(667px 폭에서는 카드 152px, 간격 10px)                                                                                              | 다이얼에 붙어 보이지 않게 한다                                                                   |
| 안전 영역      | 가로에서 머리 줄과 본문에 좌우 안전 영역 여백을 준다                                                                                                                                                                                               | 노치가 버튼을 가리지 않게 한다                                                                   |

## 범위 밖

- 소셜룸 타이머(BY-993), 싱글룸 더보기(BY-992)
- 측정 화면 자체의 가로 배치
