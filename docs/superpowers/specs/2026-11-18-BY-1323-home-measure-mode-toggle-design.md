# BY-1323 홈 분할 시작 버튼과 측정 방식 기억 설계

상위 스토리 BY-1321(카메라 없이 타이머만으로 공부)의 첫 프론트 하위 항목이다.

## 목표

- 새 홈(`HomeV3Content`)의 `공부 시작` 버튼 옆에 측정 방식 전환 버튼을 둔다.
- 고른 방식(카메라로 측정 / 카메라 없이)을 기기별로 기억한다.
- 세션 화면이 이 값을 읽어 카메라를 열지 않는 동작은 BY-1324에서 한다. 이 작업은 값을 쓰고 읽는 모듈까지만 만든다.

## 결정 사항 (스토리에서 승인됨)

| 항목             | 결정                                                                                                  |
| ---------------- | ----------------------------------------------------------------------------------------------------- |
| 기억 단위        | 기기별. 계정과 무관한 단일 키로 `localStorage`에 둔다                                                 |
| 기본값           | 카메라로 측정                                                                                         |
| 모드 아이콘 위치 | 좌측 `공부 시작` 버튼의 문구 왼쪽. 기존 재생 아이콘 자리를 대신한다                                   |
| 모드 아이콘      | 카메라 모드 `Camera`, 카메라 없는 모드 `CameraOff` 모양                                               |
| 전환 버튼        | 아이콘만 둔다. 위 화살표는 아래 꼭지가 없고, 아래 화살표는 위 꼭지가 없는 반쪽 화살촉 전환 아이콘     |
| 전환 피드백      | 토스트 없음. 좌측 모드 아이콘이 짧은 애니메이션으로 바뀐다. reduced-motion이면 애니메이션 없이 바뀐다 |
| 문구             | 가안. 좌측 버튼 문구는 지금처럼 `공부 시작`을 유지한다                                                |

## 설계

### 측정 방식 저장 모듈

- `features/measure-mode/measureMode.ts`(가칭)에 `MeasureMode = "camera" | "timer"` 타입과 읽기·쓰기·구독 훅을 둔다.
- 저장 방식은 `features/home-v3/subjectSelection.ts`의 관례를 따른다(`localStorage` 실패 시 메모리 대체, 변경 이벤트와 `storage` 이벤트 구독, `useSyncExternalStore`).
- 저장된 값이 알 수 없는 값이면 `camera`로 읽는다.
- 세션 화면(BY-1324)과 다른 시작 지점은 이 모듈의 읽기 함수만 쓴다.

### 분할 버튼

- 지금의 단일 `Button`을 좌측 `공부 시작` 버튼과 우측 전환 버튼으로 나눈다.
- 바깥쪽 모서리는 지금의 큰 둥근 모서리를 유지하고, 맞닿는 안쪽 모서리는 작게 한다. 두 버튼 사이에 좁은 간격을 둔다.
- 전환 버튼은 정사각형에 가깝게, 높이는 좌측 버튼과 같다. 터치 영역은 44px 이상이다.
- 공부 시작 요청 중(`startingStudy`)에는 두 버튼 모두 비활성이다.
- 전환 버튼 `aria-label`은 지금 방식을 함께 읽는다. 상태 표현은 `aria-pressed`보다 라벨 문구로 한다(두 값 사이 전환이라 눌림 상태가 뜻을 잘 전하지 못한다).

### 아이콘

- 홈 아이콘은 `HomeDesignIcon`이 Figma 원본 SVG를 마스크로 그린다. 같은 방식으로 `camera`, `cameraOff`, `swap` SVG를 `assets/home-v3/`에 더한다.
- Figma 시안(BY-1327)이 나오면 SVG를 시안 원본으로 맞춘다.

### 계측

- 전환할 때 `study_measure_mode_changed` 이벤트를 `mode`(바뀐 값), `from: "home"` 속성과 함께 보낸다. 함수는 `lib/amplitude.ts`의 기존 함수 모양을 따른다.

### 문구

- 전환 버튼 `aria-label` 두 가지를 ko·en·ja·zh-Hant에 더한다.

## 범위 밖

- 세션 화면이 측정 방식을 읽고 카메라를 열지 않는 동작(BY-1324)
- 결과·기록 표시와 그룹 문구(BY-1325)
- 앱 권한 확인 건너뛰기(BY-1326)
- 옛 홈(`HomeContent`, 토큰 없는 구 앱용)

## 배포

- BY-1324와 함께 배포한다. 이 작업만 먼저 나가면 버튼만 있고 동작하지 않는다.
