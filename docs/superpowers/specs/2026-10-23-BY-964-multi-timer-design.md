# BY-964 멀티 타이머(타이머·뽀모도로) 설계

- Jira: BY-964 스토리, 하위 BY-976·BY-977·BY-978·BY-979·BY-980
- 명세: `.ai` 저장소 `product/specs/BY-964-멀티-타이머.md`
- 시안: Figma V2 `S1b-5 · 세션 · 멀티 타이머` 섹션(`6998:12502`), 컴포넌트 `13 · Multi Timer`
- HTML 시안 `FocusMakers Multi Timer.html`은 피그마에 없는 것(키패드 시트, `N바퀴째` 배지)과 휠·다이얼 수치의 참고로만 쓴다.

## 왜

세션 시간은 순공이 올라가는 스톱워치 하나뿐이었다.
정해 둔 시간까지 남은 양을 보거나 집중·휴식을 번갈아 쓰려면 다른 앱을 켜야 했다.
세션 안에서 타이머와 뽀모도로를 켜되, 순공 측정은 지금처럼 따로 돈다.

## 사용자에게 일어나는 일

1. 측정 화면 오른쪽 위 버튼 열에 타이머·뽀모도로 버튼이 생긴다. 순서는 카메라 전환, 배경음, 과목, 타이머, 뽀모도로다.
2. 버튼을 누르면 그 모드 화면이 세션 위를 전부 덮는다. URL은 그대로라 카메라·감지·순공 측정이 이어진다.
3. 설정을 맞추고 `시작`을 누르면 남은 시간이 실제 시간 기준으로 준다.
4. 시간이 끝나면 짧은 알림음과 강한 햅틱이 함께 난다. 기기가 무음이면 OS가 소리를 막는다.
5. 왼쪽 위 ✕를 누르면 확인 없이 모드가 꺼지고 측정 화면으로 돌아간다.

## 사용자와 정한 것 (2026-10-23 인터뷰)

| 항목                      | 결정                                                                              |
| ------------------------- | --------------------------------------------------------------------------------- |

| 알림                      | 알림음 + 햅틱을 항상 함께 낸다. 무음은 OS에 맡긴다                                |

## 구조

```
RoomPage (세션 화면)
 ├─ SessionSideActions ── 타이머·뽀모도로 버튼(앱에서는 glass 버튼)
 ├─ useMultiTimer ─────── 모드 상태 · 1/4초 틱 · 설정 저장 · 알림 · 휴식 신호
 │    ├─ multiTimerMachine (순수 TS: 상태 전이, 실제 시간 기준 남은 시간)
 │    ├─ multiTimerSettings (localStorage `focuson.multiTimer.v1`)
 │    └─ alarmSound (Web Audio 합성음)
 ├─ MultiTimerScreen ──── 세션 위 전체 화면(Radix Sheet, 포털 = 세션 main)
 │    ├─ TimerPanel ── TimerWheel(시·분·초 3열) / 남은 hh:mm:ss
 │    └─ PomodoroPanel ── ModeCard ×2 · PomodoroDial(SVG) · MinuteKeypadSheet
 └─ useStudyRoomSession ── startBreak()/endBreak() 추가, PAUSE 트리거에 BREAK 추가
```

- 계산은 컴포넌트 밖 순수 모듈(`multiTimerMachine.ts`)에 두고 화면은 그리기만 한다.
- 모드는 플랫폼 카메라·Vision·WebRTC 코드와 닿지 않는다. 세션과는 `startBreak`·`endBreak`·`resume`과 `sessionState` 구독으로만 이어진다.

## 시간 계산

- 남은 시간은 `remainingMs`와 `anchorMs`(흐르기 시작한 벽시계 시각, 멈췄으면 `null`)로 둔다.
- 흘러야 하는 조건은 "모드가 진행 중"이고 "세션이 일시정지되지 않았다"이다. 휴식(`PAUSE`+`BREAK`)은 세션 일시정지로 보지 않는다.
- 틱마다 이 조건으로 멈춤·재개를 맞추므로, 앱 이탈로 세션이 멈추면 모드도 그 시각에 멈추고 다시 이어진 시각부터 흐른다.
- 뽀모도로는 0을 지나면 남은 음수만큼 다음 단계 길이에서 빼서 이어 간다. 타이머는 0에서 멈추고 `done`이 된다.

| 모드 상태  | 세션 일시정지 | 큰 버튼                                                                          | 아래 버튼  |
| ---------- | ------------- | -------------------------------------------------------------------------------- | ---------- |
| 설정       | 무관          | `시작`(타이머 0초면 흐리고 막힘). 세션이 멈춰 있었으면 세션도 함께 다시 시작한다 | 없음       |
| 진행       | 아님          | `일시정지`(회색)                                                                 | 없음       |

| 일시정지   | 무관          | `계속` → 모드 재개, 세션이 멈춰 있으면 세션도 재개                               | `처음부터` |
| 끝(타이머) | 무관          | `다시 설정` → 설정 화면                                                          | 없음       |

## 휴식과 세션

- `PauseTrigger`는 `MANUAL | BACKGROUND` 그대로 두고, `SessionState`의 `PAUSE`가 `BREAK` 이유를 더 가진다.
- 집중이 끝나면 `startBreak()`가 `PAUSE(BREAK)`로 전이한다. 진행 중이던 비집중 구간은 이때 닫힌다.
- 휴식이 끝나거나, ✕로 끄거나, `처음부터`로 설정에 돌아가면 `endBreak()`가 집중으로 되돌린다.
- 휴식 중 앱을 떠나면 `pause("BACKGROUND")`가 `PAUSE(BREAK)`를 끊고 새 일시정지 구간을 연다. 그래서 이벤트가 2건이다.
- 자동 종료 감시자는 `BREAK` 구간을 보지 않는다. 휴식 뒤 일시정지는 그 일시정지가 시작된 시각부터 20분을 센다.
- 복귀 뒤 `계속`을 누르면 휴식 단계면 `startBreak()`로 다시 휴식에 들어가고, 아니면 `resume()`이다.
- 배경음은 `BREAK`를 일시정지로 보지 않아 계속 나온다.
- 측정 화면의 상태 필·타이머는 휴식도 일시정지로 보인다. 모드 화면이 덮고 있어 사용자가 볼 일은 거의 없다.
- 휴식 중에 모드를 일시정지하면 휴식 상태가 그대로 남고 20분 자동 종료도 걸리지 않는다. 앱에서는 화면이 꺼지면 일시정지로 넘어가 20분 규칙을 받는다. 브라우저에서만 끝없이 남을 수 있어 PR에서 기획 확인을 받는다.

## 모드 화면

- Radix `Sheet`(오른쪽에서 들어오는 전체 폭)를 그대로 쓰고, 헤더만 피그마대로 바꾼다. 처음에는 왼쪽 ✕, 가운데 제목, 오른쪽 빈칸이었고, BY-990·BY-991에서 왼쪽 뒤로 가기 버튼(배경음·과목 페이지와 같은 `SessionPageBackButton`)과 `기본 | 뽀모도로` 토글로 바뀌었다. 제목은 화면 낭독기용으로만 남긴다.
- Escape와 바깥 누름으로는 닫히지 않는다.
- 열 때 history 항목을 하나 쌓는다. 그 항목에서 뒤로 가기가 오면 항목을 다시 쌓아 아무 일도 일어나지 않게 한다. 뒤로 가기 버튼으로 끌 때만 그 항목을 걷어 낸다.
- 열려 있는 동안 `set-back-gesture`로 iOS 가장자리 스와이프를 끄고 끌 때 되돌린다. 처음에는 `set-orientation`(`unlocked: false`)으로 세로도 잠갔지만, BY-991에서 폰 가로 배치를 만들며 이 잠금을 걷어 냈다.
- 측정 화면이 마운트될 때마다 `set-orientation`(`unlocked: true`)을 한 번 보낸다. 웹뷰가 다시 로드되거나 앱이 웹뷰를 복구하며 세로로 잠가도, 새 문서가 세션 화면의 회전 규칙을 다시 건다.
- 저장소에 표시를 남기는 방식은 쓰지 않는다. 웹뷰 프로세스가 죽으면 저장소가 함께 사라질 수 있고, 모드를 끈 뒤의 복구에서는 표시가 이미 지워져 있어 잠금이 남았다.
- 태블릿은 내용 열을 휴대폰 폭(`max-w-[402px]`)으로 가운데 둔다.

## 버튼 아이콘

- 웹은 피그마 `icon/timer`·`icon/pomodoro`를 SVG 컴포넌트로 쓴다.
- iOS glass 버튼은 타이머에 SF Symbol `timer`, 뽀모도로에 앱 번들 이미지 `pomodoro`를 넘기고, 이미지가 없는 이전 앱을 위해 `systemImage`도 함께 넘긴다.

## 비집중 색

- 모드가 진행 중이고 세션 상태가 `DISTRACTION`이면 숫자(뽀모도로는 부채꼴도)를 `--state-distract`로 칠한다.
- 휴식 중에는 감지가 멈춰 `DISTRACTION`이 오지 않는다.

## 테스트

- 순수 모듈: 상태 전이, 실제 시간 기준 남은 시간, 세션 일시정지 동안 멈춤, 뽀모도로 단계 전환, 타이머 0에서 멈춤, 설정 저장·복원·범위 자르기, 시간 표기.
- 세션 훅: `startBreak`·`endBreak`의 이벤트, 휴식 뒤 백그라운드 일시정지 2건 분리, 휴식 중 자동 종료 없음.
- 컴포넌트: 버튼 라벨 전이, `처음부터` 표시 조건, 키패드 범위, 휠 키보드 조작, 다이얼 슬라이더 값.
- RoomPage 통합: 버튼으로 열기, ✕로 끄기, 뒤로 가기로 닫히지 않음, 세션 종료 시 닫힘.
