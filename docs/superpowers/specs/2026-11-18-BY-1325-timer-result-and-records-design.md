# BY-1325 카메라 없는 세션의 결과·기록 표시와 그룹 문구 설계

상위 스토리 BY-1321(카메라 없이 타이머만으로 공부)의 세 번째 프론트 하위 항목이다. BY-1324에서 싱글룸 세션이 카메라 없이 돌고 요청에 `source: "TIMER"`를 싣게 했다. 이 작업은 그렇게 저장된 세션을 결과 화면과 기록 탭, 플래너에서 측정 세션과 구분해 보여 주고, 그룹의 순공 문구를 공부 시간 기준으로 바꾼다. 카메라 세션 화면 하단의 안심 문구도 이 작업에 별도 커밋으로 넣는다.

## 결정 사항 (승인됨)

| #   | 항목                | 결정                                                                                                                                                                                                                                                                                                                                                                   |
| --- | ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 공용 타입           | `StudySessionSource`에 `TIMER`를 더한다. 요청 타입 세 곳과 플래너 타입 두 곳(`PlannerRecordView`, `RecordDraftBlock`)의 따로 적은 리터럴을 이 타입에서 꺼내 쓰게 바꾼다                                                                                                                                                                                                |
| 2   | 결과 화면 판단      | 결과 화면이 받는 POST 응답의 `source === "TIMER"`로 판단한다. 서버(BY-1322)가 응답에 `source`를 싣는다                                                                                                                                                                                                                                                                 |
| 3   | 결과 화면 구성      | 큰 숫자의 라벨은 `총 공부시간`이다. 그 아래 총 공부 줄, 집중률 배지, 타임라인 카드, 측정 피드백 카드, 포인트 칸을 그리지 않는다. 요약 카드(`오늘 누적 순공시간`, `누적 공부 일 수`)와 인터뷰 카드는 그대로다                                                                                                                                                           |
| 4   | 결과 화면 안내      | 포인트 기능 여부와 상관없이 `카메라 없이 공부한 시간은` 다음 줄에 `연속 공부·랭킹·포인트에 반영되지 않아요`를 두 줄로 보여 준다                                                                                                                                                                                                                                        |
| 5   | 기록 탭 목록 행     | 직접 입력 행처럼 `총` 줄을 빼고, 집중률 배지 자리에 `카메라 없이` 배지를 둔다. 바는 단색이고 일시정지 구간은 그대로 보인다. 펼치면 시작·종료만 보이고 `최대 집중 시간`은 뺀다. 화면 읽기 문구도 맞춘다                                                                                                                                                                 |
| 6   | 플래너 기록 시트    | `· 직접 입력` 자리에 `· 카메라 없이`를 붙인다. 시간표 칸 모양은 측정 기록과 같다                                                                                                                                                                                                                                                                                       |
| 7   | 플래너 과목 범위    | 날짜 창 밖 과목 구간 판정(`recordDraft.ts`의 `unknownSubjects`)을 `!== "MANUAL"`로 바꿔 카메라 없는 세션도 측정 세션과 같게 처리한다                                                                                                                                                                                                                                   |
| 8   | 그룹 문구           | 공개 그룹 상세의 `이번 주 멤버 순공 합계`를 `이번 주 멤버 공부 시간 합계`로 바꾼다(4개 언어). 카드의 `이번 주 합계`와 책상·순위 화면은 "순공"이란 말이 없어 바꾸지 않는다                                                                                                                                                                                              |
| 9   | 홈 오늘 집중률      | 프론트는 바꾸지 않는다. 서버(BY-1322)가 일간 집중률과 집중률 랭킹을 측정 세션만으로 계산한다                                                                                                                                                                                                                                                                           |
| 10  | 복구 모달           | 바꾸지 않는다. 응답에 `source`가 없고 드물게 뜨는 창이라 필드를 더할 가치가 낮다                                                                                                                                                                                                                                                                                       |
| 11  | 세션 하단 안심 문구 | 싱글룸 카메라 세션 화면에 `카메라 화면은 어디로도 보내지 않아요`를 세션 내내 띄운다. 세로는 일시정지·종료 버튼 바로 아래 가운데에 두고, 아래 여백이 모자란 기기에서는 두 버튼 사이에 둔다. 가로는 화면 위 가운데에 둔다. 버튼과 시계 자리는 바뀌지 않는다. 심플 모드에서도 보인다. 글자는 시계의 총 공부 줄보다 작다. 비회원 안내가 뜨는 동안에는 비회원 안내만 보인다 |

## 서버 명세 (BY-1322와 합의)

- `POST /api/study-sessions` 응답과 기록 조회 응답의 `source`는 `MEASURED` | `MANUAL` | `TIMER`다.
- 일간 통계의 `focusRate`와 집중률 랭킹은 `MEASURED` 세션만으로 계산한다.

## 설계

### 판정 함수

- `manualRecord.ts`의 `isManualSession` 옆에 `isTimerSession(session)`을 둔다. 결과 화면, 기록 행, 플래너 시트가 같은 함수를 쓴다.
- 직접 입력 묶음·칸 탭 판정(`bundleOf`, `manualBundles`, `cellTapTarget`)은 바꾸지 않는다. 카메라 없는 세션은 측정 세션처럼 다뤄진다.

### 결과 화면 (`ResultPage`, `StudyCompleteHero`)

- `ResultPage`가 `sessions[0]`로 카메라 없는 세션인지 정하고, 히어로와 카드 묶음에 그 값을 넘긴다.
- 히어로는 라벨을 `result.totalPrefix`로 바꾸고 총 공부 줄과 배지를 그리지 않는다. 숫자는 `studySec`이다.
- 타임라인 카드, 측정 피드백 카드, 포인트 칸 대신 안내 한 줄을 그린다. 안내 자리는 포인트 칸이 있던 카드 묶음 안이다.
- 측정 피드백 카드를 그리지 않으므로 그 노출 기록과 분석 이벤트도 생기지 않는다.

### 기록 탭 (`SessionListItem`)

- 측정 행, 직접 입력 행과 나란히 카메라 없는 행을 둔다. 직접 입력 행의 구조를 따르되 바에는 일시정지 구간을 그린다.
- 배지 문구는 `records:timerItem.badge`, 화면 읽기 문구는 직접 입력 행의 `readAloudLabel`과 같은 형식으로 `카메라 없이 공부한 기록`으로 시작한다.

### 플래너 (`RecordBlockSheet`, `recordDraft`)

- 기록 시트 제목 줄의 출처 표시를 직접 입력과 카메라 없음 두 갈래로 나눈다.
- `unknownSubjects` 조건만 바꾸고 편집 가능 여부는 지금과 같다.

### 그룹 (`group-room.json`)

- `publicRoomDetailScreen.weeklyTotal` 4개 언어 문구만 바꾼다.

### 세션 하단 안심 문구 (`RoomPage`)

- 하단 버튼 줄을 기준으로 절대 위치에 그려서 줄 높이와 버튼, 시계 자리가 바뀌지 않는다.
- 세로 화면은 문구 위 끝을 버튼 아래 끝에 맞춰 레이어 아래 여백에 가운데 정렬로 둔다.
- 폰은 아래 여백이 8px에 안전 영역을 더한 값이라 안전 영역이 12px 미만이면 문구 한 줄(16px)과 화면 끝 사이 4px가 들어가지 않는다.
- 그런 기기에서는 문구를 두 버튼 사이에 두고 아래 끝을 일시정지 버튼 아래 끝에 맞춘다.
- 두 버튼 사이에서 폭이 모자라면 가운데 정렬로 두 줄이 되며 위로 자라고, 버튼과 겹치지 않는다.
- 두 자리 중 어디에 둘지는 CSS `clamp`로 안전 영역 값에서 바로 정해서 JS 측정이 없다.
- 태블릿은 아래 여백(24px, 큰 태블릿 27px)이 문구 줄 높이(20px, 24px)보다 늘 커서 언제나 버튼 아래에 둔다.
- 가로 화면은 화면 위 가운데에 두고 한 줄의 세로 중심을 더보기 버튼 중심보다 16px 위에 맞춘다.
- 가로에서 문구 위 끝은 안전 영역 위 끝에서 12px 아래이고, 줄이 늘어도 아래로만 자라 안전 영역을 넘지 않는다.
- 가로에서 좌우를 작은 카메라 창 오른쪽 끝보다 8px 안쪽까지 비워서 카메라 창과 더보기 버튼에 닿지 않는다.
- 비회원 안내는 지금 자리(버튼 줄 아래, 가로 그리드 4행)를 그대로 쓴다.
- `cameraOn && userId !== null`일 때만 그린다. 비회원 안내는 지금 그대로다.
- 크기는 폰 12px, 폭 600 이상 15px, 큰 태블릿 18px이다. 총 공부 줄(15px·22px·28px)보다 작다.
- 문구는 카메라 확인 창과 같은 `cameraPrompt.notice`를 쓴다. 번역도 같은 키라 새 번역이 생기지 않는다.
- 소셜룸과 그룹 공부방에는 넣지 않는다. 영상이 상대에게 전송되므로 같은 문구를 쓰면 개인정보 원칙에 어긋난다.

## 테스트 계획

| 대상      | 케이스                                                                                                                                                                                                                                                          |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 판정 함수 | `TIMER`만 참이고 `MEASURED`, `MANUAL`, 값 없음은 거짓이다                                                                                                                                                                                                       |
| 결과 화면 | 카메라 없는 세션은 라벨이 `총 공부시간`이고, 총 공부 줄, 집중률 배지, 타임라인 카드, 측정 피드백 카드, 포인트 칸이 없고 안내가 있다                                                                                                                             |
| 결과 화면 | 포인트 기능이 꺼져 있어도 안내가 보인다. 카메라 세션 결과 화면은 지금과 같다                                                                                                                                                                                    |
| 기록 탭   | 카메라 없는 행에 `카메라 없이` 배지가 있고 집중률 배지와 `총` 줄이 없다. 펼치면 `최대 집중 시간`이 없다. 화면 읽기 문구가 맞다                                                                                                                                  |
| 플래너    | 기록 시트에 `· 카메라 없이`가 붙는다. 날짜 창 밖 과목 구간이 있는 카메라 없는 세션은 측정 세션처럼 과목 범위를 모름으로 판정한다                                                                                                                                |
| 그룹      | 공개 그룹 상세 문구가 바뀐다(4개 언어 키 일치는 기존 카탈로그 테스트가 확인한다)                                                                                                                                                                                |
| 세션 화면 | 카메라 세션은 하단 안심 문구가 보이고, 심플 모드에서도 보인다. 카메라 없는 세션과 비회원 상태에서는 보이지 않는다. 문구는 일시정지 버튼과 종료 버튼 사이 순서에 있고 초점을 받지 않는다. 자리는 jsdom이 레이아웃을 계산하지 못해 실기기와 브라우저에서 확인한다 |

## 범위 밖

- 홈의 오늘 집중률과 집중률 랭킹 계산(BY-1322 서버)
- 복구 모달의 출처 표시
- 앱의 카메라 권한 확인 건너뛰기(BY-1326)
- 위키 개정(BY-1328)
