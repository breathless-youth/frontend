# BY-972 소셜룸 세션 배치·시간 표시·더보기·자동 숨김 설계

상위 BY-714(소셜룸 UI/UX 개선)의 FE 첫 하위 작업이다. 버튼 기능(과목·배경음·타이머)은 각 기능 티켓(BY-974·BY-973)이 채우고, 이번에는 화면의 틀을 바꾼다. 시안은 Figma V2(`YcyImcuVORDbBneii41Byh`)의 `S14`·`S14-2` 다크 섹션과 `11 · Social Room` 컴포넌트다. 세션 화면은 다크만 다룬다.

## 결정 (2026-10-24~25 사용자 승인)

- 혼자일 때도 풀스크린이 아니라 정사각 타일 한 장을 가운데 둔다.
- 세로 4명 타일은 6명과 같은 폭(`47%`)과 좌우 여백을 쓴다.
- 조작이 나타나거나 숨어도 타일 크기와 위치는 바뀌지 않는다. 바 표시에 따른 여백 예약과 타일 FLIP 애니메이션을 없앤다.
- 상대 타일만 오른쪽 위에 순공 시간 뱃지를 `HH:MM`으로 보여 준다. 값은 서버가 1분마다 보내는 `STUDY_TIME` 그대로이고 내 기기에서 이어 세지 않는다.
- 내 타일에는 시간 뱃지가 없다.
- 내 순공 시간과 총 공부 시간은 왼쪽 위에 배경 없는 글자 두 줄로 둔다. 순공이 위에 크게(`HH:MM:SS`), `총 HH:MM:SS`가 아래에 작게 놓인다. 자동 숨김과 무관하게 항상 보인다.
- 오른쪽 위 더보기(⋯)를 누르면 그 자리를 덮는 메뉴가 열리고 `카메라 전환`, `초대코드 공유` 순서로 항목이 있다. 카메라가 꺼져 있으면 `카메라 전환`은 흐리게 비활성이다.
- 하단 바는 이번 티켓에서 카메라와 나가기 두 버튼만 둔다. 과목·타이머·배경음 버튼은 기능 티켓에서 붙인다. 카메라 전환 버튼은 바에서 빠지고 더보기로 간다.
- 과목 알약(하단 바 위 8px, 바 왼쪽 끝 정렬)은 BY-974가 구현한다. 세로·태블릿 배치는 그 자리를 이미 비워 둔다.
- 가로(`landscape-compact`)는 기존 하단 바 배치를 유지하고 위아래 여백을 더 넣지 않는다. 시간 글자·알약이 타일에 겹쳐도 그대로 둔다. 태블릿 가로도 겹침을 허용한다.
- 자동 숨김: 마지막 조작 뒤 5초가 지나면 하단 바와 더보기 버튼이 함께 숨는다. 시간 글자, 상대 뱃지, 타일 닉네임·목표는 남는다(2026-10-25 실기기 확인 뒤 변경).
  - 화면을 탭하면 다시 나타나고, 보이는 상태에서 탭하면 바로 숨는다.
  - 확인 창, 더보기 메뉴, 제출 중, 오류 상태에서는 계속 보인다.
  - 숨은 동안 키를 누르면 다시 나타난다. 키보드로 조작 안에 포커스가 있는 동안은 숨지 않는다(터치 뒤 창이 닫히며 돌아온 포커스는 붙잡지 않는다).
- 타일 닉네임과 목표는 길면 각각 한 줄로 줄이고 말줄임표로 끝낸다.
- 초대코드 공유는 초대코드 화면과 같은 `shareInvite`를 쓰고 같은 계측(`trackInviteShared`·`trackMetaInviteShared`)을 보낸다. 결과가 `copied`일 때만 `초대코드를 복사했어요` 토스트를 띄운다.

## 데이터 흐름

- 내 시간: `useStudyRoomSession`의 `focusSec`·`studySec`(BY-959의 1초 눈금 표시값) → `RoomTimeText`.
- 상대 시간: `RoomMember.focusSec`(서버 `STUDY_TIME`) → `formatStudyHhMm` → 뱃지. 값이 없으면 `--:--`.
- 뱃지 테두리 색: 카메라 켬·집중 `state-focus`, 카메라 켬·비집중 `state-distract`, 카메라 끔 `text-tertiary` 계열(시안 `Room / Badge` variant 기준).
- 공유: `shareInvite(inviteCode)` → `"shared" | "copied" | "failed"` → 계측 두 개 → `copied`면 토스트.
- 전환: `flipCamera()`. 카메라 꺼짐(`paused`)이거나 조작 잠금(`phase !== "studying"`)이면 항목 비활성.

## 실패·경계

- 공유가 `failed`면 토스트 없이 계측만 보낸다(초대코드 화면과 같다).
- 더보기 메뉴가 열린 동안 세션이 `studying` 밖으로 넘어가면 항목은 비활성이 되고 메뉴는 열린 채로 남아도 조작할 수 없다.
- 상대 `focusSec`가 아직 오지 않으면 `--:--`.
- 숨은 조작은 `inert`로 포커스와 탭을 막는다. 숨김 이동·페이드는 `motion-reduce`에서 끈다.

## 테스트

- `useAutoHideControls`: 가짜 타이머로 5초 숨김, 조작마다 다시 5초, 탭 토글, 이동 10px 초과는 탭 아님, 강제 표시 구간에서 숨지 않고 끝나면 5초부터 다시, 포커스 진입 시 표시와 유지.
- `RoomGrid`: 1명이 타일 한 장으로 그려지고, 바 표시 여부와 무관하게 같은 클래스(여백·크기)를 쓴다.
- `RoomTile`: 상대 타일 뱃지 `HH:MM`·상태별 테두리·값 없음 `--:--`, 내 타일 뱃지 없음.
- `RoomTimeText`: 두 줄 형식, 스크린리더 문구.
- `RoomMoreMenu`/`LiveRoomPage`: 메뉴 열기, 항목 순서, 카메라 꺼짐 시 전환 비활성, 전환 호출, 공유 결과별 계측과 토스트.
- `RoomControlBar`: 두 버튼만 있다.
- 기존 `LiveRoomPage.test.tsx`의 풀스크린·FLIP·바 여백 토글·탭 토글 테스트는 새 규칙에 맞게 고치거나 지운다.
