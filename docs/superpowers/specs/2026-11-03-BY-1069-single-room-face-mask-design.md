# 싱글룸 공부 화면 얼굴 이모지 가림 설계 (BY-1069)

## 목표

싱글룸 공부 화면의 카메라 미리보기에서 내 얼굴을 동물 이모지로 가린다.
싱글룸은 영상을 어디에도 보내지 않으므로 영상을 다시 합성하지 않고, 재생 중인 영상 위에 이모지 이미지를 겹친다.
상위 설계는 소셜룸 얼굴 가리기(`2026-10-31-BY-1092-social-face-mask-design.md`)이고, 이모지 위치 계산(`nextFaceSpot`)과 이모지 목록을 그대로 쓴다.

## 동작

### 확인 창

- `CameraOnConfirmDialog`에 `faceMask`를 넘겨 스위치, 안내 아이콘, 이모지 줄을 그린다.
- 툴팁 문구와 보조 문구는 props로 받는다. 소셜룸 호출부는 지금 문구를 그대로 넘긴다.
- 싱글룸은 합성을 하지 않으므로 `supported`는 항상 참이다.
- 미리보기(`ClonedTrackPreview`)는 `faceMask`를 받아 영상을 `FaceMaskOverlay`로 감싼다. 흐림은 영상 요소 자체에 `filter`로 걸어야 해서, 형제 층을 겹치는 `children` 자리로는 만들 수 없다. 오버레이는 `targetAspect` 레터박스 안쪽에 놓인다.
- 소셜룸처럼 가릴 위치를 찾는 동안 미리보기 위에 `가릴 위치를 찾고 있어요` 배지를 띄운다.

### 공부 화면

- `CameraPreviewSurface`는 가리기가 켜져 있으면 `FaceMaskOverlay`를 얹는다.
- 그리기 모드는 `maskModeOf(spot, stickerReady)`를 그대로 쓴다.
  - 위치가 비면 영상을 흐리게 한다.
  - `visible=false`면 이모지 없이 선명하게 둔다.
  - 그 밖에는 이모지를 붙인다.
- 일시정지, 휴식, 카메라 전환 중에는 감지기가 멈추면서 위치를 비우므로 흐림이 된다.
- 심플 모드에서는 미리보기 층이 투명이라 오버레이도 함께 보이지 않는다.
- 흐림은 `filter`와 `opacity`로만 바꾼다. `display`·`visibility`를 쓰면 영상 디코딩이 멈춰 추론이 끊긴다.

### 이모지 배치

- `FaceSpot`은 원본 프레임 기준 정규화 좌표(`x`·`y`는 가운데, `size`는 프레임 폭 대비)이고 좌우 반전 전 값이다.
- 오버레이는 바깥 상자를 `container-type: size`로 두고, 안쪽 상자를 원본 비율(`spot.aspect`)로 만들어 object-cover와 같은 크기로 가운데에 놓는다.
  - 폭은 `max(100cqw, 100cqh * aspect)`, 높이는 `max(100cqh, 100cqw / aspect)`다.
- 이모지는 안쪽 상자 안에서 `left: x*100%`, `top: y*100%`, 폭 `size*100%`의 정사각형으로 놓는다.
- 전면 카메라면 안쪽 상자에 영상과 같은 좌우 반전을 걸고, 이모지 그림은 다시 뒤집어 원래 방향으로 보이게 한다.
- 좌표를 담는 층 전체에 `amp-block sentry-block`을 붙여 세션 리플레이로 좌표가 나가지 않게 한다.
- 위치는 1~2초마다 바뀌므로 약 0.9초 transition으로 따라간다. 사라졌다 다시 나타날 때는 transition 없이 바로 놓는다.
- `prefers-reduced-motion`이면 transition을 끈다.

## 데이터 흐름

- `RoomPage`가 `visionDetector.subscribeFaceSpot`을 구독해 위치를 상태로 들고, 공부 화면과 확인 창 미리보기에 같은 값을 넘긴다.
- 가리기가 꺼져 있으면 구독하지 않는다.
- 카메라 스트림이 바뀌면 위치를 비운다. 이전 카메라 기준 위치가 새 영상 위에 남지 않게 한다.

## 저장

- `faceMaskSettings`의 읽기/쓰기 함수가 범위(`"social"` | `"single"`)를 받는다.
- 이모지 목록과 `public/face-mask/` 이미지는 그대로 쓰고 파일 위치는 옮기지 않는다.
- 타임랩스 설정(`focuson.timelapse.v1`)과 사진 촬영 경로는 건드리지 않는다.

## 개인정보

- 이모지 위치 좌표는 화면에 그리는 데만 쓰고 진단 로그, 분석 이벤트, 서버로 보내지 않는다.
- 비전 파이프라인 설계 문서 §8의 "좌표는 화면 표시에만 쓸 수 있다" 예외를 따른다.

## 범위 밖

- 공부 도중 켜고 끄기(더보기 메뉴)
- 타임랩스 사진 가림(BY-1073)
- 추론 주기(`FRAME_INTERVAL_MS` 1000, 얼굴 2초) 변경

## 테스트

- `FaceMaskOverlay`: 위치를 %로 바꾸는 계산, 전면·후면 반전, 흐림·이모지·선명 세 상태.
- `faceMaskSettings`: 싱글룸 키와 소셜룸 키가 서로 섞이지 않는다.
- `CameraOnConfirmDialog`: 툴팁·보조 문구 props가 그려지고, 소셜룸 기본 문구는 그대로다.
- `RoomPage`: 확인 창에서 켠 가리기와 고른 이모지가 저장되고 공부 화면에 반영된다. 타임랩스 설정은 바뀌지 않는다. 위치를 흘려 넣는 가짜 감지기를 쓴다.
- 진단 로그 타입이 좌표를 받지 않는 상태가 유지된다.

## 함께 고칠 것

- Figma 싱글룸 카메라 확인 창 시안에 스위치, 보조 문구, 이모지 줄을 더한다.
- 위키 정책 문서에 싱글룸 얼굴 가리기가 내 화면에만 적용되고 소셜룸·타임랩스와 설정을 공유하지 않는다는 줄을 더한다.
