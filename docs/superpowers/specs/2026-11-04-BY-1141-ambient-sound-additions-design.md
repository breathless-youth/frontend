# BY-1141 배경음 소리 추가 설계

배경 소리 탭에 5종을 더하고, lofi 3곡으로 로파이 탭을 연다. 재생 엔진은 바꾸지 않는다. BY-683에서 만든 "파일과 카탈로그 한 줄만 더하면 뜨는 구조"를 그대로 쓴다.

아래 결정표는 최종 상태다. 처음 결정에서 무엇이 왜 바뀌었는지는 맨 아래 "진행 중 바뀐 결정"에 남긴다.

## 확정한 결정

| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 배경 소리 | 시험장 고사실, 모닥불, 잔잔한 파도, 새소리, 비행기 기내. 대학 도서관은 들어 보고 뺐다                                                            |

## 1. 음원

- 후보는 소리 8개 × 3개 = 24개다. 출처 URL, 저작자, 라이선스, 원본 길이, 원본 포맷을 함께 적는다.
- 라이선스 판별은 `sound-asset-pipeline` 스킬의 표를 따른다. Mixkit, BBC Sound Effects, CC BY-NC, CC BY-SA, 출처 불명은 후보에 넣지 않는다.
- Pixabay 음원은 원형 그대로 배포하는 것이 금지돼 있다. 구간 선택, 크로스페이드 루프, 라우드니스 보정을 거쳐 이 조항을 피한다.
- 배경 소리는 mono 96kbps, 90초 루프, 3초 크로스페이드, -18 LUFS로 만든다. 구간은 1초 단위 실효값이 가장 고른 창을 고르는 기존 방법을 쓴다.
- lofi는 stereo 96kbps로 만든다. 루프 길이는 음량 곡선의 자기상관으로 찾은 4마디·8마디 단위 배수로 잡아 이음매에서 화음이 어긋나지 않게 한다.
- 파일명은 `<id>-<sha256 앞 8자리>.mp3`다.
- id는 `<소리>-<저작자 약칭>` 꼴이다(예: `bonfire-kyles`). lofi는 같은 저작자 곡이 둘이라 `lofi-<곡>`으로 짓는다.
- 후보 3개가 모두 거절되면 그 소리만 한 번 더 찾는다. 다시 거절되면 그 항목을 빼고 출시하며 보고서에 "미수급"으로 적는다.

### 바꾸지 않는 것

- 재생 엔진(`ambientPlayer.ts`)과 저장 형식은 바꾸지 않는다. 새 id는 기존 `mix` 맵에 그대로 들어간다.
- Amplitude `ambient_sound_changed`는 그대로 둔다. 소리별 재생 시간은 새 이벤트 `ambient_sound_played`(BY-1173)가 세션이 끝날 때 재생 시간이 0보다 큰 소리마다 `sound_id`·`group`·`play_sec`·`room_type`을 싣는다. 음량을 0으로 내리면 믹스에서 빠지므로 "음량 0 초과로 들린 시간"이고, 일시정지·자동 재생 차단 구간은 빠지며, 집중 연동으로 낮아진 시간은 들어간다.
- 소셜룸(`RoomPage`·`LiveRoomSession`)은 같은 시트를 쓰므로 새 소리와 탭이 추가 작업 없이 같이 나온다.

## 3. 위키·Figma

- 위키 `product/specs/BY-939-세션-과목-배경음-페이지.md` 15절과 `product/design.md`의 배경음 페이지 행을 "세로·가로 모두 `노이즈`/`배경 소리`/`로파이` 탭"으로 고친다. 위키 PR은 따로 올리고 서브모듈 포인터는 바꾸지 않는다.
- Figma V2(`YcyImcuVORDbBneii41Byh`)의 배경음 페이지 시안(세로 `S1b`, 태블릿 `T` 프레임)에 로파이 탭과 새 소리 줄을 반영한다.

## 4. 진행 순서

1. 음원 후보 찾기(큐레이터)와 코드 변경(탭·아이콘·상한·번역 키)을 동시에 진행한다.
2. 듣기 페이지로 후보를 고른다.
3. 받은 원본을 인코딩하고 카탈로그·라이선스 기록을 채운다.
4. QA가 카탈로그·파일·라이선스 기록·번역 키·아이콘의 1:1 대응을 확인한다.
5. 실기기에서 재생과 루프 이음매를 확인한다.

## 5. 테스트

- 가로 화면에서도 탭 목록(`tablist`)이 그려지고 묶음마다 탭이 하나씩 생긴다.
- `music` 그룹 탭 이름이 `로파이`로 나온다.
- 카탈로그의 모든 `kind: "file"` 항목은 파일, LICENSES 행, ko·en 번역 키, 아이콘을 가진다. 아이콘과 번역 키 대조는 기존 `catalog.test.ts`에 없으면 추가한다.
- 상한 테스트는 16MB 기준으로 통과한다.
- 상세 목록은 5-1에서 승인받는다.
