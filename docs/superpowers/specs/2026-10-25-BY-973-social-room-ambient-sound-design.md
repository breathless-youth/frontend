# BY-973 소셜룸 배경음 연결 설계

상위 BY-714(소셜룸 UI/UX 개선)의 하위 작업이다. 싱글룸 배경음(BY-682·BY-683)을 소셜룸 세션에서도 쓰게 한다. 규칙은 위키 `BY-404-실시간-룸.md`의 "배경음" 절을 따른다.

## 결정 (2026-10-25 사용자 승인)

- 하단 바는 카메라, 배경음, 나가기 순서다. 과목·타이머 버튼은 이후 티켓이 붙인다.
- 소셜룸 바의 배경음 버튼은 바의 다른 버튼과 같은 웹 버튼이다. iOS 앱 glass 버튼으로 등록하지 않는다. glass는 BY-975에서 바 전체를 바꾼다.
- 배경음 페이지는 싱글룸과 같은 `AmbientSoundSheet`다. 아래쪽에 내 순공 시간을 보이고, 가로 화면에서는 가로 배치로 연다.
- 소리 규칙은 `useAmbientSound`가 맞춘다. 카메라를 끄면 세션이 일시정지되어 소리가 멈추고, 입장 직후 카메라를 켜기 전에도 일시정지라 소리가 나지 않는다.
- 저장된 소리가 있는 사용자가 카메라를 끈 채 들어오면 자동 시작이 소리를 먼저 걸고 나서 멈춰 짧게 소리가 샜다. 일시정지 중이면 소리를 걸기 전에 먼저 멈추도록 공용 훅을 고쳤고, 싱글룸의 일시정지 복원 진입도 같이 고쳐진다.
- 페이지가 열린 동안 조작은 숨지 않는다.
- 페이지를 닫으면 포커스가 배경음 버튼으로 돌아온다.
- 제출 중에는 바의 다른 버튼처럼 배경음 버튼도 흐리게 잠긴다.
- 소셜룸은 뒤로 가기를 막아 두었으므로 페이지를 열 때 history 항목을 쌓지 않는다. Android 뒤로 가기로 닫기는 BY-948 범위다.
- 배경음 사용 여부와 재생 시간은 싱글룸과 같이 세션 종료 계측(`study_session_ended`)에 싣는다.

## 구성

| 단위                     | 변경                                                                                                                                                                              |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AmbientSoundButton.tsx` | 앱 glass 등록을 끄는 `native`, 유리 모양을 바꿔 끼우는 `className`, `onPointerDown`, `disabled`를 더한다. 기본값은 싱글룸 동작 그대로다.                                          |
| `RoomControlBar.tsx`     | 카메라와 나가기 사이에 배경음 버튼 자리를 받고, 바 버튼 모양(`roomBarButtonClassName`)을 내보낸다. 눌림 팝은 `playPressPop.ts`로 떼어 함께 쓴다.                                  |
| `useAmbientSound.ts`     | 일시정지 중 자동 시작이면 소리를 걸기 전에 먼저 멈춘다.                                                                                                                           |
| `LiveRoomSession.tsx`    | `createAmbientUsage`·`useAmbientSound`를 연결하고, 사용 시간 스냅샷을 세션 훅에 넘기고, 페이지 열림 상태를 조작 강제 표시에 더하고, `AmbientSoundSheet`를 세션 `main`에 포털한다. |

## 테스트

- 바에 배경음 버튼이 카메라와 나가기 사이에 있다.
- 버튼을 누르면 페이지가 열리고 닫으면 포커스가 버튼으로 돌아온다.
- 페이지가 열린 동안 5초가 지나도 조작이 숨지 않는다.
- 카메라가 꺼진 동안에는 소리를 켜도 재생하지 않고, 카메라를 켜면 재생한다(가짜 플레이어 주입).
- 저장된 소리로 카메라를 끈 채 들어오면 멈춤이 소리 걸기보다 먼저 나간다.
- 소셜룸 배경음 버튼은 앱 glass로 등록하지 않고, 싱글룸 버튼은 지금처럼 등록한다.

## 범위 밖

- 과목·타이머 버튼(BY-974, 이후 티켓), 바 glass(BY-975).
- 배경음 이벤트에 룸 종류를 붙이는 계측 확장.
- 실기기 확인 항목: iOS 무음 스위치를 켠 상태의 재생, 두 기기에서 상대에게 들리지 않는지.
