## 1. 배경과 성공 기준

카메라가 부담스럽다는 설문이 많이 들어왔다. 팀원 #557이 머지되기 전에 카메라를 작은 창(PiP)으로 바꾼 세션 UI와 공간(월페이퍼) 기능을 웹 배포만으로 먼저 낸다. 화면 배치는 새 배치가 아니라 지금 dev 배치를 유지한다.

성공은 PiP 도입 기준으로 본다(릴리즈 전 2주와 후 2주 비교).

| 구분    | 지표                                                                              | 방향             |
| ------- | --------------------------------------------------------------------------------- | ---------------- |
| 주 지표 | 입장 확인 창에서 `카메라 켜기` 선택 비율 (`study_session_camera_prompt_answered`) | 오름             |
| 보조    | 카메라로 시작한 세션 중 심플 모드로 바꾼 비율                                     | 내려감           |
| 보조    | PiP를 키운 비율과 키운 채 머문 시간 비중                                          | 낮게 유지        |
| 보조    | 카메라 세션 완료율과 평균 길이                                                    | 떨어지지 않음    |
| 보호    | 공부 안 함 판정 비율 (`study_session_distracted`)                                 | 크게 변하지 않음 |

## 2. 구현 방식

dev에서 시작한다. 팀원 커밋 중 세션 배치와 무관한 독립 파일만 가져오고, `RoomPage`는 dev 코드에 직접 고친다. 팀원 `701fff09`를 통째로 가져오지 않는다(새 배치가 섞여 들어온다).

### 3.4 공간 페이지

- 배경음과 같은 오른쪽 페이지(`SessionPage`)로 연다. `RoomPage`의 `page` 유니온에 `"space"`를 더한다.
- 내용은 S1e 시안을 그대로 따른다: 제목 `공간`, 머리의 닫기 버튼(배경 박스 없음), `영상`·`이미지` 최상위 탭, 검색창, 분류 칩(`전체`, `감시` 등), 타일 목록, 푸터.
- 영상 탭: 감독관(`proctor`).
- 이미지 탭: `내 사진` 섹션(개수 `n/3`, 사진 타일, `사진 올리기` 타일)과 `심플`. 팀원 코드의 자연 배경은 출시 전이라 넣지 않는다.
- 썸네일 비율은 4:3이다.
- 썸네일을 누르면 미리보기 없이 바로 적용한다(`writeTimerBackground`).
- 썸네일 오른쪽 아래에 미리보기 버튼(확대 아이콘, 보이는 크기 24px, 누르는 영역 44px, 반투명 검은 원 위 흰 아이콘)을 둔다. 이 버튼의 누름은 적용으로 번지지 않는다. 사진 올리기 타일에는 두지 않는다.
- 내 사진 타일 오른쪽 위에는 삭제 버튼(lucide `Trash2` 18px, `text-feedback-danger`, 반투명 검은 원, 누르는 영역 44px)을 둔다.
- 사진 추가는 웹 파일 입력만 쓴다. 3장에 도달하면 사진 올리기 타일을 비활성으로 보인다.
- 푸터: 현재 적용된 공간 이름과 분류, 음소거 버튼(배경 박스 없음), 공간 마스터 음량 슬라이더(시안대로 흰색). 음량은 `watcherSound`의 `readWatcherVolume`·`writeWatcherVolume`(기본 80)을 그대로 쓴다. 이미지 탭이나 소리 없는 공간에서는 비활성으로 보인다. 슬라이더 프리미티브가 `components/ui`에 없으면 배경음 시트가 쓰는 음량 조절 방식을 재사용한다.
- 공간 소리는 배경음의 전체 끄기와 무관하다. 배경음 버튼은 공간 소리를 끄지 않는다.

### 3.5 미리보기

- 미리보기 버튼을 누르면 페이지 머리(제목·닫기) 아래부터 화면 끝까지 배경이 덮인다.
- 감독관은 영상이 반복 재생되고 사진은 정지 화면이다. 실제 세션과 같은 `WallpaperScrim`을 깐다.
- 발소리는 내지 않는다.
- 하단 푸터에 `뒤로가기`와 `적용하기`를 나란히 둔다. `적용하기`는 적용하고 목록으로 돌아온다. 이미 적용 중이면 `적용 중`으로 비활성이다.

### 3.6 세션 화면 배경

- 공간 배경과 감독관은 일반 모드에서만 그린다. 심플 모드는 dev 그대로(어두운 화면 + 상태 빛)이고 감독관도 나오지 않는다.
- 공간을 고른 적이 없으면 `simple`이라 배경 그림이 없는 어두운 단색이다.
- PiP를 키운 동안과 심플 모드에서 감독관 발소리를 끈다.
- `WallpaperScrim` 아래쪽 어둡게 깔기를 세로 `h-80`에서 `h-100`으로 늘리고, 가로·큰 화면도 같은 비율로 늘린다. 상태 줄 높이에서 약 50% 이상 어두워지게 한다.

## 4. 세션 배치 (BY-1308)

### 4.1 작은 카메라 창(PiP)

- 가져오는 것: `cameraExpandMotion.ts`(400ms)와 테스트, `ExpandGlyph`·`ShrinkGlyph`, `PIP_SIZE`(세로 108×144, regular 144×192, landscape 160×108).
- 위치는 새로 정의한다. 왼쪽 위, 왼쪽은 안전 영역 + 16px, 위 끝은 원래 상태 필의 위 끝과 같은 높이(더보기 버튼 중앙보다 17.5px 위). 시안 기준 세로 y 22, 가로 y 20.
- `카메라 켜기`로 들어오거나 심플 모드에서 화면을 탭하면 PiP 상태로 시작한다. 키운 상태는 기억하지 않는다.
- PiP 왼쪽 위 구석의 키우기 버튼(누르는 영역 44px)이나 PiP 자체를 누르면 화면 전체로 키운다. 키운 화면에서는 같은 구석의 줄이기 버튼으로 돌아온다.
- 키운 화면에서도 시계와 버튼은 위에 보이고, 팀원 코드의 위아래 어둡게 깔기를 쓴다.
- PiP 밖 빈 화면을 탭하면 dev처럼 심플 모드로 바뀐다. 심플 모드에서는 카메라를 숨긴다.
- 얼굴 가림은 `CameraPreviewSurface`와 `FaceMaskOverlay`를 그대로 써서 PiP와 키운 화면 모두에서 동작한다(흐림 포함 유지).
- `prefers-reduced-motion`이면 애니메이션 없이 바로 바뀐다.
- PiP에 타임랩스 표시는 두지 않는다.

### 4.2 상태 줄 (`SessionStatusLine`)

- 상단 상태 필(`SessionStatusPill`)과 그 사용처를 없앤다. `SessionStatusPillState` 타입은 시계 쪽으로 옮긴다.
- 시계 위에 상태 줄을 둔다: 8px 점 + 기존 필 문구(「순공시간 측정 중」 등).
- 점 색은 필 테두리 색 변수를 그대로 쓴다(공부 중 `#3182F6`, 공부 안 함 `#FF9E1B`, 일시정지 흰색 40%).
- 글자: 13px, Medium, 흰색 100%, 그림자(아래 1px, 흐림 2px, 검정 50%).
- 정렬: 문구만 시계 가운데 축에 맞추고, 점은 문구 왼쪽 바깥에 붙는다(점이 정렬 폭에 들어가지 않는다).
- `role="status"`·`aria-live="polite"`는 이 줄로 옮긴다.
- 심플 모드에서는 화면에 보이지 않지만, 화면 읽기용 알림은 시각적으로 숨긴 채 남긴다.

### 4.3 시계 묶음

- 위에서부터 상태 줄, 과목 줄, 큰 숫자, 「총」 줄.
- 간격(글자 경계 기준): 상태 줄 ↔ 과목 줄 14px, 과목 줄 ↔ 큰 숫자 12px. 심플 모드도 과목 줄 ↔ 큰 숫자 12px이다. 과목 라벨 상자 크기가 아니라 글자 간격으로 맞춘다.
- 시계 묶음 자리는 dev 그대로이고 공간 배경을 써도 움직이지 않는다. 가로도 같은 순서다.
- `SubjectLabel`의 과목 색 점을 일반·심플 모드 모두에서 없앤다.

### 4.4 세로 열과 더보기

- 세로 열: 공간, 배경음, 타이머. 과목 버튼과 그 앱 등록(`session-subject`)을 뺀다.
- 더보기 메뉴(소셜룸과 공용): 싱글룸만 `플래너` 선택 항목을 넘긴다. 싱글룸 순서는 카메라 전환, 플래너, 도움말 보기. 소셜룸 메뉴는 바뀌지 않는다.
- `플래너`는 다른 메뉴 항목처럼 글자만 두고, 누르면 기존 과목 페이지를 연다. 과목 페이지 제목도 「플래너」로 바꾼다.
- 시계 위 과목 줄을 눌러 과목 페이지를 여는 동작은 유지한다.
- `SESSION_SIDE_POSITION`, `SOLO_MORE_POSITION` 값은 그대로 두고, 필을 기준으로 설명하던 주석만 고친다.

### 5.3 도움말 (B안)

  - 집중: 깜빡임만.
  - 점프: 6px 폴짝 + 깜빡임.
  - 졸림: 깜빡임 없음. 대기 2.1초 → 꾸벅(발끝 축 5도, 2px 아래, 0.9초) → 번쩍(0.1초에 원래 자세 + 반쯤 뜬 눈 0.3초) → 다시 감음(0.3초).
  - 깜빡임: 화남 3f → 정색 4f → 화남 3f(30fps, 0.33초), 몸은 멈춤.
  - `prefers-reduced-motion`이면 움직이지 않는다.
- 세로 고정: 도움말이 열리면 `set-orientation`(`unlocked: false`)으로 앱에 세로 고정을 요청하고, 닫히면 원래 값으로 되돌린다. 브라우저에서는 가로여도 세로 배치를 그대로 보인다. 가로 전용 도움말 배치는 쓰지 않는다.
- 세로 열 설명 단계와 일시정지 설명 단계는 없앤다.
