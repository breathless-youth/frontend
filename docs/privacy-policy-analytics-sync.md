# 개인정보처리방침 — 분석 도구 반영 (2026-08-08)

현행 방침의 「7. 처리 위탁」·「8. 개인정보의 국외 이전」이 **분석 도구를 쓴다는 사실 자체를 담고 있지 않다.** GA4·Sentry 도입 시점부터 있던 누락이고, 2026-08-08 Amplitude 수집 범위 확대(IP·이용 기록)로 더 분명해졌다.

원문은 `apps/web/src/features/settings/legalDocuments.ts`의 `PRIVACY_POLICY`, 그리고 그 원본인 `https://pages-nextjs-liart.vercel.app/privacy`.

## 1. 범위 밖 — 확인 후 제외한 것

**서버 `user_id`는 새 고지 항목이 아니다.** 네이티브가 `Crypto.randomUUID()`로 만든 기기 UUID(`apps/mobile/lib/deviceId.ts`)를 등록하면 서버가 1:1로 돌려주는 번호일 뿐이고, 실명·이메일·전화번호와 연결되지 않는다. 방침 「1. 수집하는 정보」의 **기기 식별자** 항목이 이미 고지하고 있는 값이다. 이걸 Amplitude `user_id`로 넣는 것은 **수집 항목이 늘어나는 변경이 아니라 이미 수집 중인 값의 전달처가 늘어나는 변경**이므로, 아래 §2 위탁·국외이전 조항으로 커버된다.

「6. 제3자 제공」(_"외부에 제공하지 않습니다"_)도 **그대로 둔다** — Amplitude 등은 팀의 목적을 위해 처리하는 수탁자라 제3자 제공이 아니라 처리 위탁이다.

## 2. 고쳐야 할 조항

### 2-1. 「7. 처리 위탁」 — 수탁자 추가 (필수)

현행 표에 AWS 한 줄만 있다. 아래 세 줄을 추가한다.

| 수탁자                             | 위탁 업무 / 보관 국가                                     |
| ---------------------------------- | --------------------------------------------------------- |
| Amplitude, Inc.                    | 서비스 이용 행태 분석 및 화면 재생(Session Replay) / 미국 |
| Google LLC                         | 서비스 이용 통계 분석(Google Analytics 4) / 미국          |
| Functional Software, Inc. (Sentry) | 오류 진단 및 서비스 안정성 모니터링 / 미국                |

### 2-2. 「8. 개인정보의 국외 이전」 — 전면 교체 (필수)

현행: _"서비스는 개인정보를 국외로 이전하지 않습니다."_ → 사실과 다르다. 방침이 스스로 「1. 수집하는 정보」에서 기기 식별자와 접속 IP를 수집 항목으로 적고 있고, 그 둘이 위 수탁자에게 나간다.

> 서비스는 이용 행태 분석과 오류 진단을 위해 아래와 같이 개인정보를 국외로 이전합니다.
>
> - **이전받는 자**: Amplitude, Inc. / Google LLC / Functional Software, Inc.(Sentry)
> - **이전 국가 및 일시**: 미국, 서비스 이용 시점에 네트워크를 통해 수시 전송
> - **이전 항목**: 기기 식별자, IP 주소, 접속 기기·브라우저 정보, 화면 이동 및 클릭 기록, 공부 세션 요약(시간·집중률·종료 사유), 화면 재생 기록
> - **이전 목적**: 서비스 이용 행태 분석, 기능 개선, 오류 진단
> - **보유·이용 기간**: 위탁 계약 종료 시 또는 이용자의 삭제 요청 시까지
>
> 이용자는 개인정보의 국외 이전을 거부할 수 있으며, 거부를 원하는 경우 아래 연락처로 요청해 주시기 바랍니다. 다만 거부 시 서비스 품질 개선을 위한 분석에서 제외되며, 서비스의 기본 기능 이용에는 제한이 없습니다.

> ⚠️ **거부권을 문구로만 쓰면 안 된다.** 「개인정보 보호법」 제28조의8은 국외 이전 거부권을 보장하므로, 요청을 받았을 때 실제로 수집을 끌 수 있어야 한다. 구현은 Amplitude SDK의 `setOptOut(true)`(+ GA4·Sentry 대응)이며 **아직 코드에 없다** — 별도 티켓으로 만들 것.

### 2-3. 「1. 수집하는 정보와 수집 방법」 — 이용 기록 항목 보정 (권장)

현행 「서비스 이용 기록」이 _"접속 IP 주소, 접속 일시, 서비스 이용 기록"_ 인데, 실제로는 화면 이동·클릭·유입 경로·화면 재생까지 수집한다.

> **서비스 이용 기록** — 접속 IP 주소, 접속 일시, 화면 이동 및 클릭 기록, 서비스 유입 경로(광고·링크 등), 서비스 이용 중 화면 재생 기록. 화면 재생 기록에는 **카메라 영상이 포함되지 않습니다**(기록 시점에 영상 영역이 제외됩니다).

### 2-4. 「10. 만 14세 미만 아동의 개인정보」 — 문구 보정 (권장)

현행: _"수집하는 정보는 기기에서 자동 생성되는 무작위 식별자와 공부 시간 기록에 한정됩니다."_ → §1과 어긋난다(IP·이용 기록 누락). _"…무작위 식별자, 공부 시간 기록, 서비스 이용 기록에 한정됩니다."_ 로 고친다.

## 3. 반영 순서 (이 순서를 지킬 것)

`legalDocuments.ts`는 **웹 원본의 사본**이다(파일 상단 주석). 사본을 먼저 고치면 원본과 어긋난 약관이 앱에 뜬다.

1. **원본 수정** — `pages-nextjs` 저장소의 `/privacy` 페이지에 위 §2를 반영하고 시행일을 바꾼다.
2. **사전 공지** — 현행 「14. 방침의 변경」이 _"시행 7일 전부터"_ 공지를 요구한다. 국외 이전 신설이 30일 조항(_"이용자의 권리에 중대한 영향을 미치는 변경"_) 대상인지는 팀에서 판단할 것.
3. **사본 동기화** — `legalDocuments.ts`의 `PRIVACY_POLICY`를 원문 그대로 옮기고 `effectiveDate`를 원본과 일치시킨다. **의역·요약·재배열 금지**(파일 주석).
4. **배포** — 시행일 이후에 Amplitude 확대 설정이 붙은 빌드를 프로덕션에 올린다.
